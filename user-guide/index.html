NAME

user guide - install dbtools and use its tools in Revit

SYNOPSIS

Installation, Getting started

DESCRIPTION

dbtools is an add-in for Revit 2026 (2026.5 or later) and Revit 2027. The tables list its tools by ribbon panel.

TOOLS

Common

Page Use
Global Mapper Replace content in bulk, find duplicates and add shared parameters.
Transfer Drafting Views Copy drafting views to a library with Export To Library, and back with Import From Library.
Elevation Tags Align spot elevation tags with Align Elevation Tags, and set their symbol text with Set Elevation Symbol Text.

Structural

Page Use
Super Girt Tool Place girts and opening framing on a wall.
Combined Foundation Tags Update combined foundation tags with Update Combined Foundation Tags, and move them with Move Combined Tags.
Organize Foundation Types Organize foundation types for tagging.
Analytical Snap To Level Move the ends of analytical members to a level.
Allow Join and Disallow Join Allow or disallow joins at both ends of framing.
Update Joist Girder Weights Estimate the weight of each joist girder.

Testing

The Testing tools are experimental.

Page Use
View Template Comparer Compare and merge view template settings.
Record Set Package Revit models with their linked files.
Extreme Roof Framing Tool Fit columns and beams to floor and roof slopes with Extreme Roof Framing.

Services

Dialog Suppression runs when Enable Services and Enable Dialog Suppression are on. Under Settings > Services Settings, use Dialog Regex Patterns to choose which dialog text to match. A match suppresses a dialog that supports a result override.
