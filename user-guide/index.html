User guide

DB Tools is a set of tools for Autodesk Revit 2026 (2026.5 or later) and Revit 2027. This guide describes how to install the add-in and how to use each tool.

  • Installation: requirements, installing, uninstalling, files and troubleshooting.
  • Getting started: the ribbon, the settings window, logs and shared conventions.

Tools

Common

Tool Purpose
Global Mapper Replaces families, types, styles and materials in bulk, finds duplicates, and adds shared parameters.
Transfer Drafting Views Copies drafting views between the open project and a library project.
Elevation Tags Aligns the labels of spot elevation tags in plan views.

Structural

Tool Purpose
Super Girt Tool Places and manages wall girts, headers, sills and jambs.
Combined Foundation Tags Updates the data of combined pier and footing tags and moves the tags to footing corners.
Organize Foundation Types Renames foundation types by their dimensions, assigns type marks and merges duplicates.
Analytical Snap To Level Moves analytical beam and column end points to a level.
Allow Join and Disallow Join Allow or disallow joins at the ends of structural framing.
Joist Girder Weights Estimates joist girder weight and writes it to the Wt parameter.

Testing

Tool Purpose
View Template Comparer Compares two view templates and merges selected settings.
Record Set Packages Revit host models together with their linked files.
Extreme Roof Framing Tool Adjusts structural columns and beams to sloped roofs and floors.

The Testing tools are under development.

Help

  • Each tool page lists the tool's limitations and the messages it shows.
  • For a failure, read the newest log in %APPDATA%\DBTools\Logs\. See Getting started.
  • To build or extend DB Tools, see the Developer guide.
