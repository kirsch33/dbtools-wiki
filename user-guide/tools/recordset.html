Record Set

Record Set packages Revit host models together with the files they reference. It copies the selected RVT host files and their file-based links (RVT, DWG and other external references) into a target folder with a fixed folder structure, optionally processes DWG Xrefs with AutoCAD Core Console, and rewrites the references in the copied RVT files so they point to the copies. Before it writes anything, Record Set shows the planned output tree and any problems.

Record Set is a Testing tool and is under development.

Synopsis

Ribbon: DB Tools > Testing > Record Set.

The command opens the modal Record Set window. It needs an open document.

Usage

  1. Click Target Folder... and choose the output folder. The folder must be inside an allowed target root (see Safety checks). Change picks another folder.
  2. Click Add Revit File... (or Add host) and pick one or more host RVT files.
  3. In the Host Models grid, set Discipline and Building for each host.
  4. Read the Preview tree and the Preview Messages.
  5. For DWG files, set the CAD handling from the DWG's context menu in the preview tree.
  6. Click Execute when the preview is current and has no blocking message.

Canceling a file or folder picker changes nothing.

Window

Target folder

Shows the selected output folder. The footer reports:

Field Values
Root Pending, Allowed or Blocked: whether the target is inside an allowed root
Free Free space on the target drive
ACAD The AutoCAD Core Console path, or Unavailable
Sentinel Pending, Present or Missing: the .recordset_sentinel file in the target

Host Models

Column Purpose
Host File File name of the host RVT (read-only)
Discipline Discipline folder of the host and its links. Empty adds no folder.
Building Building folder. The default - adds no folder.

The Discipline and Building lists have a < Add new… > choice that asks for a new value; canceling the prompt keeps the previous value. Right-click a row and choose Remove Host to remove it.

When you add hosts, Record Set reads each host's external references. A host that is already in the list, or picked twice, is skipped with a message. A host whose references cannot be read is rejected and does not appear in the grid. Record Set does not read links of linked RVT models.

Preview

The tree shows the proposed output folder structure. It is rebuilt automatically 350 ms after the last change to the target, hosts, metadata or CAD settings.

Options menu:

Item Effect
Manage Disciplines... Add, rename and delete discipline names. Renames and deletes apply to the hosts and links that use them.
Manage Buildings... The same for building names.
Auto-discover CAD Xrefs Read the Xrefs of each DWG with AutoCAD Core Console and copy them beside the DWG. The scan fails on a DWG that has Xrefs; see DWG files.
Allow CAD repath Rewrite Xref paths in the copied DWG files.

These items are disabled until a host exists. The two CAD options follow Core Console availability until you set them; your choice lasts until the window closes and is not saved.

Right-click a DWG in the tree for its CAD actions:

Item Effect
CAD: Keep Xrefs Copy the DWG and its Xrefs (the default). Xrefs are found by discovery or by the folder heuristic; see DWG files.
CAD: Bind All Bind all Xrefs into the copied DWG with AutoCAD Core Console. Clears manually added Xrefs.
Bind Type > Bind / Insert AutoCAD BINDTYPE 0 or 1. Bind keeps Xref-prefixed names; Insert merges names and can produce name conflicts.
Add Xref... Add a DWG Xref by hand, copied beside the DWG.

Preview Messages

Messages have the severity Info, Warning or Block. Any Block message disables Execute. Examples:

  • a file excluded by the safety policy (Warning);
  • a planned source file that does not exist (Block);
  • a destination name collision; the second file is renamed name (2).ext, name (3).ext and so on (Warning);
  • Auto-discover CAD Xrefs disabled. or AutoCAD Core Console not found. DWG Xrefs copied by heuristic only. (Info);
  • CAD: Bind All, or discovery together with repath, without Core Console (Block);
  • a plan larger than 80 GiB or more than 10,000 items (Block).

Manage Items

The Manage Disciplines and Manage Buildings dialog has Add, Rename, Delete and Close. Names are trimmed and compared without case; a duplicate is ignored on Add and rejected on Rename. Close is the default button, so Enter closes the dialog.

Output structure

File Destination
Host {target}\{building}\{discipline}\{host}.rvt
Link used by one host {target}\{building}\{discipline}\Linked Files\{name}
Link used by two or more hosts {target}\Common Linked Files\{name}

A - building and an empty discipline add no folder. A link counts as common when the same full path and type appear at least twice, also twice in one host.

DWG files

  • Keep Xrefs with discovery and Core Console: Record Set scans the DWG for Xrefs. The scanner fails on any DWG that has a nonempty Xref path, so it succeeds only for a DWG without Xrefs. On a successful scan, Allow CAD repath re-saves the copied DWG. A failed scan adds the Warning CAD Xref discovery failed for <name>: <error>. Using fallback., uses the folder heuristic below and skips repath.
  • Keep Xrefs without discovery, without Core Console or after a failed scan: Record Set copies sibling folders named xrefs, xref, refs, ref, external, dwg or cad next to the DWG. Xref paths are not rewritten, so references can break.
  • Bind All: the DWG is copied and its Xrefs are bound into the copy. No Xref files are copied.

Core Console is found through the ACCORECONSOLE environment variable, then accoreconsole.exe on PATH, then AutoCAD 2026, 2025 or 2024, then DWG TrueView 2025 under C:\Program Files\Autodesk.

Revit references

In each copied host, Record Set rewrites the external references that point to copied files and leaves the loaded or unloaded state unchanged. A host with at least one rewritten reference is saved as transmitted. A transmitted workshared copy opens detached and cannot create new local files. Library references (for example keynote and assembly-code tables in a content library) are not copied or changed.

Safety checks

The safety policy is built into Record Set and cannot be changed by the user.

  • The target folder must be inside an allowed root. The shipped root is \\fileserver\Projects.
  • Files with the extensions .dwl, .dwl2, .tmp, .bak, .lnk and .exe, and files matching *backup*.rvt, *.old and ~$*, are not copied.
  • The target drive must keep at least 10 GiB (10,737,418,240 bytes) free after the copy.
  • Execute checks the policy again and checks every output path, after resolving file and folder redirects, before it writes.

Result

Execute runs the plan in order under a progress overlay that cannot be canceled. Editing and closing the window are disabled while it runs.

  1. Record Set creates {target}\.recordset.lock (only one run per target at a time) and {target}\.recordset_sentinel.
  2. It creates folders, copies files (overwriting existing files and keeping their timestamps), runs the CAD operations and rewrites the Revit references.
  3. It writes {target}\_recordset_manifests\{run_id}.json with the run ID, plan fingerprint, target, UTC time, the summary counts and the status (ok, cancelled or failed).
  4. It removes the lock.

An alert then shows Status: ok and the manifest path. A failure shows no alert and no banner: Record Set logs the error with its details and opens the logger window. With Debug Mode on, the logger window also opens when the Record Set window closes.

Limitations

  • A failed run is not rolled back: copied or rewritten files stay in the target. Read the log and the manifest before you clean the output or run again.
  • If a run stops without removing .recordset.lock, the next run at that target fails. Delete the lock only when no run is active.
  • There is no cancel action during Execute.
  • The size and item limits are preview estimates, not limits on the final package size.
  • Xref discovery fails on every DWG that has Xrefs, so Record Set copies its Xrefs only by the folder heuristic or Add Xref..., and CAD repath never rewrites an Xref path. References in the copied DWGs can break.
  • Linked RVT models are not scanned for their own links.
  • The safety policy and its allowed root are fixed in the tool.

See the developer page and the technical specification for the plan format, fingerprint and audit files.
