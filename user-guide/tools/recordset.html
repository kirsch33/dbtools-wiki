Record Set

NAME

Record Set - copy Revit host models and their linked files into one package folder

SYNOPSIS

dbtools > Testing > Record Set

DESCRIPTION

Record Set copies host RVT files and their file-based links into a target folder. Then it changes the links in the copied hosts to point to the copies. It copies the files as saved on disk, and changes no source file.

  1. Click Target Folder... and choose the target folder.
  2. Click Add Revit File... and choose host RVT files. With hosts in the list, the button is Add host.
  3. In Host Models, set Discipline and Building for each host. Choose < Add new… > to type a name.
  4. Read the Preview tree and the Preview Messages.
  5. Right-click a DWG in the tree to set its CAD handling.
  6. Click Execute.

Preview shows the files and folders in the copy plan, including any Xref folders the plan copies. Preview Messages lists files excluded by policy.

Execute is available when the preview is up to date, the footer shows Root Allowed, and no message has the severity Block.

OPTIONS

The Options menu above the preview:

Item Effect
Manage Disciplines..., Manage Buildings... Add, rename or delete names. A rename or a delete also applies to the hosts and links.
Auto-discover CAD Xrefs Find the Xrefs of each DWG, also nested ones, with AutoCAD Core Console. Copy each Xref file into the folder of the DWG copy.
Allow CAD repath With discovery, point each Xref in the DWG copies at its copy, with a relative path such as .\Grid.dwg.

Both CAD options start on only when Core Console is found. Without discovery, Record Set copies the folders xrefs, xref, refs, ref, external, dwg and cad that are beside the DWG to the same place beside the DWG copy. Names and options last until the window closes.

The context menu of a DWG link in the tree:

Item Effect
CAD: Keep Xrefs The default. Copy the DWG and its Xrefs as the Options menu sets.
CAD: Bind All Bind every Xref into the DWG copy, with Core Console. It drops the Xrefs added with Add Xref... from the plan.
Bind Type > Bind or Insert For CAD: Bind All, Bind sets AutoCAD BINDTYPE 0 and Insert sets 1.
Add Xref... Add a DWG Xref by hand. It is copied beside the DWG copy.

REQUIREMENTS

Item Rule
Target folder Must be in \\fileserver\Projects, a root built into the tool. Otherwise Root shows Blocked.
Free space At Execute, the target drive must keep 10 GiB free after the copy.
AutoCAD Core Console Needed for discovery, repath and Bind All. Record Set uses the ACCORECONSOLE environment variable, then PATH, then the newest AutoCAD or DWG TrueView. The footer shows the path in ACAD.

RESULTS

<target>\<building>\<discipline>\<host>.rvt
<target>\<building>\<discipline>\Linked Files\<link>    a link of one host
<target>\Common Linked Files\<link>                       a link of two or more hosts

The default building - and an empty discipline add no folder. A link is common when its full path appears two or more times, even in one host. When two different source files would get one target path, the second gets <name> (2).<ext>, and so on.

Execute copies the files, does the CAD work, and then changes the links in the host copies. A copy replaces an existing file in the target and keeps the source timestamps.

After a successful run, an alert shows Status: ok and the manifest path. A failed run records the error in the log. Record Set adds no Undo step.

MESSAGES

Message Meaning and what to do
Policy denied host file: <name>, and the other Policy denied … messages The file is not copied. The tool excludes .dwl, .dwl2, .tmp, .bak, .lnk and .exe files, and names that match *backup*.rvt, *.old or ~$*.
Xref <name> in <dwg> not found: <stored path> The file is not at its stored path or in the DWG folder. The DWG copy keeps the stored path.
CAD Xref discovery failed for <name>: <error>. Using fallback. Record Set copies the Xref folders as without discovery, and changes no Xref path.
Bind All blocked for <dwg>: … A Block. Every direct and nested Xref must exist and must not be excluded. Fix the Xref, or choose CAD: Keep Xrefs.
Total size <bytes> exceeds limit., Total plan item count <n> exceeds limit. A Block. The plan is over 80 GiB or 10,000 items. Put fewer hosts in each package.

FILES

<target>\.recordset.lock                    exists while a run is active
<target>\.recordset_sentinel                marks a Record Set target
<target>\_recordset_manifests\<run>.json    the run ID, counts and status (ok or failed)

LIMITS

  • A failed run does not undo its work. Read the log and the manifest before you run again.
  • If a run stops without removing .recordset.lock, the next run at that target fails. Delete the lock only when no Execute runs on that target.
  • Execute cannot be canceled.
  • Record Set does not copy the links of linked models.
  • Without discovery, or without Allow CAD repath, the DWG copies keep their stored Xref paths. An absolute path still points to the source.
  • Links with a path relative to a Revit library location are not copied or changed.
