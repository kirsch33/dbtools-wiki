Transfer Drafting Views

NAME

Transfer Drafting Views - copy drafting views between the model and a library file

SYNOPSIS

dbtools > dbtools Common > Import From Library

dbtools > dbtools Common > Export To Library

DESCRIPTION

Transfer Drafting Views (TDV) works with a library: a Revit model (.rvt) that holds standard drafting views. An import copies views from a library (the source) into the active model (the destination). An export copies views from the active model into a library.

  1. Run a command to open Select Library File. Use Filter library files to narrow the list by name or displayed path. Select a file and click OK, or click Browse for File.
  2. In the Transfer Drafting Views window, check the views to copy. Select a row to preview that view.
  3. Fix each name conflict, then click Transfer Selected. Each click is one transfer.
  4. Review the outcome and counts in Transfer Result. Click Transfer More to return to the list or Close Tool to finish.

The picker opens even when no saved library is usable. It explains the empty list and offers Browse for File. When valid and invalid paths both exist, it lists the valid files and reports the unavailable count. Cancel the file picker to return to Select Library File.

TDV opens the chosen library in the background. Choose an accessible .rvt file from the current Revit version. The active model and its workshared central file cannot serve as the library. A browsed file applies to one transfer window. Add the path in Library Files to use it from the list on later runs.

For a workshared library, TDV opens all worksets in a temporary local copy under %APPDATA%\dbtools\Cache\TDV\LibraryLocals\. A library without worksharing opens in place.

The preview fits the selected view to the pane and matches the exported background. A transparent image corner uses the Revit canvas color. Use the mouse wheel to zoom and drag with the left button to pan. Zoom Extents fits the whole view again.

OPTIONS

Control Effect
Source View Type Shows only the source views of one type.
Filter views by name Shows the views whose name contains the text, or its letters in the same order. Use × or press Esc in the field to clear it.
Import? or Export? Includes the row in the transfer.
View Name The destination name. Double-click it to change it.
Replace Replaces the destination drafting view with the same name.
Destination View Type The destination view type. Retain Original uses the type name of the source view.

Checked rows stay in the transfer when a filter hides them. Check the Selected count before transferring. Clear Selection unchecks every row.

A checked row has a conflict if its name is blank, another checked row has the same name, or a drafting view with that name already exists in the destination and Replace is off. The check ignores case and leading or trailing spaces. Turn on Replace only if you intend to replace the existing view's contents.

SETTINGS

Open dbtools > Settings and select Common on the left. In Library Files, click Add Library File… to choose a file. Select a main file to edit its Alias or choose Set Fallback Path…. TDV uses the fallback when the main file is unavailable.

A path is valid when the file exists, ends in .rvt, and was saved in the Revit version that runs. TDV opens no other file, so it never upgrades a library. The list marks any other path Unavailable.

When Revit starts, when Settings opens and when you click Save Settings, TDV checks the saved paths. One entry with no valid path turns on the warning Library Paths Invalid. The warning leaves both commands available. Fix or remove the entry, then click Save Settings. Use Validate in the Settings footer to check the current entries and refresh warnings.

RESULTS

For each checked view, TDV makes a drafting view or reuses a matching view when Replace is on. It assigns the selected view type and copies the scale, the writable VIEW_DESCRIPTION parameter, the elements and their graphic overrides. Both clearing an existing view and copying into it skip the categories Title Blocks, Viewports, Views, Schedules and Guide Grids.

If a view fails, TDV undoes that view and continues with the others. Check Per-View Issues for the view and the reason. Cancel on the progress bar undoes the Transfer Selected run, up to the end of the last view.

If the transfer report says finalization could not be verified, inspect the destination before retrying. It may contain changes from that run.

Each import transfer is one Undo step, Transfer Drafting Views. Before closing the library, TDV reactivates your saved project if Revit switched documents. Import closes the library without saving.

When the export window closes, TDV saves the library if any transfer added or replaced a view. It also saves if it cannot confirm a commit or rollback. For a workshared library, TDV synchronizes with central and relinquishes all elements. The synchronization comment gives the window's totals. TDV reports save, synchronization and close failures. If TDV cannot reactivate your project, switch back to it in Revit.

MESSAGES

Message Meaning and what to do
The open document cannot be selected as its own library file. Choose another file. The active model's central file also counts as the open document.
The selected library file cannot be used. <reason>. Read the reason and choose an available .rvt file from the current Revit version.
SourceTypeNameUnavailable TDV could not read the source type name for Retain Original. Choose a named Destination View Type.
DestinationTypeMissing The named type is not in the destination, or Retain Original could not make it.
CopyElementsFailed Inspect the source view and the reported Revit error before retrying.
TransactionRolledBack Revit discarded the whole transfer. Check the report before retrying the selection.

LIMITS

  • A copied element whose type name exists in the destination uses the destination type.
  • If the destination has no type with the Retain Original name, TDV duplicates the alphabetically first destination drafting view type and gives it that name. The type keeps the properties of the duplicated type.
