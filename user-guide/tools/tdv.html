Transfer Drafting Views

NAME

Transfer Drafting Views - copy drafting views between the model and a library file

SYNOPSIS

DB Tools > DB Tools Common > Import From Library

DB Tools > DB Tools Common > Export To Library

DESCRIPTION

Transfer Drafting Views (TDV) works with a library: a Revit model (.rvt) that holds standard drafting views. An import copies views from a library (the source) into the active model (the destination). An export copies views from the active model into a library.

  1. Run a command and select a library. TDV opens it in the background.
  2. In the Transfer Drafting Views window, check the views to copy.
  3. Fix each name conflict, then click Transfer Selected. Each click is one transfer.
  4. Click Accept and Transfer More or Close Tool in the result.

OPTIONS

Control Effect
View Type: Shows only the source views of one type.
Search views Shows the views whose name contains the text, or its letters in the same order.
Import? or Export? Includes the row in the transfer.
View Name The destination name. Click it to change it.
Replace Replaces the destination drafting view with the same name.
View Type The destination view type. Retain Original uses the type name of the source view.

A checked row has a conflict in these cases:

  • Its name is blank.
  • Another checked row has the same name.
  • The destination has a drafting view with that name, and Replace is off.

The check ignores case and leading or trailing spaces.

SETTINGS

Open DB Tools > Settings, expand Common Settings and find Library Files. Add Fallback Path adds a file that TDV uses when the main path is not valid.

A path is valid when the file exists, ends in .rvt, and was saved in the Revit version that runs. TDV opens no other file, so it never upgrades a library. A cross marks an invalid path.

When Revit starts, when Settings opens and when you click Save Settings, TDV checks the saved paths. One entry with no valid path turns on the warning Library Paths Invalid, which turns off both commands for all libraries. Fix or remove the entry, then click Save Settings. Validate Libraries shows the result but does not change the commands.

RESULTS

For each checked view, TDV makes a drafting view. With Replace, it deletes all elements of the existing view and gives that view the selected type. It copies the scale, the VIEW_DESCRIPTION parameter, the elements and their graphic overrides. It skips the categories Title Blocks, Viewports, Views, Schedules and Guide Grids.

If a view fails, TDV undoes only that view and continues. Per-View Issues in the result shows its code. Cancel on the progress bar undoes the whole transfer.

Each transfer of an import is one Undo step: Transfer Drafting Views. TDV then closes the library without saving.

After an export, TDV saves the library if any transfer in the window added or replaced a view. A workshared library synchronizes with central and relinquishes all elements. The comment of the synchronization gives the totals of the window. Then TDV closes the library and activates your model again. If the library cannot be saved, synchronized or closed, the export fails, and the error report names each failure.

MESSAGES

Message Meaning and what to do
DestinationTypeMissing The named type is not in the destination, or Retain Original could not make it.
CopyElementsFailed Revit could not copy an element. TDV copies nothing from that view.

LIMITS

  • A copied element whose type name exists in the destination uses the destination type.
  • If the destination has no type with the Retain Original name, TDV duplicates the alphabetically first destination drafting view type and gives it that name. The type keeps the properties of the duplicated type.
