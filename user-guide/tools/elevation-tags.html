Elevation Tags

Elevation Tags places the label of each matching spot elevation at a uniform position beside its leader end. The elevation text is re-measured and positioned from the tag type's font, text width and the view scale. The tool runs on demand from the ribbon and, optionally, each time you open a plan view.

Synopsis

Ribbon: DB Tools > Common > Align Elevation Tags.

The button is enabled when a view is active. It processes the active view only.

Supported views: floor plans, structural plans (engineering plans) and ceiling plans. In any other view type the command shows the warning banner Elevation Tags supports Floor Plans, Structural Plans, and Ceiling Plans only. Active view type: <type>. and changes nothing.

Usage

  1. Open a floor, structural or ceiling plan.
  2. Click Align Elevation Tags.
  3. Read the banner.

With Auto-Update Enabled on, the same alignment runs each time a supported plan view becomes active. Automatic runs show no banner. Failures go to the log.

Set Elevation Symbol Text

Ribbon: DB Tools > Common > Set Elevation Symbol Text.

  1. Select spot elevations in the active view.
  2. Click Set Elevation Symbol Text.
  3. Enter the symbol text, for example T.O. FTG., and click Apply.

The command copies each selected spot's symbol family and spot elevation type, then assigns the selected spots to the new type. The family and type names are <original name> - <text>. Existing variants with the same name and text are reused. Changing the text again uses the original names, without adding another suffix. Spots outside the selection keep their types. The original families and types keep their content.

The symbol family must contain exactly one plain text element. Labels are not supported. The command names the family when it finds no plain text or more than one plain text element. Text is trimmed and must be nonempty, on one line, and valid in Revit names and Windows filenames. An existing family with different text or an existing spot type with a different symbol causes a refusal. An in-line spot type whose Symbol parameter is read-only cannot receive a new symbol.

The command removes unused variants that the selected spots leave. It preserves user families, user types, unrelated variants, and variants still referenced in the project. Unused symbol-text copies of a family can remain, and Revit's Purge Unused removes them. Variants owned by another worksharing user remain. A temporary-file removal failure goes to the log and does not undo the text change. Cancel changes nothing. A failure rolls back the family loads, type creation, reassignment, and cleanup together. One Undo restores the whole change.

What is aligned

A spot elevation is processed when all of these hold:

  • one of its names matches a tag name pattern (see Settings);
  • it has a leader;
  • the elevation base of its type is not Relative.

For each processed spot the tool computes the label position from the leader end, then applies the per-type offsets. The placement follows the Text Location of the spot elevation type:

Text Location Label position
Above Leader, Below Leader Beside the leader end, over the leader shoulder. Above the leader when the leader runs up the screen to the point; below it when the leader runs down or is level.
In-line with Leader On the leader line, past the leader end on the side away from the shoulder.

Revit itself draws Above Leader labels above the leader and Below Leader labels below it, whichever way the leader runs. It also mirrors the marker symbol when the leader runs up the screen, so text drawn above the origin of the symbol, as in the DB Elevation Tag label symbols, lands on the side away from the point. Revit's own side therefore puts the label on the symbol text for Above Leader with a leader running down and for Below Leader with a leader running up. The tool puts the label on the point's side instead, for both locations. Revit draws no marker symbol for In-line with Leader.

The tool places the label along the plan view's displayed up and right directions, including rotated plans. The per-type offsets apply after this placement: a negative Perpendicular offset larger than the gap puts the label on or across the leader. The tool moves the label only when the new X or Y position differs from the current one after rounding both to two decimals (feet). Spots that already sit at the target position are not counted as updated.

For a type whose elevation base is Project Base Point, the displayed elevation is measured from the project base point when the project base point and survey point are at different positions.

Settings

Open DB Tools > Settings and select the Elevation Tags pack.

Setting Default Description
Auto-Update Enabled On Align tags when a supported plan view is activated.
Tag Name Patterns (Regex) ^DB Elevation Tag - (?:Concrete\|Steel\|Wall) Label$ Up to 3 regular expressions. A spot is processed when any pattern matches any of its names. Matching is case-insensitive.
Along Leader 0 Moves the label away from the leader end (positive) or toward it (negative), along the horizontal direction of the label.
Perpendicular 0 Moves the label away from the leader line (positive) or toward it (negative), vertically. For In-line with Leader, positive moves the label up.

A spot is tested against these names: the spot name, the spot dimension type name and its family name, and the name and family name of the type's marker symbol. Because spot elevations are a system family, the patterns match the type and marker symbol names, not only loaded family names.

When the pattern list is empty, the default pattern is used. A pattern that is not a valid regular expression is skipped and logged.

The two offsets are stored per spot elevation type. The offsets are in paper inches. The tool multiplies them by the view scale divided by 12 to get model units.

The settings pack has a type selector (previous and next buttons) and a live preview. The preview draws two spots of the selected type on one element, with the text where the tool places it for the type's Text Location. For Above Leader and Below Leader, the text is below the shoulder for the spot whose leader runs down to the element and above the shoulder for the spot whose leader runs up. Each spot draws the type's own symbol family at its leader end. The preview mirrors the symbol's positions for the upward leader as Revit does. For In-line with Leader, the text is centered on the leader past its end, with no symbol. The text is in the type's font and moved by the current offsets. A dashed outline shows the text position without offsets. The drawing is at twice print size, and is reduced when it does not fit. Under the drawing, the preview shows the type's font, text location, elevation indicator, elevation base and symbol. The preview uses the same Text Location value as Align in every Revit language. The text location label uses Revit's display name. A type with a missing or unknown Text Location is omitted from the preview and recorded in the log. With no project open, the preview asks for one. When no spot elevation type in the project matches the tag name patterns, the preview says so and lists the patterns.

Settings are stored per user and Revit year in %APPDATA%\DBTools\settings.<year>.json. They apply to every project.

Result

The command is one undo entry. The banner shows one of these messages:

Message Kind
Aligned N elevation tag(s). Success
Aligned N elevation tag(s); M could not be updated. See the DB Tools log. Warning
M elevation tag(s) could not be updated. See the DB Tools log. Warning
No spot elevation tags were found in the active view. Info
No spot elevation tags matched Tag Name Patterns. Check Elevation Tags settings. Info
No matching elevation tags needed changes. Spot elevations without a leader are skipped. Info

A failure on one tag does not stop the others. A spot whose names cannot be read counts as failed.

Press Ctrl+Z to undo a manual run.

Limitations

  • Only the active view is processed. There is no multi-view command; auto-update covers each view as you open it.
  • Linked models are not processed.
  • Spots without a leader and spots on a Relative elevation base are skipped. The last info message does not say which of the two causes applies.
  • The side rule follows the DB Elevation Tag label symbols, which draw their text above the symbol origin. With a symbol that draws its text below its origin, the label lands on that text.
  • For an exactly level leader the label goes below the leader, but Revit may draw the symbol either way, so the label can land on the symbol text. Give the leader a slight slope.
  • The text width is measured with the Windows font engine and the tag type's font. Arial is used when the type defines no font.
