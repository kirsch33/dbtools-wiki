Elevation Tags

NAME

Elevation Tags - align spot elevation text with its leader, and set symbol text

SYNOPSIS

DB Tools > Common > Align Elevation Tags

DB Tools > Common > Set Elevation Symbol Text

DESCRIPTION

Align Elevation Tags moves the text of each matching spot elevation in the active view beside its leader end, at the same gap for short and long text. It works in floor, structural and ceiling plans.

A spot elevation is aligned when all of these are true:

  • A pattern in Tag Name Patterns (Regex) matches one of these names: the spot type, its family, the symbol type or the symbol family.
  • It has a leader.
  • The elevation base of its type is not Relative.
Text Location Position of the text
Above Leader, Below Leader Over the shoulder, on the side of the leader toward the point that the spot measures. A level leader puts the text below the leader.
In-line with Leader Centered on the leader line, past the leader end.

Align gives Above Leader and Below Leader the same position. This keeps the text off the symbol text of the DB Elevation Tag symbols.

Set Elevation Symbol Text gives the selected spot elevations a symbol with other text. Enter the text, such as T.O. FTG., at Symbol text: and click Apply. The command copies the symbol family and the spot type, names each copy <original name> - <text>, and moves only the selected spots to the copy. The symbol type keeps its name. The same text again uses the same copies. The text must be on one line, without \ / : * ? " < > | { } [ ] ; ` ~.

REQUIREMENTS

Item Rule
Symbol family For Set Elevation Symbol Text: an editable spot elevation symbol family with exactly one text element.

SETTINGS

Open DB Tools > Settings, expand Common Settings and find Elevation Tags.

Auto Update Elevation Tags runs Align, without a banner, each time you open or switch to a supported plan view. It is on by default.

Tag Name Patterns (Regex) holds up to 3 .NET regular expressions. They are not case-sensitive. The default is:

^DB Elevation Tag - (?:Concrete|Steel|Wall) Label$

Alignment Offsets edit the type that Live Preview shows, in paper inches. The arrow buttons choose the type. A positive Along Leader moves the text along the shoulder, away from the leader end. A positive Perpendicular moves it away from the leader line, or up for In-line with Leader. The next Align run uses the saved values.

Live Preview draws the type with a downward and an upward leader. A dashed outline shows the text without offsets.

RESULTS

Align ends with a banner, such as Aligned 12 elevation tag(s). A tag that is already in place does not count. Each run that moves tags, also an automatic run, is one Undo step: DB Tools - Align spot elevations.

Set Elevation Symbol Text is one Undo step: DB Tools - Set elevation symbol text. It deletes a copy that it made when the change leaves the copy unused. A failure changes nothing.

MESSAGES

Message Meaning and what to do
No spot elevation tags matched Tag Name Patterns. Check Elevation Tags settings. Compare the patterns with the type and symbol names.
No matching elevation tags needed changes. Spot elevations without a leader are skipped. Each matching spot is in place, has no leader, or uses the Relative base.
Symbol family '<name>' contains <n> plain text elements. Exactly one is required. Edit the symbol family so that it has one text element.
Elevation Tags Disabled (a settings warning) Auto-update could not start, so Align and auto-update are off. Click Clear on the warning in Settings.

LIMITS

  • Align does not change spots in linked models.
  • The placement suits a symbol that draws its text above its origin, as the DB Elevation Tag symbols do. With another symbol, the elevation text can cover the symbol text.
  • The offsets are stored by spot type name, for every project. A renamed type or a copy from Set Elevation Symbol Text has no saved offsets unless its new name already has an entry.
  • A pattern that ends in $ can miss the copies, whose names end in - <text>. Align still finds a copy whose symbol type name matches.
  • Live Preview lists only the types whose type name matches a pattern, case-sensitive. To set offsets for another type, add a pattern for its type name.

EXAMPLES

To also align the spot types whose names start with Acme Spot, click + Add Pattern, enter this pattern and click Save Settings:

^Acme Spot
