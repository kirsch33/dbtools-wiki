Elevation Tags

NAME

Elevation Tags - align spot elevation text with its leader, and set symbol text

SYNOPSIS

dbtools > Common > Align Elevation Tags

dbtools > Common > Set Elevation Symbol Text

DESCRIPTION

Align Elevation Tags moves the text of each matching spot elevation in the active view beside its leader end, at the same gap for short and long text. It works in floor, structural and ceiling plans.

Align checks spot elevations that meet these conditions:

  • A pattern in Tag name patterns matches one of these names: the spot type, its family, the symbol type or the symbol family.
  • It has a leader.
  • Its Elevation Base displays a value other than Relative.

Align checks the displayed Elevation Base against the exact English values Relative and Project Base Point. Localized labels can change which tags Align skips or how it measures their text.

Text Location Position of the text
Above Leader, Below Leader Over the shoulder, on the side of the leader toward the point that the spot measures. A level leader puts the text below the leader.
In-line with Leader Centered on the leader line, past the leader end.

Align gives Above Leader and Below Leader the same position. This keeps the text off the symbol text of the DB Elevation Tag symbols.

Set Elevation Symbol Text gives the selected spot elevations a symbol with other text. Select the spots before running the command. Enter the text, such as T.O. FTG., at Symbol text: and click Apply. The command copies the symbol family and the spot type and names each copy <original name> - <text>. It moves only the selected spots. The symbol type keeps its name. The text must be on one line, without \ / : * ? " < > | { } [ ] ; ` ~.

A family copy with matching text and a type copy with the matching symbol can be reused. If a copy name is taken by a family with different text or a type with a different symbol, rename it before applying again.

REQUIREMENTS

Item Rule
Symbol family For Set Elevation Symbol Text: an editable spot elevation symbol family with exactly one text element.
Symbol assignment Use Above Leader or Below Leader if an In-line with Leader type has no symbol or a read-only Symbol.

SETTINGS

Open dbtools > Settings, expand Common Settings and find Elevation Tags.

Auto Update Elevation Tags runs Align, without a banner, each time you open or switch to a supported plan view. It is on by default.

Tag name patterns holds up to 3 .NET regular expressions. Align and Alignment Preview match the spot type and family names and the annotation symbol type and family names. Both ignore case. The default is:

^DB Elevation Tag - (?:Concrete|Steel|Wall) Label$

Alignment Preview reads matching spot elevation types and their symbols from the active project when Settings opens. The arrow buttons choose the type. The preview shows the offsets in paper inches. A positive Along Leader moves the text along the shoulder, away from the leader end. A positive Perpendicular moves it away from the leader line, or up for In-line with Leader. The next Align run uses the saved values. Align ignores the Revit type parameters Text Offset from Leader and Text Offset from Symbol.

The preview draws the type with a downward and an upward leader. When you set an offset, a dashed outline follows each label. The caption below the drawing gives the type's Text Location in Revit.

RESULTS

Manual runs report successful updates and warn if any tags fail. Align keeps successful updates when individual tags fail. The dbtools log gives failure details for manual and automatic runs. Each run that moves tags is one Undo step, dbtools - Align spot elevations.

Set Elevation Symbol Text is one Undo step: dbtools - Set elevation symbol text. It deletes a copy that it made when the change leaves the copy unused. A failure changes nothing.

MESSAGES

Message Meaning and what to do
No spot elevation tags matched Tag name patterns. Check Elevation Tags settings. Compare the patterns with the type and symbol names.
No matching elevation tags needed changes. Spot elevations without a leader are skipped. Each matching spot is in place, has no leader, or uses the Relative base.
Symbol family '<name>' contains <n> plain text elements. Exactly one is required. Edit the symbol family so that it has one text element.
Elevation Tags Disabled (a settings warning) Auto-update could not start, so Align and auto-update are off. Click Clear on the warning in Settings.

LIMITS

  • Align does not change spots in linked models.
  • The placement suits a symbol that draws its text above its origin, as the DB Elevation Tag symbols do. With another symbol, the elevation text can cover the symbol text.
  • The offsets are stored by spot type name, for every project. A renamed type or a copy from Set Elevation Symbol Text has no saved offsets unless its new name already has an entry.
  • Align and Alignment preview include a copy when its annotation symbol type name matches a pattern.

EXAMPLES

To also align the spot types whose names start with Acme Spot, click + Add Pattern, enter this pattern and click Save Settings:

^Acme Spot
