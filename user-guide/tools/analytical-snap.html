Analytical Snap To Level

NAME

Analytical Snap To Level - move the ends of analytical members to a level

SYNOPSIS

dbtools > Structural > Analytical Snap To Level

DESCRIPTION

The tool moves the end points of the selected analytical members to the elevation of one level. It changes only the curve of each analytical member. The plan position (X and Y) of the end points does not change.

  1. Select the analytical members. The button is enabled when any element is selected.
  2. Click Analytical Snap To Level.
  3. In Select Target Level, select a level. Each level shows as <name> (Elev: <elevation>), with the elevation in feet. The lowest level is first.
  4. Read the Snap to Level Complete window, and click OK.

REQUIREMENTS

The tool skips a selected element that fails a rule, and reports the reason.

Item Rule Skip reason
Element An analytical member, not the physical beam or column not an analytical member
Structural role Beam or Column, not another role such as Girder role not supported
Curve A straight line. A curved member keeps its shape. not straight
Length After the snap, the member is not shorter than Revit allows. An almost vertical beam fails this rule. would collapse

The role sets which end points move:

Role What moves
Beam Both end points. The member becomes horizontal.
Column Only the end point nearer the level. If both are equally near, the start point moves.

RESULTS

The completion window counts the processed and skipped elements. It shows one line for each skip reason:

<reason>: <count> (element IDs <id>, <id>, and <n> more)

It lists up to 10 IDs for each reason, and adds and <n> more for the rest. For not an analytical member, it shows only the count. The processed count includes members that were at the level already.

Each run is one Undo step: dbtools - Snap Analytical Elements to Level. An error undoes the whole run. A skip does not.

MESSAGES

Message Meaning and what to do
No target level selected. You closed the level window without a level, or the model has no levels. Nothing changes.

LIMITS

  • All selected members snap to the one level that you select. To use more levels, run the tool once for each level.
  • To snap to an elevation without a level, add a level there.
  • A sloped beam loses its slope.
