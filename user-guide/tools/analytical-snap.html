Analytical Snap To Level

Analytical Snap To Level moves the end points of the selected analytical beams and columns to the elevation of a level you choose. It edits the analytical model only. The physical elements do not change.

Synopsis

Ribbon: DB Tools > Structural > Analytical Snap To Level.

The button is enabled when at least one element is selected. Elements that are not supported analytical members are skipped and reported (see Result).

Usage

  1. Select analytical members. Select the analytical members themselves, not the physical elements they represent.
  2. Click Analytical Snap To Level.
  3. In the Select Target Level dialog, select one level and confirm. Closing the dialog without a selection cancels the command with the message No target level selected.
  4. Read the Snap to Level Complete dialog.

The level list is sorted by elevation, lowest first. Each entry reads <name> (Elev: <value>), where the value is the level elevation in feet with two decimals. The project has to contain at least one level.

Snapping rules

A member is snapped only when all of these hold:

  • it is an analytical member (the Analytical Member category);
  • its structural role is Beam or Column;
  • its curve is a straight line.
Role Rule
Beam Both end points move to the level elevation. The member becomes horizontal. Its plan position is unchanged.
Column Only the end point closer to the level elevation moves to it. The start point moves when both ends are equally close. The other end stays fixed.

X and Y coordinates of every end point are unchanged.

Result

The whole run is one Revit transaction named DB Tools - Snap Analytical Elements to Level. If an unexpected error occurs, the transaction is rolled back and no member changes.

The completion dialog shows the number of elements processed and skipped. Below that, it lists one line per skip reason with the count.

Skip reason Meaning
not an analytical member The element is not an analytical member (a physical element, an analytical wall or floor). Only the count is shown.
role not supported The structural role is not Beam or Column (for example girder or brace).
not straight The curve is not a line. The member is not changed.
would collapse The snap would make the member shorter than Revit's short-curve tolerance.

For each reason other than not an analytical member, the dialog lists up to 10 element IDs and and N more for the rest.

Press Ctrl+Z to undo a completed run in one step.

Limitations

  • The tool snaps to levels. It does not accept a reference plane or an arbitrary elevation. To use another elevation, create a level at it.
  • All selected members snap to the one level you choose. To snap different floors to different levels, run the tool once per floor.
  • Braces, walls, floors and curved members are not supported.
