Update Joist Girder Weights

NAME

Update Joist Girder Weights - estimate the weight of each joist girder and write it to Wt

SYNOPSIS

dbtools > Structural > Update Joist Girder Weights

DESCRIPTION

The tool estimates the self-weight of each joist girder in the model, in pounds per foot (lb/ft). It writes the estimate to the girder's Wt parameter and changes nothing else.

A joist girder is a Structural Framing element whose family name matches Family/Type Name Pattern. By default, these are the families G Joist Girder, BG Joist Girder, VG Joist Girder and Vulcraft Joist Girder.

The estimate uses four values of the girder: Length, Depth, Number of Joists and the point load. The point load is the load, in kips, at each panel point where a joist bears on the girder. The tool works on the whole model. It skips a girder with a missing or invalid value.

REQUIREMENTS

For each value, the tool tries each listed name on the girder, then on its type, and uses the first value found.

Value Parameters Rule
Number of Joists Number of Joists, SpaceNum, Number of Equal Spaces Must be more than 1. Enter the number of equal spaces, not of joists.
Length Cut Length, Length Must be more than 0.
Depth Depth Must be more than 0.
Point load Parameters that match the load patterns See Loads.
Weight Wt An editable Number parameter. The tool writes lb/ft here.

Text values for the first three must be plain numbers. Length and Depth are in feet. A parameter of type Length works in any display units. In a Number or text parameter, enter 48 in. as 4.

Loads

The point load is the total load, or else the dead load plus the live load. The load patterns in SETTINGS find each kind by parameter name. The tool skips the girder if two parameters of one kind have values, if a load is negative, or if no usable load exists.

A Force parameter is converted to kips. Other numbers are kips. Text can add a unit: k, kip, kips, lb, lbs, lbf, pound, pounds or kN.

SETTINGS

Open dbtools > Settings, expand Structural Settings and find Joist Girder Weights.

Auto Update Joist Girder Weights runs the tool, without a banner, each time you open or switch to a view. It is on by default. It can slow view changes in a large model. To see what it skips, run the tool from the ribbon.

The four patterns are .NET regular expressions. By default, the load patterns match DL, LL, and names that contain Dead Load, Live Load, Point Load or Total Load. The defaults are:

Family/Type Name Pattern   ^(?:(?:[BV]?G)|Vulcraft) Joist Girder$
Dead Load Pattern          (?:^DL$|Dead\s*Load)
Live Load Pattern          (?:^LL$|Live\s*Load)
Total Load Pattern         (?:Point\s*Load|Total\s*Load)

RESULTS

A run from the ribbon ends with a banner like this:

Candidates: 12
Updated: 10
Skipped: 2

Sample skipped element(s):
- Element 412345: Depth must be > 0.
- Element 412377: Number of joists must be > 1.

Candidates is the number of joist girders found. The banner lists up to 5 skipped girders, with the first problem of each. Find each girder with Manage > Select by ID, fix it, and run the tool again.

Each run that changes values is one Undo step: Auto Update Joist Girder Weights.

MESSAGES

Message Meaning and what to do
Required writable Double parameter 'Wt' not found. Add Wt as an editable Number parameter.
Missing required input for 'Point Load'. … No load parameter has a value. Fill in a load, or match the load patterns to your names.
Ambiguous <kind> Load inputs: … Two parameters of one kind, such as Dead Load and DL, have values. Clear one.
Joist Girder Weights Disabled (a warning in Settings) A saved pattern is not valid, so the tool is off. Correct the pattern and click Save Settings.
Auto-update failed; disabled for this document session. Auto-update stays off until you reopen the model.

LIMITS

  • The weight is an estimate from a fixed formula, not from SJI or manufacturer tables.
  • A blank Number total load counts as 0 and replaces the dead and live loads, so Wt becomes 0 with no warning. Fill in or delete it.
  • Make Wt an instance parameter. A type parameter gives all girders of that type one value.
  • A Wt with units, such as Length, shows a wrong value.

EXAMPLES

To also use the family Acme Girder, set Family/Type Name Pattern to this value and click Save Settings:

^(?:(?:[BV]?G)|Vulcraft) Joist Girder$|^Acme Girder$
