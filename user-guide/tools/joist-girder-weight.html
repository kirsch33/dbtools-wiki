Joist Girder Weight

Joist Girder Weight estimates the weight per foot of joist girders from their span, depth, panel count and panel point load, and writes the result to the Wt parameter of each girder. The estimate is for preliminary design and takeoffs. It does not replace the manufacturer's tables.

Synopsis

Ribbon: DB Tools > Structural > Update Joist Girder Weights.

The command processes the whole model. It does not depend on the selection or the active view.

Usage

  1. Make sure each girder family provides the inputs listed under Family requirements.
  2. Click Update Joist Girder Weights.
  3. Read the banner.

With Auto-Update Enabled on (the default), the same update runs each time you activate a view, with no banner. Disable it in the settings if view changes are slow in a large model.

Which elements are processed

The tool collects the elements of the Structural Framing category whose family name matches the Family/Type Name Pattern. It matches the type name only when the family name is unavailable.

Default pattern: ^(?:(?:[BV]?G)|Vulcraft) Joist Girder$. It matches G Joist Girder, BG Joist Girder, VG Joist Girder and Vulcraft Joist Girder.

Family requirements

Each parameter is read from the instance first and then from the type. Names match case-insensitively where the parameter is looked up by alias.

Input Parameter names Notes
Number of joists (N) Number of Joists, SpaceNum, Number of Equal Spaces Must be greater than 1.
Length Cut Length, then Length Must be greater than 0.
Depth Depth Must be greater than 0.
Panel point load Parameters matched by the load patterns See Load resolution.
Output Wt A writable Double parameter, on the instance or the type.

Numeric inputs may be Double, Integer or text. A text value has to parse as a number.

Load resolution

Load parameters are found by matching their names against the three load patterns. Matching parameters are collected from the instance and the type.

Pattern Default Matches, for example
Dead Load (?:^DL$\|Dead\s*Load) Dead Load, DL
Live Load (?:^LL$\|Live\s*Load) Live Load, LL
Total Load (?:Point\s*Load\|Total\s*Load) Point Load, Panel Point Load, Total Load

The load is resolved as follows:

  1. A negative value in any load parameter skips the girder as invalid.
  2. More than one parameter with a value in any one group (Total, Dead or Live) skips the girder as ambiguous. This check comes first: one Total Load value plus two Dead Load values skips the girder.
  3. If exactly one Total Load parameter has a value, it is the panel point load.
  4. Otherwise, if exactly one Dead Load and exactly one Live Load parameter have values, their sum is the panel point load.
  5. Otherwise the girder is skipped.

A single Total Load value takes precedence over single Dead and Live values.

Load values are converted to kips. A Force parameter is converted from its stored unit. A number with no unit is taken as kips. Text values accept a number followed by an optional unit: kip, kips, k, lb, lbs, lbf, pound, pounds or kN (for example 10 kips, 10000 lb, 45 kN).

To use other parameter names, such as localized names, change the patterns in the settings.

Settings

Open DB Tools > Settings and select the Joist Girder Weights pack.

Setting Default
Auto-Update Enabled On
Family/Type Name Pattern ^(?:(?:[BV]?G)\|Vulcraft) Joist Girder$
Dead Load Pattern (?:^DL$\|Dead\s*Load)
Live Load Pattern (?:^LL$\|Live\s*Load)
Total Load Pattern (?:Point\s*Load\|Total\s*Load)

An empty pattern field uses the default. A pattern that is not a valid regular expression is reported as a configuration error. In that case the manual command shows the error as a warning banner for 10 seconds and changes nothing. Auto-update shows the same banner and raises the tool warning Joist Girder Weights Disabled, which disables the command until you clear the warning in the settings.

Calculation

The estimate uses N joists (N - 1 panels), panel point load P (kips), length L and depth D, in inches:

  • panel spacing = L / N;
  • maximum moment from the end reaction P(N - 1)/2, less the moments of the panel loads between the support and midspan;
  • chord force = moment / (0.95 D);
  • required chord area = chord force / (50 ksi x 0.6);
  • top chord weight = area x L x 0.28356 lb/in^3 x 1.06;
  • bottom chord weight = 1.13 x top chord weight;
  • web weight = 0.7 x top chord weight;
  • Wt = (top + bottom + web) / (L in feet), in lb/ft.

The value is written to Wt as a number, without a unit conversion.

Result

The manual command writes all valid girders in one transaction named Auto Update Joist Girder Weights. A girder that fails validation is skipped, and the rest are updated. The banner shows:

Candidates: <n>
Updated: <n>
Skipped: <n>

Sample skipped element(s):
- Element <id>: <reason>

The sample list holds up to 5 skipped girders. The banner is a success banner when nothing was skipped, a warning when some girders were skipped, and informational when none were updated. No joist girders were found. appears when no element matches the family pattern.

Press Ctrl+Z to undo a manual run.

Limitations

  • The tool writes only Wt. It changes no other parameter.
  • The calculation uses a fixed allowable stress and fixed efficiency factors. Check the results against manufacturer data for final design.
  • Auto-update runs on every view activation and reads every matching girder. It adds delay in models with many girders.
