Update Joist Girder Weights

NAME

Update Joist Girder Weights - estimate the weight of each joist girder and write it to Wt

SYNOPSIS

dbtools > Structural > Update Joist Girder Weights

DESCRIPTION

The tool estimates the self-weight of each joist girder in the model, in pounds per foot (lb/ft). It writes the estimate to the girder's Wt parameter and changes nothing else.

A joist girder is a Structural Framing element whose family name matches Family/type name. By default, these are the families G Joist Girder, BG Joist Girder, VG Joist Girder and Vulcraft Joist Girder.

The estimate uses four values of the girder: Length, Depth, Number of Joists and the point load. The point load is the load, in kips, at each panel point where a joist bears on the girder. The tool works on the whole model. It skips a girder with a missing or invalid value.

REQUIREMENTS

For each value, the tool tries each listed name on the girder, then on its type, and uses the first value found.

Value Parameters Rule
Number of Joists Number of Joists, SpaceNum, Number of Equal Spaces Must be more than 1. Enter the number of equal spaces, not of joists.
Length Cut Length, Length Must be more than 0.
Depth Depth Must be more than 0.
Point load Parameters that match the load patterns See Loads.
Weight Wt An editable Number parameter. The tool writes lb/ft here.

Text values for the first three must be plain numbers. Length and Depth are in feet. A parameter of type Length works in any display units. In a Number or text parameter, enter 48 in. as 4.

Loads

A populated total load sets the point load, including an explicit zero. Otherwise, the tool adds the dead and live loads if both groups have inputs and at least one group has a value. The load patterns in SETTINGS find each kind by parameter name. The tool skips the girder when two usable inputs of one kind have values, when a Force load is negative, or when no usable load exists.

The tool reads Revit Force parameters and converts their values to kips. It also reads nonnegative loads from Text parameters. A plain number means kips. Text accepts k, kip, kips, lb, lbs, lbf, pound, pounds, or kN. Use a decimal point and optional commas for thousands. Examples include 10, 10 kips, 10,000 lb, and 45 kN.

The tool ignores matching parameters of other types, including Yes/No, Number, and Family Type. It also ignores invalid load text. If no load resolves, the skip message names each ignored match and its reason and shows any invalid text.

The tool ignores a blank total. A dead or live load group with only blank Force or Text inputs counts as zero if the other group has a value. A Dead Load of 2 kips and a blank Live Load give 2 kips.

An instance load input takes precedence over a type input with the same name, even when blank.

SETTINGS

Open dbtools > Settings, expand Structural Settings and find Joist Girder Weights.

Auto Update Joist Girder Weights runs without a banner when you open or switch to a view after a model or pattern change. It runs once when you first activate a view in a document. It is on by default. To see what it skips, run the tool from the ribbon.

The four patterns are .NET regular expressions. By default, the load patterns match DL, LL, and names that contain Dead Load, Live Load, Point Load or Total Load.

Family/Type Name   ^(?:(?:[BV]?G)|Vulcraft) Joist Girder$
Total Load         (?:Point\s*Load|Total\s*Load)
Dead Load          (?:^DL$|Dead\s*Load)
Live Load          (?:^LL$|Live\s*Load)

RESULTS

A run from the ribbon ends with a banner like this:

Candidates: 12
Updated: 8
Unchanged: 2
Skipped: 2

Sample skipped elements:
- Element 412345: Depth must be > 0.
- Element 412377: Number of joists must be > 1.

Candidates is the number of joist girders found. Unchanged counts girders whose weight already matches the calculation. The banner lists up to 5 skipped girders, with the first problem of each. Find each girder with Manage > Select by ID, fix it, and run the tool again.

Each run that changes values is one Undo step: Auto Update Joist Girder Weights.

MESSAGES

Message Meaning and what to do
Required writable Double parameter 'Wt' not found. Add Wt as an editable Number parameter.
Missing required input for 'Point Load'. … The tool lists missing or blank loads and explains which matching parameters it ignored. Supply a total or a dead and live pair with at least one value. Use Force or Text parameters.
Ambiguous <kind> Load inputs: … More than one parameter of that kind has a value, including any explicit zero. Clear all but one.
Joist Girder Weights Disabled (a warning in Settings) Correct the pattern and click Validate to dismiss a draft warning. Save Settings keeps the corrected pattern. After correcting the cause of a session warning, click Clear to re-enable updates.
Auto-update failed; disabled for this document session. Auto-update stays off until you reopen the model.

LIMITS

  • The weight is an estimate from a fixed formula, not from SJI or manufacturer tables.
  • Make Wt an instance parameter. A type parameter gives all girders of that type one value.
  • A Wt with units, such as Length, shows a wrong value.

EXAMPLES

To also use the family Acme Girder, set Family/type name to this value and click Save Settings:

^(?:(?:[BV]?G)|Vulcraft) Joist Girder$|^Acme Girder$
