Super Girt Tool

NAME

Super Girt Tool - place girts, headers, sills and jambs on one wall

SYNOPSIS

dbtools > Structural > Super Girt Tool

To change a placed system, select one of its members, then click Modify | Structural Framing > Super Girt > Edit SGT Wall.

DESCRIPTION

Super Girt Tool (SGT) frames one straight wall with horizontal girts. At each opening, it can add a header, a sill and two jambs. It stores the configuration with the members for later edits.

The framing band is the height range for girts. It runs from the bottom to the top of a linked wall. On a host foundation wall, it runs from the foundation top to 20'-0" above it. SGT ignores openings in a host foundation wall. SGT shows member elevations from the system's Reference Level.

  1. Click Super Girt Tool and pick a straight wall in a linked model. Press Esc at that prompt to pick a straight foundation wall in the host.
  2. SGT opens the window and analyzes the wall. It adds girt rows at the base and at each 5'-0" interval within the framing band. With Live Preview on, the progress overlay stays open until the Elevation preview is ready. With Live Preview off, startup keeps the current view and finishes without waiting for the preview. Click Cancel to close SGT without changes. If the preview fails, the window stays open and reports the error.
  3. Change the rows and openings. The preview shows the result.
  4. Click Place. SGT places the members and closes the window.

OPTIONS

Type a length as decimal feet (7.5), feet and inches (7'-6 1/2") or inches (18"). A number without a mark is in feet.

Layer
The exterior face of this wall layer sets the framing line for any wall Location Line setting. The default is the most-exterior structural layer. If none exists, SGT chooses the thickest non-finish layer, or the thickest layer when all are finishes. Ties favor the exterior layer. With no layer data, the selector is disabled and shows No layer data.
Offset
The distance from the selected layer's exterior face to the framing line. A positive value moves the line toward the exterior. The default orientation seats the section at this plane and keeps the steel on the interior side. The back of an angle girt's long leg sits flat on this plane and faces the exterior. Its short leg is at the bottom and points toward the interior. The toes of a channel jamb point away from the opening.
Reference Level
Choose the Revit level for a new system. Place and Update use that level for every new girt, header, sill, and jamb in the system. After placement, the picker shows the system's level and is disabled. To change it, delete the system and place it again. The list shows host levels from highest to lowest. Dropdown heights measure from the project base point. A level whose type uses the Survey Point elevation base can show a different height in its level head. The list marks the initial selection and wall base level. When you change the selection and click Place, SGT remembers the pick for new systems in that project. Walls on another datum or more than 8'-0" from the project datum use their own level by default. Changing the picker refreshes the elevation numbers in both grids. The framing geometry stays in place.
Girts
Each row is one girt at one Elevation, with a Girt Type. When you choose a type of another family, SGT replaces Rotation, Y Justification, Z Justification and Flip with the defaults of that family. To add a row, enter Elevation next to Add Girt and click Add Girt. The editable Elevation column and the Add Girt input measure from the system's Reference Level. The column names that level, for example Elevation from FFE.
Openings
On a linked wall, SGT detects doors, windows and wall openings. A linked wall without openings is valid and starts with an empty Openings grid. If SGT cannot read a supported opening, analysis stops with [SpecFail/OpeningQuery/Incomplete]. Check the wall or insert named in the detail. Add Opening adds one by hand. Center Along is the distance from the wall's left end in the exterior view to the opening center. The grid lists openings from left to right in that view. An opening keeps its default name when it moves to a different position in the grid. The Left Jamb, Right Jamb, Header and Sill boxes turn each member on or off. Bottom Elevation measures from the system's Reference Level and sets the sill and lower jamb ends. Height sets the distance to the header and upper jamb ends. Add Opening places the new opening's left edge at the wall's left end.

A girt is split at each opening that it crosses. Click the chevron of a split row to edit each segment.

To change one column across several rows, select the rows in that grid and commit the edit in one selected row. Elevation in Girts and Center Along in Openings affect only the edited row. A girt elevation applies when you commit the cell or leave the field. When you edit several openings, their changes apply when you commit the row. Held and unframed openings are read-only. Commit or cancel the current opening row before adding, duplicating or deleting rows.

Right-click a row to duplicate or delete it. The Girts row menu also moves rows and inserts a row below. On an Openings row, use Jamb Segments to add or remove a jamb segment.

The default gap between a jamb face and the end of a header, sill or girt is 1/2".

Each jamb extends to the nearest girt that reaches it above and below the opening. At an end with no such girt, the jamb extends to the wall limit. Extend a jamb past its default end to split the added length at girts it crosses. At each split, the two jamb ends clear the girt faces by 1/2". SGT leaves the jamb in one piece at the joint when either member ends at the other. If the next jamb piece would be shorter than 6", the jamb ends 1/2" before the girt face. The preview reports a shortened extension and uses the selected target to recalculate the end when the girt changes.

Bulk Edit

Double-click a row to open Bulk Edit for that row and the other selected rows. Use Target Roles to choose the member roles, then check Apply for each field to change. Use the Flip switch to choose its value. Apply (N) counts the checked fields.

Preview

The preview has an Elevation, a Section and a 3D mode. Elevation shows the wall from the exterior, so the wall start is at the right. Left Jamb and Right Jamb are left and right in this view. The horizontal dimension of the selected opening shows Center Along from the wall's left end.

Drag the dashed blue section marker in Elevation to move the Section cut. It snaps along the wall in 6" steps. The blue band runs up to 2'-0" to the left of the marker. Section shows members that intersect this band, with the exterior face on the left.

In Elevation, drag a member's end handle to a grid line, an opening edge, a wall edge or another member. A drag that ends elsewhere changes nothing. Double-click an end handle to type the gap at that end. An inner end of a split girt can move within the solid span between two opening edges or between an opening and a wall end. A grid must leave at least 6" of span and clear the adjacent jamb flange by 1/2" at the grid line. A typed gap adjusts the end from that line. Changes to wall or opening geometry or framing, grids, girt elevations or extents, or jamb types, orientations or extents can make a saved grid unsuitable. SGT reports when it drops the grid and uses the opening edge and its gap for the split. A short outer pier keeps its anchor and gap so it can return when there is room.

Right-click a girt segment in the preview to delete it or merge it with an eligible neighbor. Right-click an opening member to delete its segment. Deleting the last segment disables its role. If no role stays enabled, SGT deletes the opening row.

With the Elevation preview focused, point near overlapping handles. Press Tab or Shift+Tab to cycle, Enter to select or Esc to clear.

If a girt loses an anchor, SGT moves that end to an opening or wall edge and clears the old gap override. It can merge overlapping segments. Check the affected ends in the preview before Update.

Undo and Redo apply to Wall Offset, wall layer, committed grid edits, Bulk Apply, segment flyout edits, opening segment commands, and preview edits. Each action takes one step, even when it changes several rows. Commit or cancel an active opening row and fix invalid fields before using Undo or Redo. Running wall analysis or clicking Confirm in Change Review starts a new draft and clears both stacks. If another plan write supersedes the recorded state, SGT keeps the newer plan. It clears stale history when you try to apply or replay an edit. If SGT recovers from an error after a plan write, it keeps the accepted plan, clears the history, and keeps the window open. Complete or remove blank girt rows and fix invalid grid fields before changing Wall Offset or the wall layer. If a grid edit blocks the change, SGT keeps the rows and restores the accepted wall value.

REQUIREMENTS

Item Rule
Wall A straight, vertical wall in a loaded link, or a straight, vertical host wall whose type has the function Foundation.
Girt types Structural Framing types of editable families: C and MC channels, Z shapes, angles and HSS.
Opening types Channels and HSS only.
Girt end gaps Each girt end with a gap needs an extension parameter that can hold the gap value.

SGT knows a shape by the Structural Section Shape, Section Shape or Shape parameter, or by names such as C10X15.3, C Shapes or HSS. It skips a family or type whose name contains joist, girder or truss. SGT prefers C Shapes : C10X15.3 as the default girt type. If that type is not eligible, SGT selects another eligible type.

SGT uses a sample type to find default settings for a family. Square and rectangular HSS use separate samples. SGT checks the geometry of each type and solves that type directly if the family settings do not seat it. SGT measures visible steel solids and excludes solids with materials identified as non-steel. It also measures solids with unassigned or unrecognized materials. If every visible solid is excluded, the diagnostic lists the materials and their classes.

RESULTS

Place creates and tags the members. SGT writes the end gaps of each girt to its Start Extension and End Extension, as negative values. Place and Update check the extension limits for all girt segments before writing any members. Place, Update, and Review Changes commit the active opening row before continuing. A refused edit leaves the grid open for correction. Point to a disabled Place or Update button for the reason.

For an edited system, Update writes existing members with a changed curve or instance settings. It creates missing members and deletes extra members. It can also replace a matched member whose location is a bound arc with the straight member from the plan. The member must be editable, have the same family type, and have no tags, hosted elements, joins, or other model relationships. A matched spline, ellipse, unbound line, or other unsupported location stops Update with Update/LocationMissing.

SGT places the replacement on the system's Reference Level. It copies Mark, Comments, and IfcGUID, which preserves the member's IFC export identity. It checks that Y/Z offsets, opening member extensions, shared parameter values, and other editable instance values outside SGT's placement settings match. Revit recalculates values such as Exact Weight.

Update rolls back if a required value would change or Revit refuses a write. SGT can remove a stored duplicate Mark warning when it verifies that the warning belongs to the source member. When Update recreates a matched member, any Revit warning in the transaction also rolls it back. The only exception is a duplicate Mark warning that names the replacement and the other framing members that share its Mark. The failure reports Revit's warning text and identifies the affected members. Update without matched recreation uses the normal warning handling.

Update Summary lists Moved, Recreated, or Deleted for each change. A replaced member has both element IDs and the reason on its Recreated row. Delete System deletes the members and the configuration.

Cancel or closing the window rolls back the session.

Change Review

Change Review opens when you edit a system whose wall or openings changed in the model. Review Changes opens it at any time. Opening Start and End measure from the wall's left end in the exterior view. The review uses a tolerance of 1" for opening edges and opening elevations. The wall tolerance is 0.01 ft for endpoints, elevations and layer thicknesses.

When you accept a wall with a different base elevation, Move offers to keep each existing girt at the same height above the new base. Rows on the spacing grid follow the grid. Rows at custom heights keep those heights. The suggestion lists old and new elevations relative to the accepted base. After Move, Remove is available for any row above the new top. Keep or Ignore pauses the move. Return to Accept on the same wall to restore it.

If SGT infers spacing and the wall is taller, Add offers the next whole intervals after any move. SGT uses the girt gaps at the start of the review and ignores gaps under 6 inches. Rows added during the review keep their chosen height above the accepted base, including after Relink.

Decision Effect
Accept Use the changed geometry from the model. A complete scan that confirms a missing opening makes Accept schedule its framing for removal at Update.
Keep Keep the geometry of the last placement, or the values that you typed.
Ignore Leave the framing as placed. Change Review asks again next time.

When a wall or opening cannot be read, its review row offers Keep and Ignore. A row marked for deletion or already accepted for removal offers Accept and Keep.

Select an existing opening missing from the current observation, choose an unpaired live opening under Same as, then click Pair. Unpair undoes a pair made in this review. For a linked item, Locate selects the link instance in Revit.

Confirm saves the decisions and clears the window's Undo history. An information banner confirms the result. Click Update to apply the framing changes. Relink moves the system to another wall and offers a fresh Move if that wall changes the base elevation. Deconstruct removes the SGT data and keeps the members as plain framing.

MESSAGES

Message Meaning and what to do
[SpecFail/Calibration/NoEligibleFamilies] No eligible structural framing families found … No loaded family meets the REQUIREMENTS. Load one, such as C Shapes.
Profile warmup failed for <n> family types; … SGT cannot read the section of these types, so you cannot select them.
[SpecFail/Writer/ExtensionCalibrationMissing] SGT needs Start and End Extension calibration for this girt type. Select an eligible girt type and try again.
[SpecFail/Writer/ExtensionParamMissing] The girt type lacks the extension parameter for an end with a gap. Use another type, or set that gap to 0.
[SpecFail/Writer/ExtensionParamReadOnly] The extension parameter has a fixed value that differs from the required value. Use another girt type or change the gap.
[SpecFail/Writer/NoLevels] Place and Update require a level in the host project.
[SpecFail/Writer/ReferenceLevelMissing] The host level is unavailable. For Place, reopen SGT and select an available level. For Update, delete the system and place it again.
[SpecFail/Writer/ReferenceLevelSetFailed] Revit could not create the framing on the required Reference Level with the requested level offsets. SGT rolls back the write.
[SpecFail/Writer/LocationMismatch] Revit placed a member with endpoints or direction that differ from the plan. SGT rolls back the write.
[SpecFail/Update/ReferenceLevelChanged] The system's Reference Level was set at placement. Delete the system and place it again to change its level.
The project Reference Level pick could not be updated. SGT saved the framing and its Reference Level. The warning gives the reason the project pick could not be saved.
Removed SGT data for <n> systems. The old systems' members stay in the model as plain framing. Placing again on those walls can overlap the existing framing.
<action>: [<code>] <detail> An action failed. The detail gives the reason.

LIMITS

  • An opening splits each girt that crosses it, even with all four members off. To run a girt across, drag the girt's handle at one edge of the opening to the other edge. SGT joins the two pieces into one girt.
  • SGT leaves out a girt piece shorter than 6", with no message.
  • Update overwrites any Start Extension or End Extension value that you type on an SGT girt.
  • If you move or resize a detected opening, its Source becomes Manual, and SGT stops following the opening in the link.
  • A second Super Girt Tool run on a wall places a second system. To change a system, use Edit SGT Wall.
  • A copy of an SGT member keeps its SGT tag, so Delete System deletes it too.
  • If Place or Update fails, the window closes and all changes of the session are lost.
