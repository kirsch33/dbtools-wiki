Super Girt Tool

NAME

Super Girt Tool - place girts, headers, sills and jambs on one wall

SYNOPSIS

dbtools > Structural > Super Girt Tool

To change a placed system, select one of its members, then click Modify | Structural Framing > Super Girt > Edit SGT Wall.

DESCRIPTION

Super Girt Tool (SGT) frames one straight wall with horizontal girts. At each opening, it can add a header, a sill and two jambs. It stores the configuration with the members for later edits.

  1. Click Super Girt Tool and pick a wall in a linked model. For a foundation wall of the host model, press Esc at that prompt; SGT then asks for a host wall.
  2. SGT analyzes the wall and opens its window. It adds girt rows at the base and every 5'-0" above it.
  3. Change the rows and openings. The preview shows the result.
  4. Click Place. SGT places the members and closes the window.

Elevations are heights above the base: the bottom of a linked wall, or the top of a foundation wall. On a foundation wall, SGT frames a fixed band 20'-0" high above the foundation, and ignores the openings of that wall.

OPTIONS

Type a length as decimal feet (7.5), feet and inches (7'-6 1/2") or inches (18"). A number without a mark is in feet.

Layer
The wall layer that the members align to. The default is the most-exterior structural layer. If none exists, SGT chooses the thickest non-finish layer, or the thickest layer when all are finishes. Ties favor the exterior layer.
Offset
The distance from that layer, across the wall. A positive value moves the members toward the exterior.
Girts
Each row is one girt at one Elevation, with a Girt Type. When you choose a type of another family, SGT replaces Rotation, Y Justification, Z Justification and Flip with the defaults of that family. To add a row, type an elevation next to Add Girt and click it.
Openings
On a linked wall, SGT detects doors, windows and wall openings. Add Opening adds one by hand. Center Along is the distance from the wall start to the opening center. The Left Jamb, Right Jamb, Header and Sill boxes turn each member on or off.

A girt is split at each opening that it crosses. Click the chevron of a split row to edit each segment. Double-click a row to open Bulk Edit for that row and the other selected rows.

Preview

The preview has an Elevation, a Section and a 3D mode. Elevation shows the wall from the exterior, so the wall start is at the right. Left Jamb and Right Jamb are left and right in this view.

In Elevation, drag a member's end handle to a grid line, an opening edge, a wall edge or another member. A drag that ends elsewhere changes nothing. Double-click an end handle to type the gap at that end. The Undo and Redo buttons of the window apply only to these edits.

REQUIREMENTS

Item Rule
Wall A straight wall in a loaded link, or a host wall whose type has the function Foundation.
Girt types Structural Framing types of editable families: C and MC channels, Z shapes, angles and HSS.
Opening types Channels and HSS only.
Girt end gaps A girt with a gap needs the Start Extension and End Extension parameters.

SGT knows a shape by the Structural Section Shape, Section Shape or Shape parameter, or by names such as C10X15.3, C Shapes or HSS. It skips a family or type whose name contains joist, girder or truss. SGT prefers C Shapes : C10X15.3 as the default girt type. If that type is not eligible, SGT selects another eligible type.

RESULTS

Place creates and tags the members. SGT writes the end gaps of each girt to its Start Extension and End Extension, as negative values.

For an edited system, Update moves the existing members, creates the missing ones and deletes the extra ones. Update Summary then lists each change as Moved, Recreated or Deleted. Delete System deletes the members and the configuration.

Cancel or closing the window rolls back the session.

Change Review

Change Review opens when you edit a system whose wall or openings changed in the model. Review Changes opens it at any time.

Decision Effect
Accept Use the changed geometry from the model.
Keep Keep the geometry of the last placement, or the values that you typed.
Ignore Leave the framing as placed. Change Review asks again next time.

Confirm saves the decisions and changes no framing; click Update afterward. Relink moves the system to another wall. Deconstruct removes the SGT data and keeps the members as plain framing.

MESSAGES

Message Meaning and what to do
[SpecFail/Calibration/NoEligibleFamilies] No eligible structural framing families found … No loaded family meets the REQUIREMENTS. Load one, such as C Shapes.
Profile warmup failed for <n> family types; … SGT cannot read the section of these types, so you cannot select them.
[SpecFail/Writer/ExtensionParamMissing] Start/End Extension parameters are required for endpoint gaps. A girt with a gap has no extension parameters. Use another type, or set the gap to 0.
<action>: [<code>] <detail> An action failed. The detail gives the reason.

LIMITS

  • An opening splits each girt that crosses it, even with all four members off. To run a girt across, drag the girt's handle at one edge of the opening to the other edge. SGT joins the two pieces into one girt.
  • SGT leaves out a girt piece shorter than 6", with no message.
  • Update overwrites any Start Extension or End Extension value that you type on an SGT girt.
  • If you move or resize a detected opening, its Source becomes Manual, and SGT stops following the opening in the link.
  • A second Super Girt Tool run on a wall places a second system. To change a system, use Edit SGT Wall.
  • A copy of an SGT member keeps its SGT tag, so Delete System deletes it too.
  • If Place or Update fails, the window closes and all changes of the session are lost.
