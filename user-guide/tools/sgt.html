Super Girt Tool (SGT)

The Super Girt Tool places horizontal girts and opening framing (headers, sills and jambs) on one wall in one operation. You configure every girt row and opening of the wall in one window, check the result in a 2D and 3D preview, and place all members together. SGT stores the configuration with the members, so you can edit, update or remove the system later.

Use SGT to:

  • add girts to a host foundation wall or a wall in a linked model;
  • frame doors, windows and penetrations with headers, sills and jambs;
  • keep girt spacing and alignment consistent along a wall;
  • edit or update a girt system placed earlier.

Quick start

  1. On the DB Tools ribbon tab, Structural panel, click Super Girt Tool.
  2. Select a wall in a linked model, or a host foundation wall.
  3. Check the girt rows and openings that SGT proposes, and change them as needed.
  4. Click Place.

SGT computes rotation, justification and position from the selected framing types and the wall.

The SGT window

Wall setup

Control Purpose
Offset Distance from the selected layer plane along the wall depth. 0 places the girt's exterior flange on the layer face; positive values move girts outward, negative values inward.
Layer The wall layer plane that girts align to, for compound walls. The default is the most-exterior structural layer; without one, the thickest non-finish layer, or the thickest layer when all layers are finishes. Ties prefer the exterior layer. The list shows the layers of the analyzed wall and follows the current plan, also when the preview cannot update.

Girts

Each row is one girt at one elevation.

Column Purpose
(chevron) Opens the segment flyout of a segmented girt
Elevation Height above the plan base
Girt Type Structural framing family and type, for example C Shapes : C10X15.3
Rotation Cross-section rotation: 0°, 90°, 180° or 270°
Y Justification Lateral justification: Left, Center, Right or Origin. The Revit Y offset stays zero.
Z Justification Vertical justification: Top, Middle, Bottom or Origin. The Revit Z offset stays zero.
Flip Revit Flip Facing. Available only when the type supports facing flips, as found during analysis.

To add a girt, type an elevation in the field next to Add Girt and click Add Girt. The row context menu has Move Up, Move Down, Add Row Below, Duplicate Selected and Delete Selected. Select several rows to edit them together.

A girt is split at each opening it crosses, unless it bypasses the opening. A girt split in this way shows a chevron in the first column. Click it to open the segment flyout, where you edit Type, Rotation, Y, Z and Flip of each segment, or delete a segment. The selected segment is highlighted in the preview. The flyout opens to the right of the chevron, centered vertically in the window; resizing widens mainly the Type field. The background is dimmed lightly, so the preview stays visible. When opening edits merge the segments back into one, the chevron goes away.

Openings

In linked mode, SGT detects the openings of the linked wall; you can also add manual openings. In host foundation mode, SGT ignores the openings of the Revit wall, and the grid contains only openings you add with Add Opening.

Column Purpose
Opening Name of the opening
Source Live (detected) or Manual
Center Along Distance along the wall from the wall start
Bottom Elevation Distance from the plan base to the bottom of the opening
Width, Height Rough opening size
Left Jamb, Right Jamb, Header, Sill Turn the framing member on or off

Opening members (headers, sills and jambs) use Channel or HSS types only. Zee and L-Angle types are for girts only and are not offered for opening roles.

The chevron of an opening row opens the segment flyout for its members: role-level Type, Rotation, Y, Z and Flip and, when a role is segmented, one child row per segment. It behaves like the girt segment flyout.

Opening row edits are drafts. While you edit Center Along, Bottom Elevation, Width, Height or a role checkbox, the preview shows the last committed plan. Leave the row or press Enter to commit the row, which re-segments and refreshes the preview once. Esc cancels the draft (see the limitation below). If you turn on a role and change its Type, Rotation, Y, Z or Flip before you leave the row, the commit keeps those settings. An invalid row stays in edit mode, and the last committed plan stays, until you fix the highlighted fields or cancel.

When analysis of a linked wall finds no openings, SGT shows an information banner, removes stale detected rows and keeps manual openings.

Saving edits together

An opening commit, a segment flyout edit and a preview edit (snap, gap, delete, merge) each save your other unsaved field edits in the same step; for example, a wall offset you typed just before you clicked another opening row, or a field you changed while the 3D preview was building.

While any wall setup, girt or opening field is invalid, SGT refuses such an edit and writes nothing:

  • the opening row stays in edit with its values;
  • the gap editor stays open with the typed gap, also when the preview redraws, until you press Enter again or Esc;
  • a refused flyout choice shows the saved value again;
  • your other unsaved field edits stay;
  • the preview status shows the reason: Fix invalid fields, Fix invalid rows or Preview blocked.

Deleting girt rows in the grid, also an invalid row, is never refused. The next sync renumbers the segment group of the deleted row; a group left with one row becomes a plain girt.

Undo and Redo

Undo and Redo apply to preview edits: drag and snap edits of girt and opening-member handles, typed gap changes, segment deletes and merges. Undo of a typed gap restores the previous override. An accepted typed gap change clears the redo history. Undo and Redo restore the whole plan, so they also replace unsaved field edits, including an invalid field.

Bulk edit

Double-click a row in either grid to open the Bulk Edit flyout. It is an overlay inside the SGT window, so it stays with the window when you minimize and restore it.

  • Targets: the member roles the operation applies to (Girt, Left Jamb, Right Jamb, Header, Sill).
  • Flip: three states; the indeterminate state leaves Flip unchanged.
  • Apply (N): applies the N selected fields (Type, Rotation, Y, Z, Flip). Ctrl+Enter applies; Esc closes.

Preview

The preview on the right shows what SGT will place.

Mode Content
Elevation Front view of girts and openings
Section Cross-section with horizontal member profiles and jamb depth bands. See Section preview.
3D Interactive 3D view

The Role Palette shows the role colors: Girt blue, Header green, Sill orange, Left Jamb purple, Right Jamb cyan. In Elevation and Section mode the legend also shows segment types.

The mode selector, Zoom to fit and Reset view are at the top right of the preview.

  • Entering 3D, and Reset view, show the exterior home camera: a three-quarter view with a slight downward pitch, also for mirrored or rotated links. Other updates keep your camera.
  • Wheel zoom allows close inspection. Pan and orbit stop on mouse-up and when the window loses focus.
  • Click an element in 3D to select it (gold highlight) and show a tooltip with its role and section name. A click selects on mouse-up; a drag pans. Clicking a wall layer shows layer information and keeps the selection. Clicking empty space clears the selection. When a segment is selected, the other segments of the same member are dimmed slightly and unrelated elements fully.
  • Section shows compound wall layers as labeled thickness bands and highlights the selected layer. 3D shows wall layers as faint context geometry with the selected layer emphasized, thin outlines of all detected openings and a transparent floor plane.
  • Text, line weights and styling use a fixed visual scale; hit testing (snap thresholds, hit radii) follows the display scaling.
  • Grid markers in Elevation are white bubbles with black labels.
  • Elevation, Section and 3D show the same member positions, orientations and segment order that Place and Update write. Profiles in the preview come from temporary instances placed during analysis, with rotation applied first, then Flip, then justification, like placed members.
  • On a wall that is not at a right angle to the project axes, jambs are analyzed and placed with a small rotation correction; the Rotation column still shows 0, 90, 180 or 270.

Editing in the preview

Drag handles in the Elevation preview to change girt and opening-member extents.

  • Handles snap only to valid associations: other members, grid lines, opening edges and wall edges. There is no free position along the wall. A drag commits only when it ends within snap distance of an accepted target; until then the border and guide show the invalid state.
  • While you drag, available targets show as dim bands and the active guide as a line: cyan when valid, red when invalid.
  • When several handles overlap, press Tab to cycle them (Shift+Tab reverses), Enter to confirm and Esc to cancel.
  • Openings have no drag handles; edit their geometry in the grid.
  • Segmented opening members have handles per segment; dragging one moves that segment's extent.
  • On a girt split by openings, only the outer endpoints (the start of the first segment and the end of the last) move the girt's extents. The other segment endpoints edit opening-edge gaps; they are identified by opening and edge, so mirrored or rotated links do not move the opposite endpoint.
  • An opening's lower edge is the edge nearer the wall start; its higher edge is nearer the wall end. A girt's start snaps to the higher edge, and its end to the lower edge, of an opening that crosses the girt. For a girt inside one opening, the start snaps to the lower edge and the end to the higher edge. Edges of an opening the girt bypasses are offered too; snapping to one clears the bypass. An edge that would leave the girt no span of at least 6" (0.5 ft) is not offered. A snap to an edge that cannot bound that end fails with GirtSnap/BoundaryInvalid; a snap that leaves no usable span fails with GirtSnap/NoUsableSpan.
  • Dragging an interior endpoint of a split girt to the opposite edge of the same opening joins the segments into one girt that bypasses the opening.
  • Jamb, header and sill handles, and girt segment handles other than the girt's own start and end, are offered all eligible opening edges in the preview, not only those of the selected opening row.
  • Snapping a girt endpoint to a new association clears the gap override of that endpoint and edge, so the default gap for the new association applies.
  • Merging adjacent girt segments re-targets opening-member extents that referenced either segment to the merged segment.
  • Right-click a segmented opening member to delete that segment. Row delete commands appear in the row menu. Deleting the last segment of a role removes the role; the opening row stays until all its roles are removed.

Gaps and segmentation rules

  • A girt whose start is on an opening's lower edge and whose end is on the same opening's higher edge lies inside that opening. Every other girt is split at each opening it crosses, unless it bypasses the opening.
  • An opening splits girts even when all its framing roles are off.
  • Girt pieces shorter than 6" (0.5 ft), for example a narrow pier between two close openings, are left out of the preview and of placement. A girt with no piece of at least 6" cannot be placed.
  • A girt end at an opening edge gets the gap of the jamb at that edge, or 0 when there is no jamb. A girt end on a wall edge or grid line that lies exactly on the edge of an opening the girt stops at also gets that edge's jamb gap. A gap override you set replaces the default.
  • Gap override fields reject NaN and Infinity; negative values are allowed. Invalid overrides fail plan validation before placement.
  • When the opening or grid line a girt end was attached to is removed, or the opening no longer crosses the girt (after an opening edit or a shorter wall), SGT moves that end to the nearest opening edge at least 6" from the girt's other end, or to the wall edge, and clears that end's gap override. A gap override of the edge it moves to is kept. The banner reports Re-anchored N girt end(s) to the nearest opening or wall edge. When two segments of one girt then overlap, SGT merges them into the first, and the banner also reports Merged N overlapping girt segment(s) into their neighbors.
  • When re-segmentation leaves fewer than two segments in a group, SGT turns the group back into one row and shows a banner with the number of groups collapsed.
  • If a geometry-based gap cannot be computed (a missing profile or a transform failure), SGT reports an error. Reopen SGT to analyze the wall again.

Commands

Button Action
Cancel Close without placing or updating. Rolls back every model and storage change made in the window.
Place Create all configured members (new system).
Update Edit mode: update the existing members.
Review Changes Edit mode: open Change Review.
Delete System Edit mode: delete all elements tagged with the system ID, including tagged copies, and the stored system.

Place and Update are disabled when there is nothing valid to place; the tooltip gives the reason.

Workflows

Create a girt system

  1. Click Super Girt Tool.
  2. Select a wall in a linked model or a host foundation wall. SGT analyzes the wall and fills the window.
  3. Check the seeded girts. SGT seeds girt rows at 5'-0" spacing. Change elevations and types as needed.
  4. Configure openings. In linked mode, openings are detected. In foundation mode, click Add Opening for each opening. Turn the framing roles on or off.
  5. Check the layout in Elevation, Section and 3D.
  6. Click Place.

Enter elevations and offsets

Elevation and offset fields accept:

  • decimal feet: 7.5;
  • feet with an apostrophe: 7';
  • feet and quoted inches: 7'-6", 7'-6 1/2";
  • quoted inches: 18", 6.5", 6 1/2".

Spaces are allowed around the marks, the hyphen and the fraction slash. One leading + or - applies to the whole value, for example -6 1/2". Unit names (ft, in, metric units), localized decimal commas, exponents, signs on components, unquoted fractions and trailing text are rejected.

Limit girts to grid lines

When grid lines cross the wall, drag a girt's start or end handle in the Elevation preview to a grid line. The end snaps to the grid, and the girt runs from that grid line. Drag it to the wall edge to return to the full length.

Configure opening framing

Member Typical use
Header Above most openings
Sill Below windows; often off for doors at grade
Left Jamb, Right Jamb Usually both on; turn one off when the opening is at a wall end

Edit an existing system

  1. Select a member of the system in Revit.
  2. On the Modify | Structural Framing tab, click Edit SGT Wall. The button appears only when SGT members are selected.
  3. Change the configuration in the SGT window.
  4. Click Update, or Delete System to remove it.
  • Opening rows show their source, Live or Manual. Editing the position or size of a live opening makes it Manual; its distance from the wall start stays fixed when the wall length changes.
  • A completed session is one Super Girt Tool Undo entry. Cancel, an error or a Dev Mode reload rolls back the session's model changes.
  • Update moves existing members in place. If a required member cannot be matched or moved, Update stops with an error; it does not delete and recreate members.
  • Place and Update set each girt's Start and End Extension from its end gaps (0 where there is no gap), so placed girts match the preview. Place and Update replace a family default extension, and Update replaces an extension typed on a placed SGT girt. If Update must change an extension whose parameter is missing or read-only, it fails and rolls back its changes.

Change Review

When an edited wall or opening differs from the stored observation, SGT opens Change Review before it writes the update; you can also open it with Review Changes. Each row shows the opening's source name (or Manual opening for an unnamed manual row), its source, its status and its decision. The details pane shows the effects of the selected row. Placement validation messages show the along-wall range of an opening outside the wall bounds.

Decisions:

  • Accept adopts the current live observation and applies its framing at the next Update.
  • Keep keeps the placed or manual geometry and framing for this session.
  • Ignore leaves the existing framing unchanged and asks again at a later review. An opening you edited in this session returns to its placed geometry and framing. A manual opening that was never placed stays unframed; choose Keep at a later review in the same session to frame it again. Update does not save an ignored manual opening that was never placed.

Saved live openings that are missing from a successful observation need a decision. An incomplete observation shows the opening as Unreadable and never deletes it. Without a live observation, a row offers only Keep and Ignore.

The review also lists wall and layer changes, remembered decisions, accepted removals that wait for Update, and girt ends that will be re-anchored.

  • Same as and Pair pair a missing live opening with a current opening. Unpair restores the previous pairing and its draft row. Locate selects the source element when it exists.
  • Relink picks a new wall for a system whose wall reference changed. SGT analyzes the selected wall and rebuilds the review draft before any decision is saved.
  • Delete System removes the stored system and its placed members. Deconstruct removes the stored system and the SGT tags and keeps the members in the model.
  • Confirm saves the review plan and decisions in the current session. It does not change Revit members; click Update afterward. Cancel closes the review without saving its decisions.

All of these run inside the session's transaction group: the main window's Cancel, an error or a forced close rolls them back, including a confirmed review. A successful window close keeps them as one Super Girt Tool Undo entry.

Unsupported stored data

An unreadable SGT payload fails with a typed storage error. If an owned storage entity or element tag uses an unsupported schema or format version, the session purges that entity and its SGT tags inside the transaction group, and also purges tags that point to a system that no longer exists. A successful close keeps the purge; Cancel, an error or a forced close restores it. Framing members are not deleted. After an unsupported-data message, place the system again.

Settings

Rotation

  • 0: default orientation (web vertical, flanges horizontal).
  • 90: rotated 90°.
  • 180: rotated 180° from the default.
  • 270: rotated 270° (-90°).

C-channels and I-beams used as horizontal girts usually use 0 or 180.

Y justification

  • Left: member shifted toward the wall start.
  • Center: member centered on the placement line.
  • Right: member shifted toward the wall end.
  • Origin: the family origin.

Z justification

  • Top: top of the member at the elevation.
  • Middle: center of the member at the elevation.
  • Bottom: bottom of the member at the elevation.
  • Origin: the family origin.

Debug logging

With Debug mode on, SGT writes summaries instead of one line per probe:

  • Analysis steps 1 to 3 report total, success and failure counts.
  • Opening detection and merge logs are summarized, with a small sample of openings.
  • Orientation analysis writes one Debug summary per role, with the probe details folded in.
  • Temporary probe transactions log only when they captured diagnostics. Blocking probe failures are logged as warnings or errors, and the family or type is named in the analysis results.

Limitations

  • SGT supports straight walls only.
  • Girts do not follow later wall changes. Edit the system and click Update, or delete it and place it again.
  • If you save the window (by fixing another field or making another edit) while an opening row is still in edit, the row's draft is written too. Esc then shows the old values in the row, but the plan keeps the draft, and a later refresh can show it again.
  • A gap handle of an opening you just deleted can remain on the canvas until the preview redraws. Double-clicking it shows a Gap edit failed banner instead of a gap editor.
  • A header or sill split position outside the wall makes Place or Update fail with a message that names the opening.
  • A girt segment that cannot be placed reports its own failure, with the same text for Place and Update. For example, a girt family without Start and End Extension parameters reports Writer/ExtensionParamMissing when an end gap needs them. A missing opening framing type reports Plan/EligibleOpeningTypesMissing.
  • Placement validation failures are reported before any change. Unexpected Revit faults during placement are reported through the tool's error handling with their original cause.

Troubleshooting

"No structural framing families found"

The project has no structural framing family. Load at least one (for example C Shapes or W Shapes) before you start SGT.

Girts are not where you expect

  1. Check Layer: girts align to the selected layer plane.
  2. Check Offset.
  3. Check Rotation and the justifications, and look at the 3D preview.

The preview shows nothing

  1. Make sure at least one girt row exists with a valid type.
  2. For openings, make sure at least one role is on.
  3. Close and reopen SGT to analyze the wall again.

Place is disabled

There is nothing valid to place. Add a girt row, select a type for each row and make sure every elevation is valid. The button's tooltip gives the reason.

Openings are not framed

The roles were off, or the opening was not detected. Edit the system, turn on Header, Sill, Left Jamb or Right Jamb, and click Update.

Members have the wrong orientation

  1. Toggle Flip for the row.
  2. Change Rotation (0, 90, 180, 270).
  3. Adjust Y Justification and Z Justification.

If the preview still looks wrong after you change row settings, close and reopen SGT so the wall and openings are analyzed again before you place.

Cannot edit an SGT system

Select a member that SGT placed. When several SGT systems exist on different walls, select a member of the wall you want to edit.

Edit mode reports incompatible stored data

The stored payload does not match the current SGT data format. Delete the system and place it again, so SGT writes a current payload.

Supported framing

Standard structural framing families: C Shapes (channels), MC Shapes, HSS and angles. Zee and angle shapes are for girts only, not for opening framing. Each girt row is independent, so different elevations can use different types. Types that analysis found unusable cannot be selected.
