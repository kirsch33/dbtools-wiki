Allow Join and Disallow Join

The Allow Join and Disallow Join commands (the Framing Joins tool) allow or disallow joins at both ends of the selected structural framing elements. Revit joins a beam or brace to the column or framing it meets and cuts the geometry accordingly. The tool sets that behavior for many members in one operation.

Synopsis

Ribbon: DB Tools > Structural > the Allow Join / Disallow Join split button.

Command Effect
Allow Join Allows joins at both ends of each selected framing member.
Disallow Join Disallows joins at both ends of each selected framing member.

The top part of the split button runs the current command. The arrow lists both commands.

Availability

Both commands are enabled when the selection contains at least one element of the Structural Framing category. The commands are disabled when nothing is selected or when no selected element is structural framing.

Usage

  1. Select the framing members. Use a selection box, Ctrl+click, or a Revit selection filter.
  2. Run Allow Join or Disallow Join.
  3. Read the confirmation banner.

Selected elements that are not structural framing are ignored. Only family instances of the Structural Framing category (beams, braces and joists) are changed. Columns and other categories are not.

Result

The command is one undo entry named DB Tools - Allow Join Selected or DB Tools - Disallow Join Selected. It sets both ends (end 0 and end 1) of each member. A confirmation banner shows Allowed joins on N element(s). or Disallowed joins on N element(s). for 3 seconds. N counts the members processed, including members that already had the requested state.

If Revit rejects the change on any member, the command stops, reports Failed to apply allow join operation for element <id>. (or disallow) and changes nothing. No member keeps a partial change.

The information banner No elements were modified. appears for 5 seconds when no member was processed.

Press Ctrl+Z to undo a run in a single step.

Limitations

  • The command sets both ends together. To set the ends differently, use the end-join controls in Revit.
  • Structural columns are a separate category and are not changed.
