Allow Join and Disallow Join

NAME

Allow Join, Disallow Join - allow or disallow joins at both ends of framing

SYNOPSIS

DB Tools > Structural > Allow Join or Disallow Join

DESCRIPTION

The two commands share one split button. Allow Join allows joins at both ends of each selected Structural Framing element, such as a beam. Disallow Join disallows joins at both ends.

  1. Select the framing. The commands are enabled when the selection holds at least one Structural Framing element.
  2. On the split button, click Allow Join or Disallow Join.
  3. Read the banner.

RESULTS

A run changes only the Structural Framing elements in the selection. It ignores all other elements, such as structural columns, and does not report them.

The banner shows Allowed joins on <n> element(s). or Disallowed joins on <n> element(s). The count <n> includes elements that had that join state already.

Each run is one Undo step: DB Tools - Allow Join Selected or DB Tools - Disallow Join Selected.

MESSAGES

Message Meaning and what to do
Failed to apply allow join operation for element <id>. Revit refused the change for that element. The run stops and changes nothing. The message says disallow for Disallow Join. Find the element with Manage > Select by ID.

LIMITS

  • A command always sets both ends of each element. It cannot set one end only.
