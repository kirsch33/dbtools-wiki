View Template Comparer

View Template Comparer (VTC) compares two view templates in the open project, side by side. For each differing setting you choose which template's value to keep. VTC then writes the result to one of the templates or to a new merged template. It can also save templates to a library and load them back.

Synopsis

Ribbon: DB Tools > Testing > View Template Comparer.

The Testing panel is shown when Enable Testing Tools is on in the settings (the default). If the project has no view templates, the command shows No view templates found in the document.

Usage

  1. Select the Left and Right templates. The Swap button exchanges them.
  2. Click a value cell in the Settings Comparison tree to choose which side wins for that row. The Inspector has Use Left, Use Right and a clear button for the selected row.
  3. For a category row, use Edit Left or Edit Right (in the Inspector, from the row, or from the context menu Edit Override...) to stage a local graphic-override edit. A staged edit is marked Edited.
  4. Review the selected rows and eligible staged edits in the Preview tab.
  5. Click Process and choose the target.

Comparison tree

The tree has these top-level groups: Template Parameters, Model Categories, Annotation Categories, Analytical Model Categories, Imported Categories, Filters, Filter Overrides, Revit Links, Worksets and Design Options.

Control Effect
Search box Filters rows by name.
Filter Limits the rows by configuration (see below).
Select Left / Select Right Selects all differing rows shown by the current search and filter, taking the value from that side.
Wipe Clears all selections and conflict state. Filters are kept.
Reset Resets the search, the view filter and the conflict filter.
Expand/collapse button Expands or collapses all groups.
Show: All, Conflicts, Success After Process, shows all rows, only rows that failed to apply, or only rows that applied.
Context menu Select from Left (with children), Select from Right (with children), Clear selection (with children), Edit Override..., and for Revit links Open Revit Link Settings... and Copy Revit Link Settings To....

A category row or a Filter Overrides row is configured in a template when that template hides it or overrides any of its graphics. A Template Parameters row is configured when the template includes the parameter. The Filter modes are:

  • Configured (default): rows configured in either template.
  • Configured in Left and Configured in Right: rows configured in that template.

Rows that are not category, filter-override or template-parameter rows are always shown. Select Left and Select Right select every differing row that the filter and search show. Under Configured in Left, Select Left can therefore select a row that both templates hide when only Right overrides its graphics. Processing that row to the right template keeps it hidden and clears those overrides.

Process

Process applies the selected rows and the eligible staged edits in one batch. A staged edit is eligible when its row has a selected side and that side is the edited side, or when its row is not in the current comparison. An edit on a visible row with no selected side, or with the other side selected, is not applied. The dialog asks Apply changes to:

Option Effect
Overwrite <Left name> Writes the selected values into the Left template.
Overwrite <Right name> Writes the selected values into the Right template.
Create Merged Template Creates a new template named in Template Name:. The name is required.

A merged template starts as a copy of the Left template, so settings VTC does not compare, such as the view scale, keep the Left values. Use Swap to choose the other base.

For a row that has a selected side, the target takes that side's value. When the selected side lacks the setting (it is absent there), the row in the target is reset to its default, instead of keeping the base value. This applies to categories, worksets and Revit link settings.

Each setting is applied in its own sub-transaction. A setting that cannot be applied is reported as a conflict and the others are applied. Any other failure rolls back the whole batch. Overwriting a template is one undo entry. Create Merged Template is one undo entry named Create Merged View Template. If it fails, no template remains, so you can retry with the same name.

Imported categories

Imported categories (DWG, DXF and other imports) appear under their own Imported Categories group. They use the same compare, edit, preview and process flow as other categories.

Revit links

Revit link settings appear under Revit Links, grouped by link. Type-level and instance-level link targets are listed separately. VTC lists only the settings that the Revit API can both read and write in the running Revit version:

Visibility Mode, Linked View, Filters, Nested Links, Object Styles, Color Fill, View Range, Phase, Phase Filter, Detail Level, Discipline.

Links are matched by the canonical link name, not by element id. If a name is ambiguous, VTC stops instead of guessing.

Action Effect
Open Revit Link Settings... Opens Native Revit Link Settings for one link target. The window always lists all supported settings of that target, even if you opened it from one row. Apply to Template writes the selected settings; it is one undo entry.
Copy Revit Link Settings To... Copies the supported settings to other link targets. Linked View, Phase and Phase Filter are matched by name in the target linked model. If the name is unavailable because the linked document is unloaded, the raw id is reused only when source and target reference the same linked model. The copy is one undo entry. A target that cannot accept the settings is reported and the others are copied. Any other failure leaves every target unchanged.

Loading a saved template from the library also remaps Linked View, Phase and Phase Filter by name in the target linked model. If the saved name is not found there, the setting fails with a not-found error. If the snapshot holds no name (the linked document was unloaded), the stored id is reused.

When only one template contains the link row, VTC uses that template. When both do and you have not selected a side, VTC asks which template to use.

Library

The Library tab saves template snapshots to disk and applies them back to a template.

  • Save Template > Left Template, Right Template or Merged Template. An optional name field sets the saved name. When blank, the source template name is used.
  • Load applies the selected saved template to the side chosen in Load to:. It first asks for confirmation, because it overwrites the template's settings in Revit.
  • A delete button removes the selected saved template, and a refresh button reloads the list.

Snapshots are stored under %APPDATA%\DBTools\Cache\VTC\. VTC creates the folder on the first save. Saved names ignore case and surrounding spaces. Saving under an existing name asks Replace saved template 'X'?; Cancel saves nothing. If VTC cannot check the name, or another Revit session saves that name during your save, the save fails and nothing is overwritten. A snapshot that is incomplete or malformed fails to load with a storage error. VTC does not repair or migrate it.

If a save or delete succeeds but the list cannot refresh, VTC shows a warning that names the template. A save or delete that fails shows an error.

Limitations

  • VTC compares templates in the open project. It does not compare templates across projects, except through the library.
  • Link settings that the Revit API cannot read and write are not shown.
  • Create Merged Template copies the Left template, so use Swap to base the merge on the other template.
