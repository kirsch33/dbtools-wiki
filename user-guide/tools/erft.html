Extreme Roof Framing Tool

NAME

Extreme Roof Framing Tool - set column and beam offsets to the underside of a floor or roof

SYNOPSIS

dbtools > dbtools Testing > Extreme Roof Framing

To edit an adjustment, select its members, then click Edit ERFT on the contextual Modify tab.

DESCRIPTION

ERFT raises or lowers column tops and beam ends to fit a floor or roof. It writes Top Offset on columns and Start Level Offset and End Level Offset on beams. ERFT saves the adjustment for Edit ERFT.

  1. Click Extreme Roof Framing.
  2. Select a linked floor or roof. To pick one in the host model, press Esc.
  3. Select the columns and beams, then click Finish.
  4. Check the Columns and Beams tables, then click Apply.

The target label shows the type and level. A linked target also shows the link name. ERFT projects vertically to downward-facing surfaces generated by the floor, roof or its modeled openings and uses the one nearest the member end. At equal distances, it uses the lower one. An end just beyond an edge can use the edge elevation within Revit's vertex tolerance.

Member end Target elevation
Column top The nearest underside elevation at the column's plan position.
Beam end near a selected column top The adjusted top of the nearest column.
Beam end near another selected beam's interior The adjusted location line of the supporting beam at that plan position.
Beam end near a directly supported beam end The support elevation at the followed end.
Other beam end The nearest underside elevation for that end.

For beam ends, ERFT checks supports in the order shown. It uses a fixed 1/2 in. distance in three dimensions. A beam interior support point must also be more than 1/2 in. from either end of the supporting beam.

Free ends from different beams can share a splice target when every pair is within 1/2 in. ERFT chooses among their rounded projected elevations. Up picks the highest, Down the lowest, and Nearest the first projecting end in beam ID order.

ERFT rounds each end's change in steps of Tolerance: and adds it to the current offset. Up and Down apply where an end projects to the underside, including when choosing a shared splice target. An end that uses a support or a shared target rounds its own change with Nearest. A change of 0.000001 ft or less in either direction counts as zero.

OPTIONS

Control Effect
Pick Selects another target and calculates again.
Tolerance: 1/16", 1/8", 1/4" (default), 1/2", 1" or Custom. A custom value is in inches and at least 0.01. Use a decimal point.
Nearest, Up, Down Round a projected change. At 1/4", -0.1 in. becomes 0 with Up and -0.25 in. with Down.
Status Pending (will change), No Change (the rounded change is 0) or Error. Point to an Error cell to see the reason.
Apply On when the tolerance is valid, a row is Pending and no row has Error.

REQUIREMENTS

Item Rule
Column A structural column in the host model, placed at a point.
Beam Straight structural framing in the host model, not a brace.
Material ERFT leaves out a member whose structural material name has the word concrete, in any capitalization.
Selection At least one column, or a beam with an end within 1/2 in. of a model column top in three dimensions.
Target A floor or roof.

RESULTS

A beam that follows another beam end shows the followed end below its offset. Error rows show the current offsets. If a follower's support has no adjusted elevation, the tooltip names the followed end and its support.

Apply writes the offsets and marks each changed member. On success the window closes and Revit records one Undo step, Extreme Roof Framing Tool. An expected failure rolls back the writes and shows Apply failed: with the reason. The window stays open. Canceling the tool rolls back the session.

Edit ERFT restores the target, tolerance and rounding of the adjustment. It reads the current offsets and calculates again. If the selection holds more than one adjustment, select one in Select ERFT System.

MESSAGES

Message Meaning and what to do
3D Preview is unavailable: <reason> The message gives the preview failure. Apply depends on the adjustment plan and tolerance.

LIMITS

  • A beam can use only selected members as supports. A column in the model can qualify a beams-only selection. Select that column to use its adjusted elevation as a support.
