Extreme Roof Framing Tool

The Extreme Roof Framing Tool (ERFT) adjusts structural columns and beams so their tops follow the underside of a sloped floor or roof. It changes the top offset of each column and the start and end offsets of each beam; it does not change level associations. You pick a target floor or roof and the members to adjust, check the calculated changes in a table and a 3D preview, then apply them as one undo entry. ERFT stores the result with the members, so you can edit the system later.

ERFT is a Testing tool and is under development.

Synopsis

Ribbon: DB Tools > Testing > Extreme Roof Framing.

To edit an existing system: select its members, then Modify tab > Edit ERFT.

The command needs an open document.

Usage

  1. Click Extreme Roof Framing.
  2. Select the target. The banner says Select a LINKED floor or roof target (press ESC to switch to HOST target selection). Click a floor or roof in a linked model, or press Esc to pick one in the host document. At the host prompt, Esc cancels.
  3. Select the source columns and beams to adjust, then click Finish.
  4. Check the target, the tolerance, the Columns and Beams tables and the preview.
  5. Click Apply.

Source members

ERFT accepts members of the host document only:

  • structural columns placed at a point;
  • structural framing with a straight location line that is not a brace.

Members whose structural material name contains the word concrete (any case) are excluded, and a banner reports how many. The selection must contain a column, or a beam that connects to a column. Otherwise the launch stops with a message (see Messages).

Window

Target

Target: shows the selected floor or roof. Pick hides the window, lets you select another target and recalculates the plan.

Tolerance

The tolerance is the rounding step for offset changes.

Control Values
Tolerance: 1/16", 1/8", 1/4" (default), 1/2", 1", or Custom
Custom field Inches, at least 0.01; an invalid value shows a message and disables Apply
Nearest, Up, Down Rounding direction. Up and Down are numeric: Down makes a negative change larger.

The change is rounded to a multiple of the tolerance. Nearest rounds to the closest multiple, so a change smaller than half the tolerance becomes no change. Up rounds to the next multiple above the change, and Down to the next multiple below it. With a 1/4" tolerance, a +0.01" change becomes +1/4" with Up and 0 with Down; a -0.01" change becomes 0 with Up and -1/4" with Down. A row shows No Change when its rounded change is smaller than half the tolerance.

Columns and Beams

Table Columns
Columns ID, Type, Top Offset, Delta, Status
Beams ID, Type, Start Offset, End Offset, Status

The status is Pending (will change), No Change or Error. Selecting a row selects the member in the preview, and clicking a member in the preview selects its row. Esc, or a click on an empty area of a table, clears the selection; Esc does not close the window.

3D Preview

The preview shows the target as a transparent surface and the members at their adjusted positions, colored by status: green for Pending, gray for No Change, red for Error. Hover a member for a tooltip. Zoom to Fit fits the scene and keeps the view angle; Home returns to the default view angle. The target cannot be selected.

If the graphics device fails, the preview is turned off for that window and asks you to update the graphics driver or enable GPU acceleration, then reopen the tool. Tolerance, Apply, Cancel and Pick still work. A member type whose section profile cannot be read is left out of the preview.

Commands

Button Action
Cancel Close without changes.
Apply Write the changes. Enabled when the tolerance is valid, at least one row is Pending and no row has an error.

During Apply, Cancel, closing the window and a second Apply or Pick are blocked.

How the changes are calculated

ERFT processes columns first, then beams in dependency order.

  • Column: the new top is the nearest point of the target's bottom surface to the column top. The change is rounded to the tolerance and added to the top offset.
  • Beam end at a column (within 1/2"): the end follows the column's adjusted top.
  • Beam end on another beam (within 1/2"): the end follows the adjusted supporting beam, interpolated along its plan position.
  • Free beam end: the end goes to the nearest point of the target's bottom surface.

The bottom surface is the set of faces of the target that face downward. "Nearest point" is the closest point in 3D, not a vertical projection, so a member outside the target's outline goes to its nearest edge. If the target has no downward faces, every row shows Error.

Result

Apply makes one undo entry, ERFT Apply Adjustments. Press Ctrl+Z to undo it. Apply:

  1. sets the column top offsets and the beam start and end offsets of the Pending rows;
  2. tags each changed member as an ERFT member of the system;
  3. saves the system (target, tolerance, rounding and offsets) in the model.

If any offset, tag or stored-data write fails, Apply changes nothing. A success alert reports the number of modified columns and beams and the unchanged count, and the window closes. A failure shows an error alert and keeps the window open.

Editing a system

Select one or more ERFT members. On the Modify tab for Structural Columns, Structural Framing or a multi-category selection, click Edit ERFT. When the selection belongs to several systems, choose one. ERFT restores the stored target, tolerance and rounding, reads the current member geometry and offsets and calculates again. Applying again starts from the current offsets; it does not add the stored changes a second time.

If some stored members no longer exist, a warning reports how many, and the others are edited. If no stored member exists, or the stored data is missing or invalid, the edit stops with a message (see Messages).

Limitations

  • Only host-document members can be adjusted. The target can be in the host or in a loaded linked model.
  • Concrete members are excluded.
  • Brace framing and curved beams are not supported.
  • ERFT changes offsets only, never the levels of members.

See the developer page and the technical specification for the geometry, rounding and storage details.
