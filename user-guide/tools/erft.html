Extreme Roof Framing Tool

NAME

Extreme Roof Framing Tool - set column and beam offsets to the underside of a floor or roof

SYNOPSIS

dbtools > dbtools Testing > Extreme Roof Framing

To edit an adjustment, select its members, then click Edit ERFT on the contextual Modify tab.

DESCRIPTION

ERFT raises or lowers column tops and the ends of beam location lines. It moves them to the bottom surface of a target floor or roof. It changes the Top Offset of each column and the Start Level Offset and End Level Offset of each beam. It changes no levels. ERFT saves each adjustment in the model for Edit ERFT.

  1. Click Extreme Roof Framing.
  2. Select a floor or roof target.
  3. Select the columns and beams, then click Finish.
  4. Check the Columns and Beams tables, then click Apply.

The bottom surface uses faces whose normals point mostly down.

Member end Moves to the height of
Column top The nearest point of the bottom surface.
Beam end within 1/2 in. of a selected column top The adjusted top of that column.
Beam end within 1/2 in. of another selected beam That beam's adjusted location line, at the same plan position.
Other beam end The nearest point of the bottom surface.

ERFT rounds each change to a multiple of the Tolerance: value and adds it to the current offset.

OPTIONS

Control Effect
Pick Selects another target and calculates again.
Tolerance: 1/16", 1/8", 1/4" (default), 1/2", 1" or Custom. A custom value is in inches and at least 0.01. Use a decimal point.
Nearest, Up, Down The rounding direction. At 1/4", a change of -0.1 in. becomes 0 with Up and -0.25 in. with Down.
Status Pending (will change), No Change (the rounded change is 0) or Error.
Apply On when the tolerance is valid, a row is Pending and no row has Error.

REQUIREMENTS

Item Rule
Column A structural column in the host model, placed at a point.
Beam Straight structural framing in the host model, not a brace.
Material ERFT leaves out a member whose structural material name has the word concrete, in any capitalization.
Selection At least one column, or a beam with an end within 1/2 in. of a column top in the model.
Target A floor or roof.

RESULTS

Apply is one Undo step: ERFT Apply Adjustments. It writes the offsets and marks each changed member. If one write fails, it changes nothing and shows Apply failed: with the reason. After a success, the window closes.

Edit ERFT restores the target, tolerance and rounding of the adjustment. It reads the current offsets and calculates again. If the selection holds more than one adjustment, select one in Select ERFT System.

MESSAGES

Message Meaning and what to do
3D Preview is unavailable: … The preview is off for this window. Apply still works. Update the graphics driver and open ERFT again.

LIMITS

  • Only selected members are supports. A beam end at a column that is not selected goes to the target surface. With only beams selected, ERFT checks for a column in the model, but no beam end follows it.
  • ERFT rounds the change, not the resulting offset.
