Installation

NAME

installation - install, update and remove dbtools

SYNOPSIS

dbtools-Setup-<version>.exe
dbtools-Setup-<version>.exe /VERYSILENT /SUPPRESSMSGBOXES

DESCRIPTION

dbtools runs in desktop Revit 2026 (2026.5 or later) and Revit 2027, on 64-bit Windows 10 or later. Setup installs it for one Windows user and needs no administrator rights. Download dbtools-Setup-<version>.exe from the releases page.

INSTALLING

  1. Close Revit.
  2. Run Setup as the Windows user who uses Revit. Setup installs into the %APPDATA% folder of that user only.
  3. On Revit versions, select the Revit years. Setup selects each compatible Revit on this computer. It disables each other year:
    • Revit 2026 - update to 2026.5 or later: update Revit, then run Setup again.
    • Revit <year> - not detected: that Revit year is not installed.
  4. Go to the next page. If dbtools is installed, Setup asks An existing dbtools.bundle was found. Replace it with this version? Click Yes.
  5. On Ready to install, check Product, Revit and Location. Click Install.
  6. The last page shows dbtools is installed. Open install folder opens %APPDATA%\dbtools.
  7. Start Revit. If the dbtools tab does not show, read the logs.

UPDATING

To update, run Setup of the version that you want. Setup replaces the whole bundle folder, so it deletes files that you added there. It keeps your settings and logs. dbtools does not check for updates.

UNINSTALLING

Close Revit. In Windows Settings > Apps, find dbtools and click Uninstall. The uninstaller deletes the bundle folder, and keeps your settings and logs in %APPDATA%\dbtools\.

SILENT INSTALLATION

Setup accepts the standard Inno Setup switches, such as /VERYSILENT and /SUPPRESSMSGBOXES. A silent install selects every compatible Revit year and replaces an installed version without a prompt. Run it in the Windows session of the Revit user. Setup writes a log during installation.

Exit code Meaning
0 dbtools is installed.
10 Setup could not activate the copied files.
Another code Setup did not install, for example because Revit is running or no compatible Revit is installed. The Setup log gives the reason.

MESSAGES

Message Meaning and what to do
Close Revit and run Setup again to install dbtools. Revit runs in your Windows session. Close it.
Select at least one installed Revit version. For Revit 2026, install update 2026.5 or later. No Revit year is selected.
dbtools could not be installed The last Setup page gives the reason and the path of the Setup log. It also tells whether your previous version is still installed. Close each program that uses a file in the dbtools folders, and run Setup again.
A dbtools dialog when Revit starts, such as dbtools theme failed to load: dbtools could not start. Run Setup again. If the dialog shows again, send the log.

FILES

Path Contents
%APPDATA%\Autodesk\ApplicationPlugins\dbtools.bundle\ The add-in. Revit loads it at start. Contents\dbtools\<version>\<year>\ holds the files for one Revit year.
%APPDATA%\dbtools\ The uninstaller, your settings, the logs in Logs\ and the tool caches in Cache\
