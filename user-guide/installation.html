Installation

DB Tools is a Revit add-in for Revit 2026 (2026.5 or later) and Revit 2027 on 64-bit Windows 10 or 11. The installer runs under a standard user account and needs no administrator rights.

Requirements

Item Requirement
Revit 2026.5 or later, or 2027 (desktop)
Windows 10 or 11, 64-bit
Account Standard user

Installing

  1. Download DBTools-Setup-<version>.exe from the GitHub releases page, or from the location your administrator provides.
  2. Close all running Revit sessions.
  3. Run the installer.
  4. On the Revit page, select the Revit years to install for. The installer checks %ProgramW6432%\Autodesk\Revit <year>\RevitAPI.dll. It enables only the years it detects, and it selects them by default. At least one year has to be selected.
  5. If DBTools.bundle is already installed, the installer asks An existing DBTools.bundle was found. Overwrite?. Answer Yes to replace it. Answer No to cancel the installation.
  6. Wait for the installer to finish. The installation log is shown on the progress page and on the finish page. The button Open install folder opens %APPDATA%\DBTools.

Start Revit. The DB Tools tab appears on the ribbon.

What the installer does

The installer copies the release into a staging folder next to the active bundle, checks that the required files exist for each selected year, and rewrites PackageContents.xml so that the bundle registers only the selected years. It then renames the current bundle to a backup, moves the staging folder into place, and deletes the backup. If any of these steps fails, the installer restores the previous bundle and reports the error.

Installing replaces the entire bundle. A new install removes the previous version folder and any other file in the old bundle.

There is no in-app updater. To update, run the installer of the new release.

Files and folders

Path Contents
%APPDATA%\Autodesk\ApplicationPlugins\DBTools.bundle\ The add-in, loaded by Revit as an Autodesk application plugin bundle. Contents\DBTools\<version>\<year>\ holds DBTools.addin, DBTools.dll, DBTools.Core.dll, DBTools.Presentation.dll, DBTools.HandyControl.dll and the Tools\ folder with one DBTools.<Tool>.dll per tool.
%APPDATA%\DBTools\ The installer's data folder: the uninstaller, the icon and Families\ (Revit families that the tools use).
%APPDATA%\DBTools\settings.<year>.json User settings, one file per Revit year.
%APPDATA%\DBTools\Logs\ Log files, named dbtools-<year>-...log.
%APPDATA%\DBTools\Cache\ Tool caches, for example VTC\ (saved templates) and TDV\ (temporary library copies).

Each tool stores its own data under %APPDATA%\DBTools\ as its page describes.

Uninstalling

Open Settings > Apps > Installed apps, select DB Tools, and select Uninstall. The uninstaller deletes DBTools.bundle together with its .staging and .backup folders, and the Families folder.

The uninstaller keeps your settings, logs and caches in %APPDATA%\DBTools\. To remove all DB Tools data, delete that folder.

Silent installation

The installer is an Inno Setup program and accepts the standard Inno Setup switches, for example:

DBTools-Setup-<version>.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

A silent installation installs for every detected Revit year. With /SUPPRESSMSGBOXES, the overwrite question takes its default answer, Yes. The installer has no switch for choosing Revit years or the install folder.

Troubleshooting

The DB Tools tab does not appear

  1. Close Revit and make sure %APPDATA%\Autodesk\ApplicationPlugins\DBTools.bundle\PackageContents.xml exists and lists your Revit year.
  2. Start Revit.
  3. Open the newest file in %APPDATA%\DBTools\Logs\ and search for ERROR or FATAL. If startup fails before logging starts, %APPDATA%\DBTools\Logs\DBTools.Fallback.log holds the failure.
  4. Reinstall DB Tools.

DB Tools theme failed to load

Revit shows this message when startup cannot load the DB Tools theme. The message is followed by the failure details. Check that the year folder in the bundle holds DBTools.dll, DBTools.Core.dll, DBTools.Presentation.dll, DBTools.HandyControl.dll and the Tools\ folder. If any file is missing, close Revit and reinstall DB Tools.

The installer reports an error

The installer reports Could not activate the staged DBTools bundle or a similar message when it cannot rename the bundle folder. Close Revit, close any program that holds a file in the bundle folder, and run the installer again. Antivirus software that locks files in %APPDATA% can cause this error.

Revit years

A Revit year that is not installed cannot be selected. To add a year later, install Revit for that year and run the installer again.
