Getting started

This page describes the DB Tools ribbon, the settings window and the conventions shared by all tools. For installation, see Installation.

The ribbon

DB Tools adds the DB Tools tab to the Revit ribbon. The tab has these panels:

Panel Contents
DB Tools Settings Settings
DB Tools Common Global Mapper, Transfer Drafting Views (Export To Library and Import From Library), Align Elevation Tags
DB Tools Structural Super Girt Tool, Combined Foundation Tags (Update Combined Foundation Tags and Move Combined Tags) and Organize Foundation Types in one split button, Analytical Snap To Level, Allow Join and Disallow Join in one split button, Update Joist Girder Weights
DB Tools Testing View Template Comparer, Record Set, Extreme Roof Framing

The pages of this guide refer to a panel by its last word, for example DB Tools > Common.

The Testing panel holds tools that are still under development. A panel is hidden when its group is turned off in the settings. A tool whose prerequisites are not met is disabled, and a settings warning explains why (see Warnings).

Settings

Click Settings to open the settings window. It opens without a model.

The General section has these options:

Option Default Effect
Enable Common Tools On Shows or hides the Common panel.
Enable Structural Tools On Shows or hides the Structural panel.
Enable Testing Tools On Shows or hides the Testing panel.
Enable Services On Shows or hides background services in the ribbon.
Enable Debug Mode Off Writes verbose logs and opens the logger window.

Below General, each tool that has options contributes a settings pack: Elevation Tags, Combined Foundation Tags, Joist Girder Weights, Library Files (Transfer Drafting Views) and others. Each pack has a Reset button.

Button Effect
Validate Checks the settings and refreshes the warnings.
Save Settings Saves all changes and closes the window.
Reset All > Reset All Settings Resets every setting.

Settings are stored per user and per Revit year in %APPDATA%\DBTools\settings.<year>.json.

If Settings cannot load, Reset Settings in the Settings Load Problem alert preserves the per-year file as settings.<year>.json.recovery-<guid>.bak. If DB Tools can read the file, it replaces the current session's settings sections with defaults and keeps every other section's JSON value unchanged, including settings for unloaded tools. Otherwise it replaces the whole file with defaults, for example when the file is not valid JSON or names a section twice. It keeps earlier preservation copies. An absent file needs no copy. The success banner and Information log name the preservation file. Access or preservation failures leave the active file unchanged and report the failure. This action does not repair appsettings.json. Normal Reset All Settings requires a valid per-year JSON object.

Several tools have an Auto-Update Enabled option. It makes the tool run when a view is activated. It does not update DB Tools itself.

Warnings

A tool can raise a settings warning when a prerequisite is missing, for example Combined Foundation Tags Disabled or Library Paths Invalid. The warning disables the commands that depend on the prerequisite. The settings pack of the tool shows a card with a fix action, or states what to correct.

Banners

A banner appears in a strip across the top of the window that ran the tool, or of the Revit window. Each banner shows its title on the first line and its message on the second. Point at the text to read all of it. A long message, such as a list of skipped elements, also has a Details button that opens the log window, where the full message is.

Banner Look Closes
Confirmation, for example Settings saved. Gray, green check After 3 seconds
Information, for example No elements were modified. Gray, blue i After 5 seconds
Warning or refusal Amber bar After 8 seconds
Error Red bar After 10 seconds
Prompt, for example Select a linked wall or host foundation wall... Gray bar, pointer When the pick ends
Banner with buttons Color of its kind When you close it or click a button that finishes the task

A tool page states any banner that closes at another time. A banner's time runs only while you can see it.

  • While the pointer is over the strip, no banner closes and no row moves. New banners wait until the pointer leaves, except the result of a button you click. After the pointer leaves, each banner stays at least 2 more seconds.
  • The same banner shown again does not add a row. The open row shows a count, for example ×2, and its time starts again.
  • One action shows one banner. A failure appears once, even when several layers of a tool report it; the log keeps the details.
  • Banners with buttons and prompts stay above other banners. With more than three banners, the last row reads +N more. Click it to show all banners. They collapse again after the pointer leaves the strip. A banner behind +N more waits; its time starts when it comes into view.
  • If the window that ran the tool closes before one of its banners appeared, the banner appears on the Revit window, with its count.
  • While the window is minimized, its banners wait. When it is restored, each banner stays at least 2 more seconds.
  • Click the close button of a banner to close it at once.

Logs and debug mode

DB Tools writes a log file for each Revit session to %APPDATA%\DBTools\Logs\, named dbtools-<year>-...log. With Enable Debug Mode on, the logger window opens after a tool runs. The window can search and filter entries, copy them, and export them. Double-click an entry to see its details, such as the full source, the duration and the correlation ID; Copy details copies them for a problem report.

Conventions

  • A failure while a tool changes the model rolls back the run and leaves the model unchanged, except where a tool page says otherwise.
  • Tools report their result in a banner across the top of the window or in a dialog. See Banners.
  • A completed run is normally one undo entry. Press Ctrl+Z to undo it. Each tool page states exceptions.
  • Tools that match elements by name take .NET regular expressions in their settings.
