Getting started

NAME

getting started - the DB Tools ribbon, settings, banners and logs

SYNOPSIS

DB Tools > Settings

DESCRIPTION

This page describes the parts that all tools share.

RIBBON

The tab has four panels: DB Tools Common, DB Tools Structural, DB Tools Testing and DB Tools Settings. This guide names a panel by its last word, such as DB Tools > Structural. The user guide lists the tools on each panel.

A tool button needs an open model. Only Settings works without one.

A tool raises a settings warning when its settings are not valid, or when the model lacks something that the tool needs. Then the Settings button shows a warning icon, the DB Tools tab is highlighted, and the buttons that need the missing item are disabled. Open Settings to read and fix the warning.

SETTINGS

Click Settings to open DB Tools - Settings. DB Tools saves settings for each Windows user and each Revit year. Settings that you make in Revit 2026 do not apply in Revit 2027.

Option in General Default Effect
Enable Common Tools On Shows the DB Tools Common panel.
Enable Structural Tools On Shows the DB Tools Structural panel.
Enable Testing Tools On Shows the DB Tools Testing panel.
Enable Services On Changes nothing. To stop Dialog Suppression, clear Enable Dialog Suppression in its pack.
Enable Debug Mode Off Opens the log window and adds Debug entries to the log. It applies at once and lasts until Revit closes.

A cleared panel option hides the panel only. The auto-update options of its tools still run.

Common Settings, Structural Settings, Testing Settings and Services Settings hold the settings packs of the tools. Some packs have an auto-update option, such as Auto Update Joist Girder Weights. It runs the tool each time you open or switch to a view.

Button Effect
Validate Checks the unsaved settings and shows the warnings. It saves nothing.
Save Settings Saves all changes and closes the window. Text at the bottom of the window tells when the changes apply.
Reset All > Reset All Settings Resets every setting at once, after you confirm.
Reset on a pack Resets that pack at once, after you confirm.

If you close the window without Save Settings, DB Tools discards your changes without a prompt.

BANNERS

A tool shows its result in a banner at the top of its window or of the Revit window. Most banners close by themselves after 3 to 10 seconds, and an error stays longest. While the pointer is over the banners, no banner closes.

A long message has a Details button, which opens the log window with the full text. With more than three banners, the last row shows +<n> more. Click it to show all banners.

LOGS

DB Tools writes one log file for each Revit session to %APPDATA%\DBTools\Logs\, named dbtools-<year>-*.log. A failure from before the log starts goes to DBTools.Fallback.log in the same folder. For a problem report, send the newest log.

When DB Tools logs an error, the log window opens and Debug Mode stays on until you clear it or Revit closes. In the log window, double-click an entry to see its details. Click Copy details to copy them, or Export to save all entries to a file.

MESSAGES

Message Meaning and what to do
Could not load settings. The settings file may be corrupt or inaccessible. Reset Settings keeps a copy of the settings file in %APPDATA%\DBTools\ and resets the settings. The banner names the copy. Abort Addin Load closes only the settings window. Close closes only the message.
