Namespace DBTools.Presentation.Behaviors

Classes

BehaviorState

Keeps attached behavior state weakly keyed by its element and releases all state for an element during tool-window retirement. The table is stable; its values must be cleared by Release(DependencyObject) before a payload generation is unloaded.

ContextMenuOnClickBehavior

Opens a button's context menu from its click, placing it below the button. A toggle button keeps its checked state synchronized with the menu's open state.

FocusRequestBehavior

Focuses the attached control when a bound request value changes. The request is a plain counter or token owned by the view model; the behavior owns and aborts its posted operation.

PreviewZoomBehavior

Fits an image inside a named viewport when its binding target updates. It also supports a button click for an explicit zoom request, using names so no payload control type is stored.

SelectOnRightClickBehavior

Selects and focuses an items-control container before its context menu opens.

TreePathNavigationBehavior

Expands a tree path, selects its final item, and brings that item into view. Paths contain item values, so payload types do not enter the stable behavior assembly.

TreePathRequest

Plain path request consumed by TreePathNavigationBehavior.

Interfaces

IReleasable

Releasable state owned by one stable attached behavior.
