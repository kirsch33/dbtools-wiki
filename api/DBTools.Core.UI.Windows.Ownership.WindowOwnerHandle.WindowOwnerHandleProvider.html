Resolves a WPF window's HWND for the windows it owns: banners, dialogs and file pickers. A closing or closed window cannot own a new window, so resolution then returns the registered default owner (Revit's main window), or a zero HWND when none is registered. Construct the provider on the window's dispatcher thread.
