Remarks

Girt endpoints use exactly these three kinds; an opening boundary is always OpeningEdge (opening key + side). Left is the opening's lower-T edge and Right is its higher-T edge. This type is the only reader of stored girt anchors (Full-Length placeholder, grid name, gap-map key).

Remarks

The format is "<openingKey>:<Left|Right>". Other anchors return an empty string and store their gap in the endpoint gap field. Returning an empty string allows the record's generated ToString to read this property without throwing.
