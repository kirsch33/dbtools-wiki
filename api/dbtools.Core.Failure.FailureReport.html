Shows each failure once. A handler that shows a failure banner records it with the exception; an outer handler that receives the same exception only logs it. The banner system keeps every request it accepts (see NotificationBannerService), so a request counts as shown when it is made.

Remarks

The outermost SafeExecutor run of an asynchronous flow opens a report scope; nested runs use its records. A run that rethrows to its caller hands its record on to the window error boundary, which takes it once. A later run ignores and removes a record that another run handed on, so a failure its caller cached and throws again is shown again. Tool code that shows its own banner and rethrows records the failure for its next handler.
