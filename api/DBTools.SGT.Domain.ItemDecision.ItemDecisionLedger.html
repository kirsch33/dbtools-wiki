Forget(string)

Leaves an item owned only by Placed: removes its remembered decision and any removal tombstone (only openings have tombstones). Ignore is never remembered (ItemDecisionEntry.Validate), so every Ignore of an opening or the wall routes here. There is no revision check: every caller decides against the current Placed revision, and loaded ledgers pass ValidateFor.
