Remarks

Rejects an empty batch, null entries and repeated sections. Acquires a cross-process lock and rereads the file before replacing sections. Lock acquisition throws IOException after 10 seconds. A failed commit leaves the settings file unchanged.

Remarks

Missing files, sections and optional values use defaults. A value of the wrong JSON kind at an object or collection position reads as empty. An object, array or null at a string property reads as an empty string. A later file's null or scalar preserves an earlier object or array.

Malformed JSON and missing JsonRequired members throw, including members of objects that read as empty. Values that cannot convert to a boolean or number throw, including null, objects and arrays. Other I/O errors propagate.
