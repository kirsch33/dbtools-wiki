Remarks

For a raw modal view use DialogResult="True" (Save) or DialogResult="False" (Cancel), with this behavior's optional Command and CommandParameter properties. A result implies close. The attached command executes before the session's close gate runs. Use the attached Command, rather than Button.Command, so WPF does not execute a second command after closing. ExecuteAndClose retains result-free closing for existing views. Accepted clicks remain unhandled so parent Click handlers can observe them.
