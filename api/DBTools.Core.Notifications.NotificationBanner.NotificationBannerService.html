DBTools.Core.Notifications.NotificationBanner

DBTools.Core.dll

Shows transient notification banners anchored to the supplied owner through a modeless IToolWindowSession. On the owner dispatcher's thread, owner resolution and presentation run before return and their exceptions reach the caller. From any other thread the request is queued on that dispatcher, the call returns at once, and delivery failures are logged, never thrown. Choosing the dispatcher (WpfDispatcher.GetDispatcherOrThrow) can throw on any thread. A suppressed request (zero owner HWND, no anchor position, retired host, host reset) returns a handle that does nothing, so a returned handle never confirms that a banner showed. Disposing the returned handle before delivery cancels that presentation.
