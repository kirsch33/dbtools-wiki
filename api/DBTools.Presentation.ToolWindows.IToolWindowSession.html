Owns a raw-XAML view and its stable window shell.

public interface IToolWindowSession

Remarks

Register payload event handlers and cleanup through the session. Retire synchronously on the shell's UI thread before unloading a payload generation. Window and View are unavailable after retirement. ShowDialog returns null after retirement.

Host-owned creation, lifecycle, root layout and dispatcher callbacks temporarily clear contextual reflection and restore the caller's scope on return. Raw templates resolve through the stable schema. The close gate, subscribed handlers and AddCleanup callbacks re-enter the creation context with ExecutionContext flow suppressed. Retirement releases that context on every exit.

Flow suppression prevents captures. Clearing contextual reflection controls synchronous resolution. A command must suppress flow throughout its payload reflection scope, including tool-triggered layout outside shell overrides. WPF can measure an invalidated subtree directly. This work can see the command context but cannot capture it while flow is suppressed. Async callback continuations do not inherit that context. Name resolution after an await must explicitly re-enter it under suppression for synchronous work.

Binding accessors, edit cancellation, collection notifications and custom shell initializers execute in the host's neutral reflection context. They must not depend on ambient name resolution.

Synchronously retires the owned stable graph through the same path after either close kind. Writers are quiesced before behavior release, LIFO cleanup and edit cancellation. Final discovery and severing include disconnected containers and owned popup roots.
