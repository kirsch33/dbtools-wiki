Namespace

DBTools.Presentation.dll

Attached behavior that executes a command when the user commits a ComboBox selection.

WPF's SelectionChanged fires for both user edits and programmatic updates (e.g. rebuilding ItemsSource, restoring state, threshold/sort refreshes). GM needs a signal for "user intentionally picked something" so programmatic updates do not get treated as manual edits.

This behavior executes the command on DropDownClosed only if the selected item's Equals implementation reports a logical change between open and close.
