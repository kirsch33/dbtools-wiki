Runs work inside one transaction group within a single Revit API callback, so the group becomes exactly one Revit Undo entry. Revit rolls back a group that is still open when the callback that started it returns, so a group must never span call-gate calls.

RunAsync<T>(string, Func<CancellationToken, Task<T>>, Func<T, bool>, CancellationToken)

Begins the group on the active document, runs work, then assimilates the group when keep accepts the result and rolls it back otherwise. An exception, or cancellation seen at any point before finalization, rolls the group back and propagates. The work must complete within the callback: its call-gate calls run inline. A document with an open transaction is refused before any work. Unless Revit confirms the rollback, the call throws TransactionGroupOutcomeUnknownException.
