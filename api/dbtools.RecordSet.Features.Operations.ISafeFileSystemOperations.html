CopyPath(SafeCopyPathRequest, RecordSetSafeOperationContext)

Copies a file, or each file under a directory at the same relative path, to a destination in the target root.

void CopyPath(SafeCopyPathRequest request, RecordSetSafeOperationContext context)

Parameters

request SafeCopyPathRequest

The source and destination paths, the file filter and the verification option.

context RecordSetSafeOperationContext

The target root, long-path mode, log and cancellation token of the run.

Remarks

A file that ShouldCopyFile rejects is skipped with a log line and is not a failure. Each accepted file overwrites its destination and gets the source creation, last-access and last-write times. With VerifyAfterCopy, the SHA-256 hash of each accepted destination file must equal that of its source. A normal return means that every accepted file was copied and verified as requested, not that every source file was copied.

The resolved destination is checked against the target root before each write. The check and the write are separate operations, so a concurrent path replacement can race them. Cancellation is observed between operations; a running file copy or hash read is not interrupted, so a late cancellation can return normally. A copy, timestamp, callback or verification failure, or a cancellation, can leave destination files changed, and execution does not restore them. An exception from ShouldCopyFile or Log propagates unchanged.

Exceptions

ArgumentNullException

request, context or the context runtime is null.

InvalidOperationException

The destination, or a file destination under it, resolves outside the target root.

OperationCanceledException

The context cancellation token was canceled before an operation started.

IOException

The source does not exist, a read or write failed, or verification found a missing or different destination file.

UnauthorizedAccessException

The process cannot read the source or write the destination.
