Remarks

After the registry retires, Post(Action, DispatcherPriority) returns a task that stays pending and never runs its callback. Queue(Dispatcher, Action, DispatcherPriority) and Invoke(Dispatcher, Action, DispatcherPriority) throw InvalidOperationException with the retired-registry message, including when Invoke runs on the dispatcher thread. An Invoke already waiting on a worker thread receives the same exception when retirement drops its queued callback. A Post reporter failure stays on its task and does not reach UnhandledException. A Queue callback failure reaches UnhandledException after registry cleanup. When the registry is open, Post throws InvalidOperationException if no dispatcher is available or it is shutting down.
