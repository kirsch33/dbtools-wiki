SurfaceFatalFailure(ILogger, Guid)

Surfaces a fatal execution failure on a best-effort basis. Display may be posted to a dispatcher and finish after this call returns, so a normal return does not prove the surface was shown. Display failures are reported through logging by the surface, not thrown.

void SurfaceFatalFailure(ILogger logger, Guid correlationId)

Parameters

logger ILogger
correlationId Guid

Remarks

An exception thrown synchronously from this call is a surface failure: SafeExecutor returns it in an AggregateException together with the operation failure.
