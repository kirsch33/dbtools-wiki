Remarks

The parameterless constructor stays inert to satisfy Revit's IExternalCommand contract. Runtime services are resolved during Execute(ExternalCommandData, ref string, ElementSet).

Sync-over-Async Pattern:

The Execute(ExternalCommandData, ref string, ElementSet) method uses .GetAwaiter().GetResult() because Revit's IExternalCommand.Execute method must return synchronously. The async pattern in RunAsync(ICommandContext) is for composability within the command implementation.
