Remarks

This host primitive applies none of the synchronous-delegate admission rules from IRevitCallGate. Queued work that has not started when the owning call-gate task retires is dropped, and its task never completes, even if its cancellation token is cancelled later. Callers must not await or block on such a task during shutdown. Failed-startup cleanup cancels pending work instead.
