Attached behavior that forwards mouse wheel scrolling to a DataGrid's internal ScrollViewer. This makes scrolling consistent even when the pointer is over nested controls in row details.

ForwardToNearestDataGridProperty

When attached to a non-DataGrid element (e.g., a Border), forwards mouse wheel events to the nearest child DataGrid's internal ScrollViewer. If the DataGrid is at its scroll extent, lets the event bubble to the parent ScrollViewer.
