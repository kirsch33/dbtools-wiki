Remarks

Resolves the wall document/scope, enumerates hosted door/window inserts, and maps each to RawOpening. Per-opening bounds extraction is delegated to DBTools.SGT.Features.Openings.Revit.Query.OpeningQueryBoundsExtractor; each result also carries the owning opening UniqueId and, for linked walls, the link-instance UniqueId.
