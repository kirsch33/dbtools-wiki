Namespace dbtools.Presentation.Controls

Classes

DialogFooter

Arranges the buttons at the bottom of a dialog or tool window. Tertiary buttons sit at the left; secondary buttons and then the primary button sit at the right, so the primary button is rightmost whatever the declaration order. The tab order follows the arranged order. A destructive confirmation gives the danger button the Primary role and makes Cancel the default (IsDefault), so Enter cancels.

ListEmptyState

The line that a list, tree or data grid shows while it has no items, such as "No library files. Add one with Add library file…". The theme templates of ListBox, TreeView and DataGrid show it; without it an empty list stays blank.

SearchBox

A filter-as-you-type text box that reads as search at a glance: a leading magnifier, a placeholder that names what it filters, an optional result count and a clear button that shows only while there is text. Escape clears the text. It is a TextBox, so a Text binding and its automation id work as on a plain text box.

SettingsPack

One settings pack: a flat card with a header row (title, a Modified marker and a small "Reset to defaults" action) over the pack's content. The reset action is enabled only while the pack differs from its defaults. UI Automation exposes the pack as a group.

ToolbarRow

A row of commands that act on the list or content next to it, such as Add, Remove and Validate. Children sit left to right in declaration order with one gap between neighbors and are centered vertically. The row does not wrap.
