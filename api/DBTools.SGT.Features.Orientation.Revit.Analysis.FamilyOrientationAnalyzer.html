AnalyzeOrientation(FamilySymbol, SymbolCalibration, WallFrameTargetContext, MemberRole, Document, ILogger)

Three-gate orientation analysis: Gate 1 tests rotation (web normal direction); Gates 2/3 run the deterministic Y/Z solver over every justification pair. Returns an OrientationResult with gate status and diagnostics. Expected per-family incompatibilities (calibrated faces not found, rejected rotation, justification or offset writes, rotation out of range) arrive as DBTools.SGT.Domain.SpecFailure.SpecFailureException; cancellation, rollback failures and invariant defects propagate unchanged.
