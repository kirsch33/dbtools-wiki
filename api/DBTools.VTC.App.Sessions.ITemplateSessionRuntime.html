BatchApply(long, TemplateComparison, IReadOnlyList<SettingSelection>, IReadOnlyList<PendingCategoryOverride>)

Applies selections, then pendingOverrides, to template targetTemplateId in one transaction, one subtransaction per setting; empty input returns a zero result without a transaction.

TemplateApplyResult BatchApply(long targetTemplateId, TemplateComparison comparison, IReadOnlyList<SettingSelection> selections, IReadOnlyList<PendingCategoryOverride> pendingOverrides)

Parameters

targetTemplateId long
comparison TemplateComparison
selections IReadOnlyList<SettingSelection>
pendingOverrides IReadOnlyList<PendingCategoryOverride>

Returns

TemplateApplyResult

The attempted, succeeded and failed counts, with one conflict for each setting whose apply failed with an expected apply failure (that setting's subtransaction rolled back); no conflicts when every setting was applied.

Exceptions

Exception

An unexpected fault, including a BatchApplyException from one setting, rolls back the whole transaction, including the settings applied before it.
