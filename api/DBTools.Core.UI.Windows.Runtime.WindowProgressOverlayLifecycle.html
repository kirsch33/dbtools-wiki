UnregisterHost(Window)

Releases the window's overlay host. Without a configured lifecycle nothing can be registered (EnsureHost(Window, ILogger) requires one and DBTools.Core.UI.Windows.Runtime.WindowProgressOverlayLifecycle.Reset() clears every registration), so this is a no-op; it runs from Window.Closed, where a throw escapes WPF's window destruction.
