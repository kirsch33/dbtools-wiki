Classes

ElevationTagsSettings

Persisted settings for elevation-tag alignment workflows.

PreviewContext

Draws the selected spot elevation type as Align places it. The preview shows one spot whose leader runs down to the element point and one whose leader runs up to it. The family symbol, shoulders, leaders and elevation text use paper-inch layout and the type's visual properties.

SettingsPackContext

Settings pack context for elevation tag configuration. Coordinates pattern, type, and preview contexts for the settings UI.

SpotElevationPreviewLayout

Places a spot type preview in paper inches. It shows one leader that runs down to the element point and one that runs up. X grows along the shoulder and canvas Y grows downward.

SpotElevationPreviewScene

A laid-out preview: two spots of one type whose leaders run down and up to one element point. ShowsSymbol is false when the type has no symbol drawing or uses in-line text.

SpotElevationPreviewTag

One spot in the preview. The symbol center is LeaderEnd; the shoulder runs from there to ShoulderEnd, where the leader turns to the element point. Label and BaseLabel span the capitals, from their top to the baseline; BaseLabel is the label without offsets.

SpotElevationPreviewTag.SymbolPlacement

The symbol's leader-end origin and its canvas-space extent.

SpotElevationSymbolDrawing

A Revit-free spot symbol drawing in paper inches. The family origin is the leader end. X grows along the shoulder and Y grows up.

SpotElevationSymbolDrawing.Fill

One solid filled region with all its boundary loops.

SpotElevationSymbolDrawing.Path

A tessellated family curve or region boundary.

SpotElevationSymbolDrawing.Text

A plain family text element; its position is the Revit anchor selected by vertical alignment.

SpotElevationTypeSnapshot

Immutable snapshot of a spot elevation type's visual properties for WPF preview rendering. No Revit API references — safe to use on the UI thread.

TypeAlignmentOffsets
