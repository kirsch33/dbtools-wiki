Runs action inside the safe-execution boundary, reports its outcome, and rethrows every outcome except success.

Remarks

The returned task completes normally only for Succeeded. A Refused, Canceled or Failed outcome is reported first and then rethrown. The rethrown exception is the instance that the action threw, with its original stack trace, unless a reporting stage failed and the outcome became an AggregateException.

Reporting follows opts and needs a notifier for banners. An exception that an inner run already showed (FailureReport) is logged again, without a second banner or failure surface.

  • A SafeExecutionRefusedException is Refused. It shows a warning banner, or writes a warning log entry when there is no notifier or banners are suppressed. It writes no exception diagnostics and uses no failure surface.
  • Every OperationCanceledException is Canceled, also one that does not come from ct. It writes a warning log entry and shows no failure banner and no failure surface. A canceled ct stops the action before it starts.
  • Any other exception is Failed. It is logged, shown in an error banner, and passed to the failure surface, as opts allows. The banner text is the exception message, or The operation failed. for a blank message. A success banner that throws makes the outcome Failed with that exception.

A reporting failure makes an AggregateException with the operation's exception first and the reporting failure second. The stages run in this order: refusal reporting (the outcome is then Failed and takes the failure path), failure notification, failure surface. When more than one stage fails, each later aggregate holds the earlier one as its first inner exception.

The outermost run hands its failure record to the caller's handler, such as the window error boundary.

Exceptions

ArgumentNullException

action, logger or opts is null. The returned task faults with this exception; nothing is reported.
