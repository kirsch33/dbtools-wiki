Remarks

One logical flow; not thread-safe. Contextual attempts wrap every exception in InvalidOperationException, including cancellation and typed failures. Pass an operation's primary failure through the constructor, Add(Exception?), or contextless Attempt(Action, string?); context is for cleanup steps.
