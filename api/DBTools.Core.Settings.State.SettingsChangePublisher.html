RegisterRibbonSettingsObserver(Func<SettingsFlags, SettingsChangeDelivery, Task<bool>>, Func<IReadOnlyCollection<string>, SettingsChangeDelivery, Task<bool>>, Func<WarningChangedEventArgs, SettingsChangeDelivery, Task<bool>>)

Registers the one ribbon settings observer. Each callback receives the change and its SettingsChangeDelivery. Under Required, true confirms the change was applied; under BestEffort, true only acknowledges that the change was handled or scheduled. false means the callback skipped the change.

public IDisposable RegisterRibbonSettingsObserver(Func<SettingsFlags, SettingsChangeDelivery, Task<bool>> applyFlags, Func<IReadOnlyCollection<string>, SettingsChangeDelivery, Task<bool>> applyWarnings, Func<WarningChangedEventArgs, SettingsChangeDelivery, Task<bool>> applyWarning)
