Post(Action, DispatcherPriority)

Queues the action on the application UI dispatcher. The returned task completes after the action runs, and faults with the exception the action throws. When no dispatcher is available or it is shutting down, the call throws instead of returning a task.

public static Task Post(Action action, DispatcherPriority priority = DispatcherPriority.Normal)

Parameters

action Action
priority DispatcherPriority

Returns

Task

Remarks

A post made after the application generation retires its dispatcher operations is refused before it reaches the dispatcher, and its task is canceled. A queued operation that the dispatcher aborts before it runs faults with InvalidOperationException. Accepted work that has not run when the generation retires is dropped, and its task never completes. Callers must not await or block on such a task during shutdown.

Post(nint, Action, DispatcherPriority)

Queues the action on the dispatcher that owns the owner window handle, or on the application dispatcher when no WPF source owns that handle. The returned task completes after the action runs, and faults with the exception the action throws. When no dispatcher is available or it is shutting down, the call throws instead of returning a task.
