Unified entry point for executing Revit API callbacks either inline (modal) or queued (modeless).

public interface IRevitCallGate

Remarks

Null work delegates and rejected delegate shapes throw from the call itself. Failures after argument validation, including cancellation, mode or context refusal, callback failure, and erased awaitable-result rejection, are delivered through the returned task. Cancellation completes the task as Canceled. An OperationCanceledException thrown by a gate check or work delegate is rethrown; cancellation observed by the queued host surfaces as a TaskCanceledException.

Remarks

Queued work that has not started when the owning call-gate task retires is dropped, and its task never completes, even if its cancellation token is cancelled later. Callers must not await or block on such a task during shutdown. Failed-startup cleanup cancels pending work instead.

RunAsync<T>(Func<UIApplication, T>, CancellationToken, RevitCallGateMode)

Executes the work delegate on the Revit UI thread and returns a result. Task and ValueTask result shapes and reference-typed multicast result delegates throw from the call before execution. An erased Task or boxed ValueTask result (for example, a Task returned as object or an interface) is rejected only after the work runs. Its side effects remain, and any started Task continues running. Other awaitable types (for example, ConfigureAwait results and custom awaiters) are not detected.
