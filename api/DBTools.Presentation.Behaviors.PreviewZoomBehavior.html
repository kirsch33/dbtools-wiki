Fits an image inside a named viewport when its binding target updates. It also supports a button click for an explicit zoom request, using names so no payload control type is stored.

public static class PreviewZoomBehavior

object

Remarks

Set ZoomExtentsOnSourceUpdated="True" on an Image and bind its TargetViewportName. The Image.Source binding must set NotifyOnTargetUpdated=True. Button clicks additionally use TargetImageName.
