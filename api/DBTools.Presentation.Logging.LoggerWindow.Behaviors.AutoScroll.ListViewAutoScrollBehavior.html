Remarks

Turning AutoScroll off explicitly prevents automatic resumption until the user enables it. A scroll-induced pause ends when the user scrolls down to the bottom, or new items arrive after AutoResumeIdleWindow. AutoResumeIdleWindow defaults to 15 seconds since the last upward scroll.

Fields

True when the user explicitly turned auto-scroll off via UI toggle. When true, all automatic re-enabling is suppressed until the user turns it back on.
