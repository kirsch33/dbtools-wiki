TransactionFailurePreprocessor

Preprocessor that suppresses Revit warnings and prevents Revit's failure UI from surfacing.

  • Warnings are deleted. With dbtools.Core.Revit.Transactions.TransactionFailurePreprocessor.DeletableWarnings, only the listed warnings are deleted and any other warning blocks the commit like an error.
  • Errors/fatal failures cause the transaction to roll back (no Revit dialogs) so dbtools can surface the error.
TransactionFailureRecord

One Revit failure message that a dbtools transaction saw while committing, and how dbtools resolved it.

TransactionRunner

Transaction runner implemented on top of IRevitCallGate. Resolves the target Revit document through the call gate, then delegates transaction/subtransaction execution to dbtools.Core.Revit.Transactions.TransactionExecutor.
