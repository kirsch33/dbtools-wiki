Remarks

The mode follows the wall function, not the link status.

  • Standard — the wall-bottom base used for linked walls (users see it as linked mode): base reference = wall bottom elevation; the seeding/preview window spans the full wall height.
  • Foundation — the foundation-top base: base reference = top of the basis foundation wall; the seeding/preview window is the fixed foundation seed band.
