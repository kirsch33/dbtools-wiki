Class RevitCallbackRelay

Namespace
dbtools.Presentation.RevitCallback

A callback object for Revit whose type belongs to the never-reloaded tier. Revit keeps some callbacks after the call that received them; for example, it keeps native copies of failure handling options, with their failures preprocessor, until it next pumps. A reloadable callback held that way keeps its Dev Mode generation alive while a reload proves the generation unreachable. Revit holds this relay instead.

Remarks

The relay is a DispatchProxy, so Presentation needs no Revit API reference. The runtime defines the proxy type in the current contextual-reflection context and caches it per base-type context; commands run inside their generation's context, so dbtools.Presentation.RevitCallback.RevitCallbackRelay.CreateProxy<TCallback>() enters Presentation's context first and the type is as stable as Presentation. A forwarding relay holds its target until Release(object); a constant relay never holds a reloadable object.
