ExternalReferenceKey

Identity of a discovered external reference, keyed by its case-normalized absolute path and typed LinkType. Replaces the loosely-named (string, int) tuples that previously cast the enum down to System.Int32. The path must already be normalized via WindowsPathOperations.NormalizeCaseFullPath before construction so equality matches the prior tuple semantics.
