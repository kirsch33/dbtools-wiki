Class ElevationRules

Namespace
DBTools.SGT.Domain.Geometry
Assembly
DBTools.SGT.dll

Elevation semantics for SGT. Canonical rule: UI/plan elevations are stored as feet ABOVE the plan base reference.

  • Standard (linked) mode: base reference = wall bottom elevation
  • Foundation mode: base reference = top of basis foundation wall (seed window starts here)
