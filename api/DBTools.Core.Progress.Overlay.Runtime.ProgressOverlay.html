WPF implementation of IProgressOverlay bound to the overlay host state of one owner Window. Public instance operations marshal their overlay UI changes to the Dispatcher of the owner window: a direct call on the owner thread, Dispatcher.Invoke from any other thread. The static For factory does not marshal; call it on the UI thread of the owner window. CancelRequested is a thread-safe snapshot that workers can read directly.

RunAsync(string, Func<CancellationToken, IProgressOverlay, Task>, bool, ProgressOverlayRunOptions?, CancellationToken)

Runs work with an overlay lifecycle managed by the overlay implementation. This is the preferred API for long-running operations because it allows the overlay to guarantee first paint (when requested), enforce minimum visible duration, and bridge cancellation consistently across tools. A second run against the same window while one is active is rejected with InvalidOperationException.
