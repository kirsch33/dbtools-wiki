Remarks

Instance operations change UI state directly on the owner thread or through Dispatcher.Invoke from other threads. Call the static For factory on the owner's UI thread. CancelRequested is a thread-safe snapshot available to workers.

For(Window, ILogger)

Creates a progress overlay bound to the specified owner window. Call it on the UI thread of the owner window: it reads and attaches the overlay host state of the window on the calling thread without dispatcher marshaling, so a call from another thread throws the WPF thread-affinity InvalidOperationException.

Remarks

This is the API for long-running operations: the overlay can guarantee first paint (when requested), enforce a minimum visible duration, and bridge cancellation consistently across tools. A second run against the same window while one is active is rejected with InvalidOperationException.
