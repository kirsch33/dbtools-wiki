DBTools.Core.dll

Production base for auto-update settings pack contexts. Owns the shared mechanics: header text, auto-update/warning toggle state, clear-warning command, pending-change tracking against a saved baseline, and state-change notification. Derived contexts own everything shaped by their settings type: bindable values, snapshot construction, baseline equality, and validation rules.
