Resolve(EditableOpeningRow, OpeningMemberConfig?, double, double, IEnumerable<double>?, IReadOnlyDictionary<string, double>?)

Jamb extent for an opening row being edited. A missing or unresolvable grid target returns a typed failure, so the editor can refuse the edit. A null config extends each end from the opening edge to the nearest girt beyond it, or to the wall base or top when there is no such girt.

public static Result<MemberAxisRange, SpecFailure> Resolve(EditableOpeningRow opening, OpeningMemberConfig? config, double baseElevation, double topElevation, IEnumerable<double>? girtElevations, IReadOnlyDictionary<string, double>? girtElevationByKey)

Parameters

opening EditableOpeningRow

Opening row whose elevation range is relative to baseElevation.

config OpeningMemberConfig

Jamb settings, or null; their override elevations are relative to baseElevation.

baseElevation double

Absolute plan base elevation in feet: the wall bottom, or the foundation top in Foundation mode.

topElevation double

Absolute plan top elevation in feet: the wall top, or the base plus the seed band in Foundation mode.

girtElevations IEnumerable<double>?

Girt elevations relative to baseElevation, searched for the nearest girt beyond each opening edge.

girtElevationByKey IReadOnlyDictionary<string, double>?

Girt elevation relative to baseElevation by girt member key, in an ordinal map.

Returns

Result<MemberAxisRange, SpecFailure>

The jamb range in absolute elevations, or the typed failure.
