Interface ITransactionGroupService

Namespace
dbtools.Core.Revit.Transactions.TransactionGroup

Groups the active document's transactions into one Revit undo entry through separate begin and finalize calls.

public interface ITransactionGroupService

Remarks

Revit rolls back an open group when the API callback that started it returns. An owned group must therefore begin and finalize through inline call-gate execution within that same callback, as in a modal command. Queued modeless work uses RunAsync<T>(string, Func<CancellationToken, Task<T>>, Func<T, bool>, CancellationToken), whose outcome contract covers an unconfirmed rollback.

On a document that is already modifiable, BeginAsync(string, CancellationToken) creates no owned group but sets IsActive, and finalization only resets that state.

Failures arrive through the returned task, and cancellation cancels it. When cleanup also fails, an AggregateException holds the first failure followed by the cleanup failures.

Remarks

An unsupported finalization value faults the task with ArgumentOutOfRangeException and leaves the session and its group unchanged. A supported value does nothing when no session is active. Commit expects a confirmed commit and Rollback expects a confirmed rollback. Another result raises TransactionFailureException, unless a Revit exception from the assimilation or rollback is already the failure.
