DBTools.Sandbox

DBTools.Sandbox is a standalone executable that validates one product year and hosts tool windows for UI development without Revit. It targets net10.0-windows for Revit 2026.5 and later and for Revit 2027; build/Distribution/RevitYearContract.cs defines the supported years.

Runtime

Sandbox starts a new default-context process for each candidate year. The entry point checks the year directory before any Core, Presentation or WPF type loads, loads the candidate's top-level assemblies and Tools/ assemblies from their paths, and then starts WPF. The candidate files are the only product assemblies in the process; the project compiles against Core, Presentation and HandyControl without copying their runtime files.

Sandbox reads window specifications from the tool manifests through Core's SandboxCatalog and hosts them in the stable Presentation window shells. At startup it calls DBTools.Core.Sandbox.SandboxMode.Activate, so SandboxMode.IsActive is true in this process; tool code checks it to avoid Revit-only services. Building real windows and checking their cleanup requires the Windows process.

For the options, the validation steps and the manifest rules, see Sandbox Validator. See also Sandbox Integration and Assembly Loading Contract.
