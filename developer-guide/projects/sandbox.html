dbtools.Sandbox

NAME

dbtools.Sandbox - preview tool windows with design-time view models

SYNOPSIS

Source    src/dbtools.Sandbox/
Project   dbtools.Sandbox.csproj
Assembly  dbtools.Sandbox.dll
Entry     dbtools.Sandbox.App.Startup.SandboxEntry

DESCRIPTION

dbtools.Sandbox is a Windows WPF application. The dbtools UI Sandbox catalog groups previews by the manifest group and labels each button with the displayName. Select a button to open its preview.

See Sandbox Validator for candidate requirements, startup and headless validation.

STRUCTURE

Paths are relative to src/dbtools.Sandbox/.

Path Role
App/ Contains the entry point, option parser and WPF application.
Composition/ Creates the Sandbox runtime and window sessions.
Features/WindowCatalog/ Lists the windows and launches previews.
Runtime/ Configures logging and the default window owner mode.
Validation/ Checks product metadata and windows.

CONTRACTS

  • The project references Core and Presentation with Private="false" and ExcludeAssets="runtime". Sandbox loads both from the selected year.
  • SandboxCatalog discovers sandboxWindows entries in the manifests embedded in App. Each entry names the raw XAML resource and its design-time view model. See Sandbox Integration for the registration rules.
  • SandboxWindowFactory constructs the view model with its parameterless constructor and creates a ToolWindowHost session. If the view model implements IToolWindowSandboxComposer, the factory calls ComposeView after it creates the session.
  • WindowStaticRuntimeConfigurator sets the default owner mode to Unowned.

FLOW

For a manual preview, use a promoted Revit 2026 distribution on Windows with Revit 2026 installed. Run the commands from the checkout root.

pwsh -NoProfile -File build.ps1 BuildSandbox -y 2026
.\.artifacts\sandbox\Release\2026\net10.0-windows\dbtools.Sandbox.exe `
  --dist-dir .artifacts\dist\Release\2026

DATA

BuildSandbox writes to .artifacts/sandbox/<Configuration>/<year>/net10.0-windows/.
