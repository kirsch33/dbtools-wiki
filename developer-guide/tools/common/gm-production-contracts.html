GM Production Contracts

These Global Mapper (GM) behaviors are performance or correctness requirements. Each section names the source that implements the contract and the effect of breaking it. A change to a contract is a product change; update this page with it. See Global Mapper for the tool design.

Paths are relative to src/Tools/Common/GM/.

Usage index sampling cap

Features/Usage/Revit/Operations/Indexing/UsageIndexSource.Families.cs, QuerySampleInstanceIdsBySymbol

The usage index samples one family instance per family type (symbol), at most 2500 instances (MaxSampleInstances in UsageIndexSource.cs). It streams view-independent (model) instances first and returns as soon as it has 2250 samples. Only when the model instances give fewer than 2250 samples does it add view-owned instances of the active view, up to the cap.

Unbounded iteration scales with views times instances: a project with 200 views and 50,000 instances stalls for minutes.

One geometry pass per usage kind

Features/Usage/Revit/Operations/Indexing/StyleMaterial/UsageStyleMaterialCollector.cs, QueryStyleMaterialUsageChunk

Style and material usage are captured from the same sample. Instance geometry is requested once for styles and once for materials, both with IncludeNonVisibleObjects = true. Symbol geometry is requested only when the instance has no geometry.

Style geometry uses the owning or active view; material geometry uses view-independent Fine detail. Sharing one geometry result between them changes coverage. The combined chunk shares element lookup and the traversal of family-dependent styles.

One instance for parameter discovery

Features/Families/Revit/FamilyScanner.ParameterNames.cs, QueryMappableParamNamesForFamily

Parameter-name discovery reads the parameters of every type of the family and of one instance. Parameter definitions are family-level, so every instance has the same definitions; scanning more instances adds cost and no data.

Deep scan runs only on request

Features/DeepScan/Workflow/DeepScanWorkflow.cs

A deep scan opens family documents with EditFamily, which takes seconds per family. It runs only from a user action: Scan Family on a family row, deep scan of all visible families, or deep scan of unscanned families with zero instances (after a confirmation). Background prewarm only reads the deep scan cache; it never starts a scan. See GM specification.

Parameter discovery filter

Revit/ParameterDiscovery/ParameterDiscoveryEligibility.cs

Discovery excludes read-only parameters, built-in parameters (InternalDefinition with a valid BuiltInParameter) and blank definition names. It does not filter on UserModifiable, because Revit can report a parameter that the API can write as not user-modifiable.

Removing the read-only or built-in filter offers parameters that cannot be written or should not be mapped. Adding a UserModifiable filter hides valid mapping targets.

Simple style canonicalization

UsageStyleMaterialCollector.RecordStyle; Features/Usage/Revit/Operations/Indexing/UsageIndexSource.StyleMaterial.cs, BuildStyleCanonicalizationMap

Style usage records the raw style ID and its canonical projection ID only. Recording every equivalent alias multiplies dictionary insertions per geometry object without improving the result.

Style maps built once per usage build

UsageIndexSource.StyleMaterial.cs, BuildStyleMaterialUsageAsync

Style canonicalization, category projection and object-style classification run once per usage build, and their results are passed to each chunk of 25 instances (UsageChunkSize). Rebuilding them per chunk repeats a full FilteredElementCollector scan for every chunk.
