dbtools.TDV

NAME

dbtools.TDV - transfer drafting views between a project and a library

SYNOPSIS

source    src/Tools/Common/TDV/ (manifest.yml)
assembly  dbtools.TDV
entry     TdvToolModule
commands  TdvImportCommand, TdvExportCommand

DESCRIPTION

WindowSession delegates library selection to LibrarySelectionDialog and opens the modal transfer window. TransferSession holds the source and destination for the window.

STRUCTURE

Path under the tool source Owner
App/Composition/ TdvToolModule registers settings. AddTdv registers scoped services.
App/Sessions/ WindowSessionDialogRunner handles close and retirement.
Features/Library/ LibraryCatalog resolves paths. LibrarySelectionDialog builds the picker. LibraryDocumentService manages documents.
Features/Transfer/Execution/ See TransferExecutor.ApplySelectionAsync and DestinationTransactionGroup (RunItemAsync, FinalizeAsync).
Features/Transfer/Operations/DraftingView/ DraftingViewTypeResolver and DraftingViewWriter.
Features/Preview/ PreviewExporter, PreviewImageExporter and PreviewCache.

DraftingViewWriter.CollectViewElementIds compares Category.Name with the English keys in s_skipCategoryNames, so the check matches only those English names. See the same method for the Viewport type check and the ExtentElem substring check.

CONTRACTS

  1. TransferExecutor.ApplySelectionAsync requires one continuous Revit API callback. TransferExecutorTests checks callback entry.
  2. DestinationTransactionGroup uses the requested document even when another document is active. EnsureOwns rejects any other document. DestinationTransactionGroup_BindsBeginItemAndFinalizeToOneNonActiveDocument checks the binding.
  3. Projection and execution trim names with TransferNameNormalizer. In TransferExecutorTests, DraftingViewReader_and_TransferCatalog_project_only_current_drafting_views_and_conflicts checks case-insensitive matching. Transfer_WhenDuplicateDestinationNamesAreSelected_FailsWithoutCreatingRenamedCopies and Transfer_WhenDestinationNameExistsAndReplaceFalse_ReportsConflictWithoutCreatingView check name rejection. See TransferExecutor.TransferSelectionItemAsync for validation and transaction order.
  4. For Retain Original, TransferExecutor.ResolveDestinationType lets EnsureDestType create a missing type. TransferExecutorTests checks that EnsureDestType creates a requested type and refuses a missing named type.
  5. TransferRunState counts and reports row successes after Committed. Transfer_DraftingView_From_GM_To_SGT checks success reporting after finalization. RunSelectionAsync checks Cancel before each view and after the final transaction group health check. The executor rolls back the group when it observes Cancel or when starting the group fails after it opens. Transfer_WhenReporterCancelsDuringFirstRow_RollsBackAndStops checks rollback with one view and with another view pending. TransferDestinationChangesTests checks window totals and unverified changes.

TransferProjectorTests checks the conflict display and the display for rolled-back or unknown outcomes.

FLOW

  1. LibrarySelectionWorkflow opens the picker even when no configured path is valid. LibrarySelectionDialog offers Browse for file in every case. When valid and invalid paths both exist, it reports the unavailable count. LibraryDialogOptions sets the initial size to 660 by 460 device-independent units. The alert owns the file picker. Canceling the file picker leaves the alert open. Before validating the choice, the workflow rejects the active model and its central path. A browsed path applies to one workflow. LibrarySelectionDialogTests and LibrarySelectionWorkflowTests check the selection routes.
  2. LibraryDocumentService checks the saved Revit year before opening. LibraryDocumentServiceTests checks year refusal and both open routes.
  3. Before releasing the library, LibraryTransferWorkflow.ReactivateHostDocument restores the project captured by the command if the active document changed. A preview export can activate the library, and Revit refuses to close the active document.
  4. ImportTransferWorkflow requests discard. ExportTransferWorkflow saves or synchronizes when TransferDestinationChanges.Any is true, including Unverified changes. It otherwise requests discard. TransferWorkflowTests checks these routes.
  5. On retirement, WindowSession defers library release until any active transfer ends. TdvWindowViewModelTransferTests checks the timing. TransferWorkflowTests checks release without queuing a call-gate operation.

DATA

The core.library pack binds Core.MasterLibrary to LibraryOptions. The Files list starts empty. Each LibraryFile entry has MainPath, FallbackPath and Alias. LibraryCatalog uses a valid fallback when the main path is missing or invalid. LibrarySettingsContext.Load skips fallback-only entries.

LibrarySettingsContext flags entries with a main path and no valid path. The core.library.invalid warning reports those entries in Settings and leaves both transfer commands available.

CachePaths defines the cache roots. PreviewImageExporter exports a PNG with a horizontal fit and a size setting of 1024 pixels. It takes the pane color from the PNG's upper-left pixel or from ColorOptions.BackgroundColor if the pixel is fully transparent. PreviewCache retains up to 32 paths and colors. It evicts the oldest inserted entry first. WindowSession.CleanupViewModel requests directory cleanup on close. PreviewCacheTests checks the limit and directory deletion. Workshared_library_sync_and_reopen_persists_changes_and_removes_local_workspace checks workspace removal after sync and discard closes. See LibraryDocumentService.TryDeleteWorkspaceForLocalPath for cleanup.

DIAGNOSTICS

Match transfer logs by RunId and read FinalizationOutcome. SaveAndCloseAsync_WhenSaveAndCloseBothFail_PreservesPrimaryThenClose checks the order of errors when library save and close both fail.
