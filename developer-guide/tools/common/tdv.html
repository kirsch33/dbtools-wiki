DBTools.TDV

NAME

DBTools.TDV - the assembly behind Import From Library and Export To Library

SYNOPSIS

source    src/Tools/Common/TDV/   (MAP.md, manifest.yml)
assembly  DBTools.TDV
entry     TdvToolModule
commands  TdvImportCommand, TdvExportCommand   (run profile InlineUi)
views     App/Views/TdvWindow.xaml, Features/Library/Settings/Views/LibrarySettingsView.xaml
behavior  src/DBTools.Presentation/Tools/TDV/TdvPanZoomBehavior.cs

DESCRIPTION

The commands run ImportTransferWorkflow and ExportTransferWorkflow. Both use LibraryTransferWorkflow to select a library and LibraryDocumentService to open it without activating it. WindowSession then shows the modal window, and TransferExecutor copies the checked views into the destination document. The user page describes the behavior.

STRUCTURE

Paths are under src/Tools/Common/TDV/.

Path Contents
App/Composition/ TdvToolModule registers the settings section and the core.library pack. ServiceCollectionExtensions.AddTdv registers scoped services, because they need the scoped call gate and transaction runner.
App/Sessions/ WindowSession implements ILibrarySelectionDialog and ITransferDialog. WindowSessionDialogRunner owns the modal loop and Dev Mode retirement.
App/ViewModels/ TdvWindowViewModel partials: rows and filters, transfer and result dialog, preview.
Features/Library/ LibraryCatalog, RevitYearProbe, LibraryDocumentService, the settings context and view, and the library workflows.
Features/Transfer/ TransferExecutor partials, DestinationTransactionGroup, the DraftingView reader, type resolver and writer, TransferProjector, and the import and export workflows.
Features/Preview/ PreviewExporter, PreviewImageExporter and PreviewCache.

CONTRACTS

  1. One callback. TransferExecutor.ApplySelectionAsync throws InvalidOperationException unless RevitCallGateApiContext.IsActive is true. It also rejects one document as both source and destination. TransferExecutorTests checks the callback and cancellation guards.
  2. One group for each transfer. DestinationTransactionGroup binds to the document given to BeginAsync, rejects any other document, and never uses the active document. Each row runs in its own transaction, Transfer: <name>. FinalizeAsync assimilates the group Transfer Drafting Views on success. It rolls the group back on cancellation or an operation failure. DestinationTransactionGroup_BindsBeginItemAndFinalizeToOneNonActiveDocument checks this.
  3. Deferred success. Row successes and counts wait until the group finalization reports TransferFinalizationOutcome.Committed. RolledBack marks attempted rows TransactionRolledBack. Unknown marks them Unknown and counts no success. TransferProjectorTests checks the projection.
  4. Names. TDV adds no suffix. Blank names, duplicate names and, without Replace, existing names fail with DestinationNameRequired, DuplicateTargetName and DestinationNameConflict before the row transaction. The checks trim the names and ignore case. TransferProjector.BuildConflictRefreshAsync applies the same rules in the window. TransferProjectorTests checks them.
  5. Types. DraftingViewTypeResolver.EnsureDestType creates a missing type only for Retain Original, by duplicating the first destination drafting type in name order. A named type that is missing fails. Revit tests in TransferExecutorTests check the creation and the refusal, but not the seed order.
  6. Copy. DraftingViewWriter skips viewports, elements whose name contains ExtentElem, and the categories in s_skipCategoryNames. The check compares Category.Name with English names. It copies one element at a time with UseDestinationTypes, groups first. It pairs each source group member with its copy, so the overrides reach the members. Transfer_DraftingViewGroup_PreservesPerElementOverridesOnGroupMembers checks the overrides.
  7. Revit year. LibraryCatalog and LibraryDocumentService.OpenLibraryAsync both use RevitYearProbe. Open throws on a mismatch, so Revit never upgrades a library and CreateNewLocal never sees another version. OpenLibraryAsync_WhenFileYearMismatchesSession_FailsLoud checks this.
  8. Warning. LibrarySettingsContext.ValidateAsync fails when an entry has neither a valid main path nor a valid fallback. Validation_marks_each_tree_path_and_returns_a_contextual_failure checks this.
  9. Close. Save and sync always close the library. A Document.Close that returns false throws. When the save or sync and the close both fail, the save or sync failure comes first in the AggregateException. TryClose returns false only for the active document. LibraryDocumentServiceTests checks the failure order and the active-document refusal.
  10. Window totals. TransferDestinationChanges adds the committed changes of every transfer in a window. A transfer that ends without a verified commit or rollback sets Unverified. An export saves or syncs the library when Any is true, and discards it only when it is false. TransferDestinationChangesTests and TransferWorkflowTests check this.

FLOW

  1. LibraryTransferWorkflow calls LibrarySelectionWorkflow, which builds a LibraryCatalog from the settings. It throws SafeExecutionRefusedException when the settings hold no path or no valid path.
  2. OpenLibraryAsync copies a workshared library with CreateNewLocal and opens all worksets. It opens other files in place. Both use Application.OpenDocumentFile, so the host stays active.
  3. ITransferDialog.ShowDialog takes the destination, the source and the column header. An import passes the host, the library and Import?. An export passes the library, the host and Export?.
  4. After an import, TryCloseAsync discards the library. After an export with changes, SyncAndCloseAsync or SaveAndCloseAsync persists and closes it. Without changes, TryCloseAsync discards it. Then ReactivateDocument activates the host with OpenAndActivateDocument.
  5. A window failure travels in TransferDialogResult.WindowFailure. The workflow persists or closes the library first and then throws it. A Dev Mode retirement releases the library in its own Revit callback: ExportTransferWorkflow.ReleaseLibraryOnRetirement saves or syncs a changed library synchronously. When a transfer runs at that moment, TdvWindowViewModel.ReleaseWhenNoTransferRuns runs the release after the transfer commits or rolls back.

DIAGNOSTICS

Most log lines start with [TDV]. Each transfer logs Begin transfer run <id> and Completed run <id> with the counts and FinalizationOutcome. A row failure logs a warning with its exception, and the row keeps only the code and message.

TESTS

./test.sh test --tool TDV                         # pure scope, the default
./test.sh test --tool TDV --scope local -y 2026   # -y 2027 for Revit 2027

Pure tests cover the catalog, path formatting, settings, library selection, conflict projection, rows, the preview cache and the dialog runner. Local tests cover the executor, the document service, the workflows, the window session and the view model. LibraryDocumentServiceTests includes a workshared round trip on a temporary central model. The Revit tests open gm_test_model.rvt and sgt_test_model.rvt (Model paths). TdvPanZoomBehaviorTests lives in src/DBTools.Presentation/Tests/.
