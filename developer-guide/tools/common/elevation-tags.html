dbtools.ElevationTags

NAME

dbtools.ElevationTags - align spot elevations and set symbol text

SYNOPSIS

source    src/Tools/Common/ElevationTags/ (manifest.yml)
assembly  dbtools.ElevationTags
entry     ElevationTagsToolModule
commands  ElevationTagsCommand, ElevationTagsSymbolTextCommand

DESCRIPTION

ElevationTagsCommand calls AlignElevationTagsWorkflow.Execute. Manual alignment and AlignOnViewActivatedTask share ElevationTagAlignmentService. ElevationTagsSymbolTextCommand calls SymbolTextWorkflow. See Elevation Tags.

STRUCTURE

Path Owner
App/Composition/ ElevationTagsToolModule registers the settings pack.
Domain/ SpotElevationNameFilter owns the default patterns and name matching.
Features/ SpotElevationTextAligner owns alignment. SpotElevationSymbolResolver owns symbol lookup. SpotElevationTypeProjector builds type snapshots.
Features/SymbolText/ SymbolTextPolicy owns text validation, InvalidTextMessage, and <name> - <text> variant names. SymbolTextEditor owns assignment and cleanup.
Settings/ SettingsPackContext provides patterns, offsets, and preview state to ElevationTagsSettingsPackView.xaml.

CONTRACTS

  • Change the plan-view checks together. See AlignElevationTagsWorkflow.IsSupportedPlanView, AlignOnViewActivatedTask.ShouldRunInternalAsync, and SpotElevationTextAligner.IsSupportedPlanViewName. ElevationTagsLogicTests checks the aligner's view names.
  • SpotElevationNameFilter uses DefaultTagNamePatterns when no pattern is entered. Align and Live Preview use interpreted, case-insensitive regexes. SpotElevationNameReader supplies the aliases to Align and the projector. The preview empty state lists the entered patterns. The settings pack saves an empty list when the only entered pattern is the default. The view binds directly to SettingsPackContext.PatternList. Core's RegexPatternListContextTests checks the configured row limit. SettingsPackContext.CollectValidationErrors checks settings patterns.
  • Change ComputeTextOffset and SpotElevationPreviewLayout together. SpotElevationPreviewLayoutTests checks that both place text on the same side of the leader.
  • ElevationTagsSettingsPackView.xaml binds the single caption below the preview to PreviewContext.PreviewTextLocationName. It shows the caption while a type matches the patterns.
  • See ViewActivationTask.AdmitAsync for settings and warning checks. ViewActivationTaskTests checks the settings snapshot and the Common panel gate in PanelScopedViewActivationTask.AdmitAsync.
  • ElevationTagsSymbolTextCommand.IsCommandAvailableCore owns the project document gate. SymbolTextEditorTests.Command_is_available_only_while_spot_elevations_are_selected checks availability for spot, level, and empty selections in a project.
  • SymbolTextVariantMarker.Read owns marker validation. SymbolTextEditorTests checks source-family text validation, reuse, copied-marker rejection, and cleanup of departed variants. It checks rollback when deletion would remove dependent spots.

FLOW

AlignElevationTagsWorkflow.Execute owns the unsupported-view toast. BuildSummary owns the result messages. SpotElevationTextAligner.Run owns the alignment transaction. Runner.Run includes name and update failures in FailedCount. SpotElevationTextAlignerTests checks those counts and the transaction call for matching candidates.

SymbolTextEditor.Apply puts family loading and spot type assignment in one transaction group. See GetOrCreateSymbol for the edit and load order. SymbolTextEditorTests checks rollback when a later type conflicts.

DATA

ElevationTagsSettings.cs defines the defaults for Tools.ElevationTags. TypeOffsets stores paper inches by type name. SpotTextLocationParser maps SPOT_ELEV_TEXT_LOCATION values.

SymbolTextVariantMarker.cs defines the Revit Extensible Storage schema. SymbolTextEditor.Families.cs defines the temporary .rfa path.

The common.elevation_tags pack declares core.common.elevation_tags. manifest.yml names dbtools.AlignElevationTagsInView as the warning's only ribbon target. ElevationTagsToolModuleTests checks that the module passes its target and WarningIdsToSetOnFailure through. For activation on admission failure, see ViewActivationTaskRegistry.RecordAdmissionFailure and Hooks. ViewActivationTaskRegistryTests.ActivateFailureWarnings_ActivatesTaskWarnings checks activation of the registered warnings.

DIAGNOSTICS

Search for [ElevationTags] in these files.

  • SpotElevationTextAligner.Run.cs has warnings for invalid patterns, lists with no valid patterns, and failed updates. Run_LogsTheFirstUpdateFailureOfEveryRun checks the update warning.
  • SpotElevationTextAligner.cs has warnings in CollectWorkItems and the units-format warning in BuildTagText.
  • AlignOnViewActivatedTask.cs has the partial-failure warning.
  • SymbolTextTemporaryDirectory.cs has the temporary-folder removal warning.
  • SymbolTextEditor.Cleanup.cs has Kept and Removed entries. See TryDeleteSpotType and TryDeleteVariant for the warning about workshared elements another user owns.
  • SpotElevationTypeProjector.cs, SpotElevationSymbolResolver.cs, and SymbolTextEditor.cs contain the remaining diagnostics.

TESTS

The Revit fixture in Tests/Integration/Revit/Features/AlignElevationTagsWorkflowTests.cs checks placement in rotated plans. It and SymbolTextEditorTests use gm_test_model.rvt and an installed spot elevation symbol template. See Model paths.

The Presentation Local fixture ElevationTagsSettingsPackViewTests checks the compiled view and its local resources in Revit.
