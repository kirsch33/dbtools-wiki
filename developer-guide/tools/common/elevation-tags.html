NAME

dbtools.ElevationTags - the assembly behind Align Elevation Tags and Set Elevation Symbol Text

SYNOPSIS

source    src/Tools/Common/ElevationTags/           (MAP.md, manifest.yml)
assembly  dbtools.ElevationTags
entry     ElevationTagsToolModule

          ElevationTagsSymbolTextCommand  dbtools.SetElevationSymbolText     (run profile InlineUi)
view      src/dbtools.Presentation/Tools/ElevationTags/ElevationTagsSettingsPackView.xaml

DESCRIPTION

The Align command and the view-activation task both call ElevationTagAlignmentService.Run. It runs SpotElevationTextAligner on the active view in one transaction. The settings pack draws the same placement with SpotElevationPreviewLayout. Set Elevation Symbol Text runs SymbolTextWorkflow, which asks for the text, and SymbolTextEditor, which copies families and types. The user page describes the behavior.

CONTRACTS

  1. Placement. SpotElevationTextAligner.ComputeTextOffset owns the rule. f = view.Scale / 12 converts paper inches to model feet. The near edge of the text is 2f/128 + f/8 from the leader end along the shoulder (the margin), and f/64 from the shoulder line (the gap). Above Leader and Below Leader take the side toward the spot origin. A rise within LevelTolerance (1e-9 of the leader length) counts as a leader that runs down. The Text Location only selects the edge that TextPosition marks, so the text box does not move: the bottom center for Above Leader, the top center for Below Leader, and the top corner nearest the leader end for In-line with Leader. The current text position plays no part, so a second run moves nothing. ComputeTextOffset_places_the_text_by_text_location_and_leader_direction and the Revit AlignElevationTagsWorkflowTests check this.
  2. Preview follows Align. SpotElevationPreviewLayout holds the margin and the gap at f = 1 in its own constants, LabelGapFromLeaderEnd and LabelGapFromShoulder. Change them together with ComputeTextOffset. Preview_and_align_place_text_on_the_same_side checks only the side.
  3. Font size. SpotElevationTextFont.EmSizeInches makes the capital height equal TEXT_SIZE, for Align and the preview. Align measures with GDI+. Shared_font_em_size_gives_the_capitals_the_requested_height checks the rule.
  4. Matching. Align compiles the nonblank patterns with IgnoreCase. An empty list means DefaultTagNamePatterns. A bad pattern is logged and skipped. TypeSelection filters the preview by type name only, with case. CollectValidationErrors blocks Save without a nonblank pattern or with a bad one. Run_FiltersByConfiguredPatterns_AndCountsOnlySuccessfulUpdates checks Align.
  5. Failures. A spot whose names cannot be read, and a spot whose update throws, add to FailedCount. The first of each kind is logged. Collection and transaction failures propagate. Run_CountsSpotsThatCouldNotBeFilteredByNameAsFailed and Run_LogsTheFirstUpdateFailureOfEveryRun check this.
  6. Text Location. SpotTextLocationParser.ParseTextLocation maps 0, 1 and 2 to AboveLeader, BelowLeader and InLineWithLeader, and throws for any other value. Align counts that spot as failed, and the preview leaves the type out. ParseTextLocation_rejects_a_missing_or_unknown_value checks this.
  7. Elevation base. TryUpdateSpot compares the SPOT_ELEV_BASE display string with Project Base Point and Relative. For the first, it subtracts the base point Z when the base point and the survey point differ in any coordinate. No test covers another Revit language.
  8. Auto-update admission. ViewActivationTask.AdmitAsync skips the task when AutoUpdateEnabled is false or the pack warning is active. ShouldRunInternalAsync admits only FloorPlan, EngineeringPlan and CeilingPlan. A failure in the run shows the Core error banner, and ViewActivationHook skips the task for that document session (DocumentSessionKey); it sets no warning. A failure in AdmitAsync also sets the pack warning. AlignOnViewActivatedTaskTests checks the run failure.
  9. One Undo step for symbol text. SymbolTextEditor.Apply runs in the transaction group dbtools - Set elevation symbol text, and assimilates it or rolls it back. EditFamily runs with no project transaction open. A variant gets its text in the family document, is saved as <name>.rfa in a unique temporary folder, and is loaded by path. SymbolTextTemporaryDirectory deletes the folder and only logs a failure. SymbolTextEditorTests and SymbolTextTemporaryDirectoryTests check this.
  10. Reuse. A family with the variant name is reused only when its one text element holds the text, and a spot type only when it uses that symbol. The source family must hold one text element even when the variant exists. SymbolTextPolicyTests and Apply_validates_source_text_even_when_the_target_already_exists check this.
  11. Owned variants. SymbolTextVariantMarker stores ElementId, SourceId (both UniqueId values), SourceName and Text. The marker is valid only on the element whose UniqueId is in ElementId, with the name <SourceName> - <Text>. Cleanup looks only at the marked types that the selected spots leave, and at their marked families. It deletes one only when nothing else uses it, no other worksharing user owns it, and Revit deletes nothing else with it. Apply_cleans_only_unused_owned_variants_and_keeps_copied_or_user_types and TryDeleteVariant_rolls_back_a_native_host_deletion_that_also_removes_spots check this.

FLOW

  1. AlignElevationTagsWorkflow.Execute refuses an unsupported view with a Warning banner.
  2. SpotElevationTextAligner.Run collects the OST_SpotElevations instances in the view and matches their names. Without a match, it starts no transaction.
  3. One transaction, dbtools - Align spot elevations, calls TryUpdateSpot for each match. It skips a spot without a leader and a Relative base. BuildTagText builds the text to measure: the elevation in the type's units, with the indicator, or with EL. when the indicator is blank. MeasureTag measures it, and ComputeTextOffset places it along RightDirection and UpDirection.
  4. The spot gets the computed TextPosition when X or Y differs after rounding to two decimals of a foot. Z stays.

DIAGNOSTICS
