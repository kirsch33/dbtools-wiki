Analytical Snap To Level

Analytical Snap To Level moves selected analytical members to a chosen level elevation. Beams move both endpoints. Columns move the endpoint nearest the target elevation and retain the other endpoint. X and Y coordinates remain unchanged. A column tie moves the start endpoint.

Use

  1. Select analytical members.
  2. Run Analytical Snap To Level on the Structural panel.
  3. Choose a level from the elevation-sorted level picker.
  4. Read the processed and skipped counts in the completion alert.

The ribbon accepts any nonempty selection through CommandAvailability.HasSelection. Processing requires OST_AnalyticalMember, an AnalyticalMember instance, and structural role Beam or Column. The curve must be a straight Line. Girder, Member, Unset, and other roles are skipped. The tool has no persistent settings.

Execution

Source: src/Tools/Structural/AnalyticalSnapToLevel/. App/Composition/AnalyticalSnapToLevelCommand resolves Features/AnalyticalSnapToLevelWorkflow. The workflow uses IAlertService for the level picker and completion alert, ITransactionRunner for changes, a window-owner provider, and a typed logger. It ensures the logger window through ILoggerWindowHost after successful completion when Debug Mode is enabled.

The public snapper boundary is:

public AnalyticalSnapper(ITransactionRunner tx, Document doc, ILogger logger);
public (int ProcessedCount, IReadOnlyList<(ElementId ElementId, string Reason)> Skipped)
    Run(ICollection<ElementId> selectedIds, Level targetLevel);

AnalyticalSnapper.Run(ICollection<ElementId>, Level) returns ProcessedCount and an ordered list of (ElementId, Reason) skips. AnalyticalSegment.SnapTo owns the pure endpoint rule. AnalyticalSnapper resolves the typed Revit structural role, constructs the adjusted line, and calls SetCurve. A processed member counts even when its endpoint elevations already match the target.

All members run in one DB Tools - Snap Analytical Elements to Level transaction. Unexpected failures, including a SetCurve refusal, propagate to safe execution and roll back the entire run. An empty selection or a missing level choice produces SafeExecutionRefusedException. The level picker returns no choice when the document contains no levels.

Skips and diagnostics

Reason Constant on AnalyticalSnapper Condition
not an analytical member NotAnalyticalMember Missing element, wrong category, or wrong runtime type
role not supported RoleNotSupported Structural role is neither Beam nor Column
not straight NotStraight Curve is not a Line
would collapse WouldCollapse Adjusted length is less than Application.ShortCurveTolerance

The completion alert groups skips in first-seen reason order. Each group shows its count and at most ten element IDs, followed by and N more when needed. The non-analytical group shows only its count. Debug logs include the target level, per-element skip or success, and final totals.

Registration and tests

manifest.yml registers DBTools.AnalyticalSnapToLevel with the command and availability type DBTools.AnalyticalSnapToLevel.App.Composition.AnalyticalSnapToLevelCommand. The button uses InlineUi, icon key analytical_snap, and order 20 on the Structural panel. The assembly is DBTools.AnalyticalSnapToLevel.

Pure tests cover endpoint geometry through AnalyticalSegmentTests and AnalyticalSegmentEdgeCaseTests. Hosted workflow tests cover skip-summary behavior. Revit integration tests live under Tests/Integration/Revit/ and exercise the command, workflow, and analytical curve changes.
