dbtools.AnalyticalSnapToLevel

NAME

dbtools.AnalyticalSnapToLevel - snap analytical members to a level

SYNOPSIS

source    src/Tools/Structural/AnalyticalSnapToLevel/ (manifest.yml)
assembly  dbtools.AnalyticalSnapToLevel
entry     AnalyticalSnapToLevelCommand

DESCRIPTION

AnalyticalSnapToLevelCommand reads the selection. AnalyticalSnapToLevelWorkflow prompts for a target level and passes its elevation and the selected IDs to AnalyticalSnapper. See Analytical Snap To Level.

STRUCTURE

File Owner
App/Composition/AnalyticalSnapToLevelCommand.cs CommandAvailability.HasSelection gates the command. [CommandService] declares the workflow for App to register.
Features/AnalyticalSnapToLevelWorkflow.cs The workflow owns the level choices and the completion alert.
Features/AnalyticalSnapper.cs Run checks selected elements and writes Revit curves.
Features/AnalyticalSegment.cs SnapTo computes endpoint coordinates on plain values.

CONTRACTS

  • SnapTo sets both endpoint Z values for a Beam. For a Column, it changes the Z of the nearer endpoint, using the start on a tie. It preserves X and Y. AnalyticalSegmentTests checks the endpoint rules.
  • See AnalyticalSnapper.Run and TryResolveRole for member and role checks. AnalyticalSnapToLevelWorkflowTests checks the column curve and the skips for arcs, unsupported roles and curves that would collapse.
  • AnalyticalSnapToLevelWorkflowTests checks that Execute refuses an empty selection or a cancelled picker before changing member curves. AnalyticalSnapWorkflowTests checks the completion alert's window title, bullet list, skip reason grouping, and ID limit.

FLOW

  1. ReadLevelOptions reads each level's name and elevation. PickTargetLevel passes these values to IAlertService.SelectSingle.
  2. AnalyticalSnapper.Run owns the transaction and curve writes. See BuildAdjustedCurve for the short-curve check.
  3. CreateCompletionRequest builds the completion alert from the processed count and the skip reasons.
  4. After the alert, Execute calls EnsureWindowIfDebugMode. AnalyticalSnapToLevelWorkflowTests.Execute_HappyPath_SnapsSelectionShowsSummaryAndEnsuresLoggerWindow checks the alert request and the logger call.

DIAGNOSTICS

Debug messages with the prefix [AnalyticalSnap] give the target level, the result for each element and the totals.
