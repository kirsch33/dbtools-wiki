Super Girt Tool (SGT)

Overview

Super Girt Tool (SGT) analyzes one wall, edits girts and opening members in a modal window with 2D and 3D previews, and places tagged structural framing. It supports new systems and contextual editing of stored systems.

The SGT specification defines the data and execution contract. This page is the developer overview. The user guide describes window controls and user procedures.

The payload embeds raw XAML; ToolWindowFactory supplies its modal shell. Sandbox uses the same raw fragments and composition callback.

Data and contracts

PlanStore owns detached accepted plans. UI edits pass through PlanSynchronizationCoordinator; preview and placement consume the same resolved member contracts. PreviewRefreshMode.UIEdit synchronizes UI values before reconciliation, PlanMutation reconciles the plan, and RenderOnly renders accepted state.

Stored systems contain Placed geometry and element identities, baseline settings, and a decision ledger. ISystemRepository provides per-system Save, Load, Exists, Delete, ledger-save, and purge operations. SettingsData.FramingMode stores the framing mode in the placementMode field.

The specification defines resolved geometry, storage, and plan admission and synchronization.

Preview opening context menus use the clicked row's IsReadOnly state for every action. Nonempty explicit jamb-command lists select their first editable row. If none is editable, the command does not use the grid selection. Empty lists and other parameters retain selection fallback.

The preview menu dispatcher sets PreviewStatus and PreviewErrorMessage when a command throws. It logs an Error unless the jamb synchronization controller already logged it. Canvas mouse-up clears the active handle and snap feedback in finally.

Workflows

  1. Launch a new system with a concrete wall target, or edit a stored system with its SystemId.
  2. Analyze the wall, calibrate eligible framing families, warm profiles, and build an admitted plan.
  3. Edit girt and opening rows or preview handles. Invalid fields block synchronization and placement.
  4. Use Change Review to compare the accepted configuration with live geometry. Confirm publishes the analyzed candidate and saves its decision ledger; Place or Update writes framing.
  5. Finish the session. A successful close assimilates its Super Girt Tool transaction group; Cancel, errors, failed close, and forced retirement roll it back.

Target re-pick hides and reopens the same modal session within one synchronous Revit command frame. Cosmetic UI-state writes run separately from model finalization. See window session and feature workflows.

Limitations

SGT requires a document that is not modifiable at launch and an inline Revit call gate (IRevitCallGate.RunsInline) for its modal session. Stored formats other than version 3 are purged within the session group. See the specification limitations for member-role restrictions and the manual Undo check.
