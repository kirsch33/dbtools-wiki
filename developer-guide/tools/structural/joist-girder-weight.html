Joist Girder Weights

Overview

Joist Girder Weights estimates pounds per linear foot and writes the result to a writable Double parameter named Wt. It scans structural framing in the active document. The ribbon command runs manually. A view-activation task runs automatically when enabled.

Data and contracts

Inputs

The configured regex tests the family name. It tests the type name only when the family name is blank. The default family pattern is:

^(?:(?:[BV]?G)|Vulcraft) Joist Girder$

It matches G Joist Girder, BG Joist Girder, VG Joist Girder, and Vulcraft Joist Girder.

Input Resolution Constraint
Number of joists Number of Joists, SpaceNum, Number of Equal Spaces Greater than 1
Span Cut Length, Length Positive internal feet
Depth Depth Positive internal feet
Load Total/point load, or dead plus live load Nonnegative kips
Output Wt Writable Double on the instance or type

Numeric aliases are checked in the listed order, with instance then type lookup for each name. Load resolution prefers instance parameters over same-named type parameters. It rejects multiple populated matches in any Total, Dead, or Live group, even when a Total value exists. One Total value takes precedence over Dead plus Live. Without Total, exactly one Dead and one Live are required.

Force-typed Double values convert from Revit internal units to kips. Unitless numeric values are kips. Text uses invariant numeric parsing and accepts these units:

Units Conversion to kips
Omitted, k, kip, kips Unchanged
lb, lbs, lbf, pound, pounds Divide by 1000
kN, case-insensitive Multiply by 0.2248089431

Examples are 10, 10 kips, 10000 lb, and 45 kN. Blank, negative, malformed, or unsupported-unit text produces an input issue.

Formula

Features/JoistGirder/JoistGirderWeightEvaluator.EstimateWeight(n, load, lengthFeet, depthFeet) returns lb/ft. The calculation converts length and depth to inches.

panelSpacing = lengthInches / n
numberOfPanels = n - 1
totalReaction = loadKips * numberOfPanels / 2
maxMoment = totalReaction * lengthInches / 2

For even n, subtract loadKips * panelSpacing * i for integer steps starting at 1 while i < numberOfPanels / 2. For odd n, subtract loadKips * (panelSpacing / 2 + panelSpacing * j) starting at 0 while j < numberOfPanels / 2.

effectiveDepth = depthInches * 0.95
chordForce = maxMoment / effectiveDepth
requiredArea = chordForce / (50.0 * 0.6)
topChordWeight = requiredArea * lengthInches * 0.28356 * 1.06
bottomChordWeight = topChordWeight * 1.13
webWeight = topChordWeight * 0.7
weightPoundsPerFoot = (topChordWeight + bottomChordWeight + webWeight) / lengthFeet

50.0 is the stress constant in ksi. 0.28356 is steel density in lb/in³. The remaining constants are depth, connection, and member multipliers.

Workflows

Update and failure behavior

JoistGirderWeightUpdater validates candidates and computes weights before opening a transaction. Invalid candidates become skipped items. Valid candidates share Auto Update Joist Girder Weights. An unexpected transaction or setter exception propagates and rolls back that transaction. Updated increments after each setter call returns. See Limitations for count semantics.

The returned summary contains Candidates, Updated, Skipped, and up to five sample issues. Zero candidates returns an empty summary. All-invalid candidates return skipped counts. The manual workflow displays an Info toast when nothing updates, Warning for mixed updated/skipped results, and Success when all candidates update. Configuration exceptions produce a ten-second Warning toast.

Automatic execution catches configuration exceptions, sets the configured warning, and shows a banner. Other runtime faults propagate to Core's view-activation handling. Warning core.structural.joist_girder disables DBTools.UpdateJoistGirderWeights and automatic updates.

Testing

Pure tests cover the evaluator, classifier, patterns, load parsing and resolution, and settings context. Revit-hosted updater and workflow tests use real Revit parameters and roll back model changes. The workflow fixture supplies a WPF owner for banners and closes its own windows after each test.

./test.sh test --tool JoistGirderWeight --scope local -y 2026

Limitations

The formula estimates weight; it does not select manufacturer sections or validate SJI load tables. Updated counts reflect attempted writes whose setters did not throw, including a false Parameter.Set result that leaves the value unchanged.
