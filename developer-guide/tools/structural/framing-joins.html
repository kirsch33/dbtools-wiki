dbtools.FramingJoins

NAME

dbtools.FramingJoins - allow or disallow joins at framing ends

SYNOPSIS

source    src/Tools/Structural/FramingJoins/ (manifest.yml)
assembly  dbtools.FramingJoins
entry     AllowJoinSelectedCommand, DisallowJoinSelectedCommand

DESCRIPTION

Both commands pass a FramingJoinOperation to FramingJoinsWorkflow.ExecuteAsync. See Allow Join and Disallow Join.

STRUCTURE

Path Owner
App/Composition/ Both commands pass Revit's selected categories to CommandAvailability.HasStructuralFramingSelection and declare the workflow with [CommandService].
Features/FramingJoinTargetBuilder.cs The builder filters plain IDs by category.
Features/FramingJoinsWorkflow.cs The workflow collects the selection and owns the transaction and result banner.
Features/FramingJoinsWorkflow.Core.cs ExecuteCore applies one operation to the prepared targets.

CONTRACTS

  • FramingJoinTargetBuilderTests checks category filtering. See FramingJoinsWorkflow.CollectStructuralFramingIds for ID preparation and ExecuteAsync for selection checks and target construction.
  • ExecuteCore calls ends 0 and 1 in order. It counts a target after both calls return. FramingJoinsWorkflowTests checks the calls and the count. FramingJoinsWorkflowRevitTests checks the join state at both ends of a beam.
  • If an end operation throws, ExecuteCore throws InvalidOperationException with the element ID and the original exception. FramingJoinsWorkflowTests checks this error.

FLOW

  1. ExecuteAsync reads UIDocument.Selection and pairs each selected ID with its document category for CollectStructuralFramingIds.
  2. For selected framing family instances, it prepares JoinOperationTarget delegates for StructuralFramingUtils.AllowJoinAtEnd and DisallowJoinAtEnd.
  3. The workflow calls ExecuteCore inside one ITransactionRunner.RunInDocumentAsync call.
  4. See the NotificationBannerService.ShowToast and EnsureWindowIfDebugMode calls at the end of ExecuteAsync.

DIAGNOSTICS

ExecuteCore logs the operation and element ID at Error level before it throws. The prefix is [AllowJoin] or [DisallowJoin]. ToolCommand uses ISafeExecutor for command failures. See Revit Execution and Progress Overlay.

FramingJoinsCommandTests checks both command declarations. FramingJoinsWorkflowRevitTests needs a level and a structural framing type in gm_test_model.rvt. See Model paths.
