Framing Joins

Framing Joins allows or disallows joins at both ends of selected structural framing instances. The tool has no persistent settings.

Commands

Command Manifest identity Operation
Allow Join DBTools.AllowJoinSelected Calls StructuralFramingUtils.AllowJoinAtEnd for ends 0 and 1
Disallow Join DBTools.DisallowJoinSelected Calls StructuralFramingUtils.DisallowJoinAtEnd for ends 0 and 1

Both commands use InlineUi and the Structural panel's framing_joins split button. Their manifest order is 0 and 1, respectively. The icon keys are allow_join and disallow_join. Availability uses CommandAvailability.HasStructuralFramingSelection.

  1. Select structural framing elements.
  2. Run Allow Join or Disallow Join.
  3. Read the completion banner for the processed instance count.

Execution

App/Composition/AllowJoinSelectedCommand and DisallowJoinSelectedCommand resolve Features/FramingJoinsWorkflow through their CommandService registration. The workflow receives ITransactionRunner, ILoggerWindowHost, a window-owner provider, and a typed logger through dependency injection.

The workflow reads the current selection, filters by OST_StructuralFraming, removes duplicate IDs, and retains only elements that resolve to FamilyInstance. An empty selection or a selection without usable framing instances produces SafeExecutionRefusedException. FramingJoinTargetBuilder owns the category filter. FramingJoinsWorkflow.ExecuteCore owns the endpoint loop.

All targets run in one transaction named DB Tools - Allow Join Selected or DB Tools - Disallow Join Selected. The count increases after both endpoint calls succeed. It counts processed instances, including instances whose join state already matches the request.

An endpoint failure logs the exception and element ID, then throws InvalidOperationException with the original cause. The transaction rolls back the complete batch. A successful batch shows a six-second completion toast and ensures the logger window when Debug Mode is enabled.

Source and tests

The implementation and manifest are under src/Tools/Structural/FramingJoins/. The project references Core and the Revit API. Pure fixtures FramingJoinTargetBuilderTests and FramingJoinsWorkflowTests cover filtering and endpoint execution. Hosted fixtures FramingJoinsCommandTests and FramingJoinsWorkflowRevitTests cover command and Revit integration.
