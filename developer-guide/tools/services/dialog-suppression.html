dbtools.DialogSuppression

NAME

dbtools.DialogSuppression - match Revit dialog text against configured rules

SYNOPSIS

source    src/Tools/Services/DialogSuppression/ (manifest.yml)
assembly  dbtools.DialogSuppression
entry     DialogSuppressionToolModule
hook      DialogSuppressionHook

DESCRIPTION

DialogSuppressionToolModule registers a lifecycle hook and the Dialog Suppression settings pack. The pack is the user entry point for the service. DialogSuppressionToolModuleTests checks both registrations and the singleton adapter registration.

STRUCTURE

Path under the tool source Owner
Features/DialogSuppressionHook.cs InitializeAsync, RollbackAsync and Shutdown.
Features/DialogBoxShowing/ DialogBoxShowingEventAdapter.Subscribe and Unsubscribe.
Features/DialogSuppressionPolicy.cs DialogSuppressionPolicy reads settings, matches the dialog text and requests an override.
Settings/ DialogSuppressionSettingsContext validates the edits from DialogSuppressionSettingsView.xaml and builds the options snapshot.

The adapter looks up DialogBoxShowing and builds its delegate with reflection. Its handler takes the event arguments as object. See the comment on DialogBoxShowingEventAdapter.OnDialogBoxShowing for the Revit event-argument type rationale.

CONTRACTS

  1. DialogSuppressionPolicy.Apply reads the Services flag for each event. An override requires both SettingsFlags.ServicesModeEnabled and DialogSuppressionSettings.Enabled. DialogSuppressionPolicyTests checks the Services flag and changes to the patterns between events.
  2. The policy creates regular expressions with RegexOptions.IgnoreCase. It reuses them while the resolved pattern sequence stays the same. It divides 250 ms among those patterns, with a minimum of 1 ms per pattern. DialogSuppressionPolicyTests checks matching, cache invalidation and timeout handling.
  3. DialogSuppressionSettingsContext blocks saves with an invalid regular expression or an empty list of nonblank patterns. DialogSuppressionSettingsContextTests checks save validation.

FLOW

  1. DialogSuppressionPolicy.GetDialogMessage reads the first non-null string in Message, MainInstruction and Title, in that order.
  2. On the first match, the policy calls OverrideResult(1) if the event arguments expose that method. DialogSuppressionPolicyTests checks the value with test event arguments.

DATA

The services.dialog_suppression pack uses Tools.DialogSuppression. Enabled and SuppressInternalExceptions default to true. SuppressInternalExceptions persists with the pack and has no effect on suppression. The view exposes Enable Dialog Suppression and Dialog text patterns.

The policy uses DefaultSuppressedDialogPatterns when the saved list contains no nonblank patterns. Otherwise, it considers the full nonblank list. The editor binds to DialogSuppressionSettingsContext.PatternList. It loads the first three nonblank patterns and displays the default if there are none. Saving Settings writes the editor snapshot. It omits blank rows, saves a sole default as an empty list, and preserves other pattern text as entered. AppPaths.GetSettingsFile defines the path for each Revit year.

DIAGNOSTICS

DialogSuppressionPolicy logs invalid patterns and match timeouts as warnings. It tries a timed-out pattern on later events and logs its timeout once per pattern text. DialogSuppressionHook logs handler failures under DialogSuppression handler failed.

TESTS

./test.sh test --tool DialogSuppression --scope pure
./test.sh test --tool DialogSuppression --scope local -y 2026

DialogSuppressionSettingsTests checks the round trip of Enabled, SuppressInternalExceptions and SuppressedDialogPatterns. DialogSuppressionSettingsViewTests checks the view, its data context, and the pattern list bindings. DialogSuppressionHookErrorBoundaryTests invokes DialogSuppressionHook.OnDialogBoxShowing by reflection with test event arguments. It checks that the handler logs an override failure and returns.
