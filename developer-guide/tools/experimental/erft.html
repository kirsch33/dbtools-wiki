NAME

dbtools.ERFT - plan and apply framing offset changes

SYNOPSIS

source    src/Tools/Experimental/ERFT/
assembly  dbtools.ERFT.dll
module    App/Composition/ErftToolModule.cs

DESCRIPTION

AdjustmentPlan holds column and beam offset changes for a floor or roof target. See Extreme Roof Framing Tool.

STRUCTURE

manifest.yml gives ErftNewCommand panel Testing and profile InlineUi. The sandboxWindows entry dbtools.ERFT.Main uses ErftWindowDesignTimeViewModel. ErftWindowDesignTimeViewModelTests checks that model's defaults. WindowSession.EnsureSession loads the embedded App/Views/ErftWindow.xaml and repeats the manifest dimensions.

For Edit ERFT, see ErftContextualRibbonInjector.BuildButton. ErftCompositionContractsTests checks the hook registration. FindTargetTabs looks for Structural Columns, Structural Framing and Multi-Select, with Multi and Multi-Category as fallbacks. EvaluateSelection checks selected elements for structural column or framing category, a valid entity, Tag equal to ERFT and a nonblank SystemId. ContextualEditCommandType names ErftNewCommand.

ErftWindowInteractionBehavior handles Escape and clicks outside grid rows. Model readers live in Features/Operations/. PreviewSceneBuilder prepares the preview scene, and PreviewProjector converts it for the shared presenter.

CONTRACTS

  • AddErft scopes AdjustmentPlanStore per run (ServiceCollectionExtensionsTests).
  • SourceSelectionCollector.IsValidSourceSelection admits beams alone when one connects to a model column. SourceSelectionValidator checks copies of the beams (SourceSelectionValidatorTests). PlanPreparationBuilder.CompletePreparation builds the graph from selected members.
  • For a resolved top level, ColumnReader adds the top offset to the level's ProjectElevation. This uses the datum of the location line read by BeamReader. FramingGraphBuilder uses a 1/2 in. distance in three dimensions. It checks the nearest column top first, then beam interiors and nearby directly supported ends. A supporting interior point must be more than 1/2 in. from both beam ends. The builder skips cycles and orders supports first (FramingGraphBuilderTests).
  • TargetGeometryReader triangulates the target's solids and reads each face's generating elements. TargetGeometryBuilder accepts faces whose reported generators are the target or Revit Opening elements. It samples the outward normal at each triangle center and uses triangles with host normal Z below -1e-9. For a linked target, it maps the points and normals with GetTotalTransform (TargetGeometryBuilderTests). TargetSurfaceProjector projects vertically to the eligible surface nearest the member end. At equal distances, it uses the lower elevation. It accepts the closest edge of a triangle when the plan miss is within Application.VertexTolerance (TargetSurfaceProjectorTests).
  • FramingGraphBuilder groups remaining free ends by beam ID, with one end per beam and every pair within 1/2 in. in three dimensions. AdjustmentEvaluator picks a shared splice target from rounded projected elevations. Up picks the highest, Down the lowest, and Nearest the first successful projection in group order. A failed projection still gives an error for that end.
  • AdjustmentEvaluator uses the selected mode for projections. An end that follows a support or uses a shared target rounds its own change with Nearest. A follower uses the support elevation at the followed end. RoundingEvaluator treats a change with magnitude 0.000001 ft or less as zero. It normalizes whole and half steps within that distance (AdjustmentCalculationTests).
  • ErftWindowViewModel.CanApply checks PendingCount > 0, zero row errors and valid tolerance. ErftWindowViewModelTests covers row errors and tolerance, including the 0.01 in custom minimum.
  • During Apply, WindowSession.Interaction ignores apply and pick requests. ErftWindowViewModel.CanClose blocks closing. An expected Apply failure keeps the window open. WindowSessionTests checks these gates and the ShowModal overload that rethrows a thrown Apply exception.
  • AdjustmentPlanExecutor rejects row errors and skips writes when nothing is pending (AdjustmentPlanExecutorTests).

FLOW

FramingAdjustmentWorkflow calls PlanPreparationBuilder.Prepare for launch and PrepareFromStoredPlan for edit. See EditReconstructionBuilder.TryCreatePlan for stored member resolution.

FramingAdjustmentWorkflow.RunSession starts the Extreme Roof Framing Tool transaction group before preparation. On success it assimilates the group into one Undo entry before showing the success alert. Canceling or failing the session rolls back the group.

WindowSession reuses the shell after Pick (WindowSessionTests). TargetRepickWorkflow.Repick preserves the plan if target resolution fails (TargetRepickWorkflowTests).

MemberProfileExtractor passes ERFT Extract Member Profile, ERFT Extract Member Profile Bake and ERFT Extract Member Profile Cleanup to separate transactions per member type inside the session group. PlanPreparationBuilderTests checks temporary instance cleanup.

AdjustmentWriter.ApplyAsync passes ERFT Apply Adjustments to the transaction runner. ApplyColumnAdjustment writes FAMILY_TOP_LEVEL_OFFSET_PARAM (FramingAdjustmentEndToEndTests). ApplyBeamAdjustment writes STRUCTURAL_BEAM_END0_ELEVATION and STRUCTURAL_BEAM_END1_ELEVATION.

DATA

TargetGeometryReader.GetTargetDisplayName formats the target type and level. GetLevelName reads the footprint roof base level, extrusion roof constraint level or face roof level. It uses Element.LevelId if that parameter does not resolve a level.

Lengths are in feet. Element IDs are long. Change the 1/4 in default in AdjustmentPlan.ToleranceFeet and TolerancePreset.Default (the ErftWindowViewModel.TryGetCurrentToleranceFeet fallback). Update "0.25" in ErftWindowViewModel._customToleranceText and ErftWindowDesignTimeViewModel.CustomToleranceText.

SystemPlanRepository.Save sets SystemIdString and DataJson on the DataStorage entity. Save and Load reject duplicate system records with SystemRepository/DuplicateSystemRecords.

AdjustmentWriter.TagElement sets Tag, SystemId, MemberRole, OriginalOffset and Timestamp. StoredPlanMapperTests checks the JSON shape and inclusion of every plan row.

AdjustmentWriter.ValidateSchema, SystemPlanRepository.ValidateSystemSchema and StorageSchema.IsElementSchemaCompatible compare schema names and required simple string fields. StorageSchemaFieldValidatorTests checks field names, types and containers. EvaluateSelection catches schema identity collisions, logs a warning and returns hasElements = false.

For a schema field change, use a distinct GUID. Add the prior (Id, Name) to StorageSchema.RetiredElementSchemas or StorageSchema.RetiredSystemSchemas.

DIAGNOSTICS

ErftNew in build/Distribution/tool-contracts.json declares the command type and window title. DevModeScenarioTests.Verified_proxies_match_the_tool_contract checks the command proxy. DevModeScenarioTests.Routes excludes the pick route. TargetSelectionPicker ties each prompt to its own Revit pick. NotificationBannerHost logs the prompt text when it closes.

AdjustmentEvaluator keeps the original offsets on error rows and records the reason in ErrorMessage. The Status cells show that reason as a tooltip. An underside miss can report the plan distance. A failed follower names the followed end and its support when available.

For Apply alerts, see WindowSession.ShowNoPlanToApply, ShowApplyFailure and ShowApplySuccess. See SourceSelectionPicker.ShowConcreteFilterToast for the concrete-filter message and WindowSession.ShowSelectionDiagnostic for selection messages.

ErftNewCommand.RunAsync defines New/RunFailed. ErftContextualRibbonInjector.RunEditFlow defines Edit/RunFailed. FramingAdjustmentFailure.Tag formats codes as [SpecFail/<code>].
