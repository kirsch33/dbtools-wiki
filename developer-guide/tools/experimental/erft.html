Extreme Roof Framing Tool (ERFT)

Overview

ERFT adjusts host structural column and beam offsets to follow a host or linked floor/roof bottom surface. It preserves level associations, previews calculated changes, and applies offsets and storage in one transaction. See the technical specification for geometry, rounding, storage, and failure contracts, and the user guide page for the window.

Architecture

Feature decisions remain behind IWindowSession and WindowSessionAction. App implements their typed presentation methods. ERFT production has no dependency on another tool. A missing active document returns Failed before opening the window. The per-run DI scope owns and disposes WindowSession on every exit path. The workflow does not dispose it. Normal-close cleanup diagnostics belong to the shared window host. ERFT logs failures from its own close-and-retire release path without replacing the caller's primary failure.

The shell explicitly sets the title Extreme Roof Framing Tool and loads the raw EmbeddedResource DBTools.ToolViews.ERFT.ErftWindow.xaml. The view merges its theme directly and uses the stable string-based EnumMatchConverter for rounding radio buttons.

Preview

PreviewSceneBuilder creates target and member meshes. PreviewProjector maps them into StructuralScene3D snapshots. DBTools.Presentation.StructuralPreview owns device lifetime, camera state, navigation, hit testing, hover tooltips, emphasis, outlines, target crease edges, and cleanup. DBTools.Presentation.Tools.ERFT.ErftPreviewOptions chooses the preserve-angle camera and fit-as-Home policy. The initial look direction is parallel to (0, 20, -10), with Z up. The camera home angle does not derive from the target mesh. Scene bounds include every rendered mesh vertex. Geometry updates within unchanged bounds preserve Home. Changed bounds fit the scene at the current angle and capture a new Home. Zoom to Fit also replaces Home and the viewport's default camera. Re-pick retains the current angle rather than constructing a new camera. Hover text uses the themed WPF ToolTip with a 16-pixel cursor offset.

Member identities use element:<ElementId> and connect preview clicks to comparison rows. Targets are non-pickable context. Empty-space clicks clear row selection. Target hover does not replace member tooltips. Selected members use cyan emphasis and a 1.6-pixel all-edge outline. Target fill opacity is 0.12. Target and member edges use the palette’s cyan-gray color. The stable presenter owns lighting and camera bounds constraints. Status remains visible while the scene prepares or degrades. Navigation buttons disable when no scene exists. Both grids use a final stretch Status column with a minimum width. Thrown zoom/reset exceptions log a warning and appear in the preview status line. Fit failures log a diagnostic; reset without a Home attempts Zoom to Fit. A projection failure clears the rendered scene and shows its cause until the scene changes or the presenter becomes unavailable. Without a specific reason, the placeholder reads 3D Preview is unavailable: the presenter is unavailable.

A graphics-device or WPF D3DImage failure permanently disables the presenter for that window. StructuralPreviewDevice releases resources once and does not forward Reinitialize to the native effects manager. It does not substitute WARP for the D3DImage bridge. The placeholder asks the user to update the graphics driver or enable GPU acceleration and reopen the tool. Preview navigation disables, but adjustment, Apply, Cancel, and target re-pick remain available outside an active apply. Re-pick retains the unavailable presenter and does not retry graphics initialization.

Profile extraction reports expected unsupported geometry per type. Unexpected geometry, transaction, cleanup, or cancellation faults propagate. One Info summary records total/extracted/unsupported counts. Per-type progress is Debug. Selection-hook logs suppress per-event start/completion banners and report evaluation changes only when state changes.

Data and contracts

The technical specification defines AdjustmentPlan, target meshes, graph ordering, rounding, element tags, and system storage.

Workflows

Use

  1. Run Extreme Roof Framing on the Testing panel.
  2. Pick a linked floor or roof. Press Esc to switch to host target selection.
  3. Pick a host target if needed. Esc at this stage cancels launch.
  4. Select source columns and beams, then Finish.
  5. Review the target, comparison rows, tolerance, and preview.
  6. Apply when the tolerance is valid, at least one row requires modification, and no row has Error status.

Sources must be point-based structural columns or straight non-brace framing in the host document. Material names matching \bconcrete\b case-insensitively exclude members. The source set needs a column or a beam that connects to a model column under ERFT's hierarchy rule. Unsupported extracted sources fail launch rather than disappearing from the plan.

Edit ERFT on contextual Modify tabs restores a selected system's stored plan and settings. Missing or incompatible storage fails edit launch. Re-pick hides the window with HideForPick, selects another target, and reuses the same shell and preview presenter with the rebuilt plan. Re-applying calculates from current model geometry and offsets.

During apply, a second Apply or Re-pick request is ignored. Cancel and window close are blocked. A successful apply reports its result and closes the window. An expected apply failure keeps the window open. A thrown apply exception closes the window and propagates to safe execution. Escape clears both comparison-grid selections and does not close the window. Cancel has no WPF IsCancel route. Clicking an empty area of either grid with any mouse button clears both selections. See the alert and preview contracts for event severity, ownership, and validation.

Testing

Pure tests cover graph construction, target projection, adjustment/rounding, storage admission, scene projection, window selection, close gating, modal lifetime, and injected device creation failure during re-pick and Apply. Core tests exercise presenter recovery and resource release without a GPU. Presentation's hosted StructuralPreview3DTests covers fit-as-Home through the renderer.

Revit-hosted FramingAdjustmentEndToEndTests uses gm_test_model.rvt and transient host floors with real beam and column instances. It covers seed viability, target extraction, calculation, offset writes, tags, and DataStorage inside rolled-back transaction groups. A Revit 2027 case checks legacy-schema cleanup on 2027/Regression/realtest_model.rvt without saving the model. Linked-target behavior requires a Revit-hosted check with a loaded linked floor or roof.

./build.sh BuildSelectedLocalTests --TestProjects DBTools.ERFT.Local.Tests -y 2026
./test.sh test --tool ERFT --scope local -y 2026 --fixture FramingAdjustmentEndToEndTests

Limitations

Unsupported member profiles omit those members from the preview. With no successful profiles, the preview contains only the target. Graphics failure requires a new window to initialize another presenter; calculation and Apply remain available in the existing window.
