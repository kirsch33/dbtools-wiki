NAME

dbtools.ERFT - the assembly behind the Extreme Roof Framing Tool

SYNOPSIS

source    src/Tools/Experimental/ERFT/   (MAP.md, manifest.yml)
assembly  dbtools.ERFT
entry     ErftToolModule
command   ErftNewCommand                 (run profile InlineUi, panel Testing)
hook      ErftContextualRibbonInjector   (Edit ERFT on contextual Modify tabs)
view      App/Views/ErftWindow.xaml, src/dbtools.Presentation/Tools/ERFT/

DESCRIPTION

FramingAdjustmentWorkflow runs both flows. RunNewModalFlow picks a target and the sources, then calls PlanPreparationBuilder.Prepare. RunEditModalFlow takes a loaded StoredPlan and calls PrepareFromStoredPlan. The window changes the tolerance and rounding of AdjustmentPlanStore.Current and recalculates. Apply runs AdjustmentPlanExecutor. Lengths are in feet, and element IDs are long. The user page describes the behavior. Structural Preview describes the 3D presenter.

CONTRACTS

  1. Sources. SourceSelectionFilter admits host FamilyInstance columns with a LocationPoint and framing with a Line that is not StructuralType.Brace. SourceSelectionPicker drops members whose structural material matches \bconcrete\b, case-insensitive. If a reader returns fewer members than the user selected, the launch fails with Selection/SourceExtractionFailed.
  2. Column check. A selection with no column must have a beam within the connection tolerance of a model column, or it fails with Selection/NoColumnConnection. The check runs on clones of the selected beams, so it changes no connection. The plan graph uses the selected members only. SourceSelectionValidatorTests checks this.
  3. Graph. FramingGraphBuilder.ConnectionToleranceFeet is 0.5 / 12 ft. A beam end connects to the first column, in selection order, whose top is within the tolerance (inclusive). A free end then connects to the nearest other beam segment that is closer than the tolerance. An end whose connection would make a cycle stays Free, with a warning. The processing order is the columns, then a Kahn sort of the beams. Among beams with no open dependency, beams that frame to columns go first, then lower IDs. FramingGraphBuilderTests checks the connections.
  4. Target. The bottom surface is every face whose normal Z, at the middle of its UV box, is -0.1 or less in host coordinates. A link uses GetTotalTransform. TargetSurfaceProjector preserves the query X and Y and interpolates Z on each triangle that covers that point. It chooses the nearest vertical intersection when triangles overlap and returns no point when no triangle covers the query X and Y. Expected target failures return a TargetGeometryFailureReason, not an exception. TargetSurfaceProjectorTests checks the projection. No Revit test uses a loaded linked target.
  5. Rounding. RoundingEvaluator.ApplyRounding uses Math.Round (midpoint to even), Math.Ceiling or Math.Floor of delta / tolerance. A column, or a beam at both ends, is NoChangeNeeded when the rounded change is 0 (IsWithinTolerance: less than half the tolerance). A beam end on a beam takes the adjusted Z of the supporting beam at the XY parameter, clamped to the segment. AdjustmentCalculationTests checks the rounding and the propagation.
  6. Apply. AdjustmentWriter runs one transaction, ERFT Apply Adjustments, in the active document. It purges retired entities, sets FAMILY_TOP_LEVEL_OFFSET_PARAM, STRUCTURAL_BEAM_END0_ELEVATION and STRUCTURAL_BEAM_END1_ELEVATION, tags each changed member and saves the system. A FramingAdjustmentFailureException rolls it back and becomes a failed result. Before the writer runs, AdjustmentPlanExecutor refuses rows with Error as Apply/PlanHasErrors. AdjustmentWriterTests and FramingAdjustmentEndToEndTests check this.
  7. Snapshot. StoredPlanMapper.CreateSnapshot stores every column and beam in the plan. SystemPlanRepository.Save replaces the one record of the system, so Edit ERFT restores every member from the last applied plan. CreateSnapshot_IncludesEveryMember checks the stored rows.
  8. Admission. StoredPlanMapper.Deserialize requires the tolerance, the rounding mode, the Columns and Beams lists, positive element IDs, a matching SystemId and a host target or a link and linked target pair. It fails with a Storage/* code. StoredPlanMapperTests checks this.
  9. Profiles. MemberProfileExtractor places one temporary instance of each type on the lowest level and deletes it. It commits three transactions for each type in the host document, outside any group. Expected ProfileLoops/* conditions fail one type. Other faults propagate. The ExtractProfiles_* cases in PlanPreparationBuilderTests check this.
  10. Apply gate. While IsApplyInProgress is true, the session ignores Apply and Pick, and CanClose blocks closing. An expected failure keeps the window open. A thrown failure closes it and reaches the command. WindowSessionTests checks this.

FLOW

  1. TargetSelectionPicker obtains a floor or roof target.
  2. SourceSelectionPicker picks the sources. SourceSelectionCollector extracts and checks them.
  3. PlanPreparationBuilder reads the target, builds the graph, calculates, and extracts the profiles before the window opens.
  4. ShowModal returns RepickTarget, Applied or Cancelled. Re-pick hides the shell, runs TargetRepickWorkflow and shows the same shell again.
  5. Edit: ErftContextualRibbonInjector reads the Tag and SystemId of the selection and chooses one system. Its RunEditFlow calls RunEditModalFlow in a command context that Core creates for ErftNewCommand. EditReconstructionBuilder reads the current geometry and offsets of the stored members.

DATA

All fields are simple String fields with vendor input dbtools. Revit stores the vendor ID in uppercase.

Schema GUID Fields
dbtools_ERFT_V2, on members 20af133f-34e7-4ff7-910e-bf351e04f3d0 Tag (ERFT), SystemId, MemberRole (Column or Beam), OriginalOffset, Timestamp
dbtools_ERFT_System_V2, on a DataStorage f2e43724-0569-469b-85b3-64c3810e7aea SystemIdString, DataJson (camel-case StoredPlan JSON)

Apply deletes entities of the retired schemas dbtools_ERFT and dbtools_ERFT_System only when the vendor and name match. It deletes a DataStorage that has no entity left. Apply also deletes the entities of the four schemas of the earlier product spelling, by their earlier GUIDs and names. Their data is not migrated.

DIAGNOSTICS

FramingAdjustmentFailure.Tag formats codes as [SpecFail/<code>]. Alerts and repository failures show the tag. Profile extraction logs one Info summary of total, extracted and unsupported types.
