Structural Preview

DBTools.Presentation.StructuralPreview is the stable WPF host for the structural 3D preview shared by the Extreme Roof Framing Tool (ERFT) and the Super Girt Tool (SGT). A tool adapter supplies immutable scene data and receives pointer events. The host owns the Helix viewport, effects manager, camera, navigation, materials, hit testing, tooltip, overlay markers and cleanup. Helix and SharpDX are merged into Presentation as internal types; no tool assembly or raw view names them. ERFT and SGT register the presenter's disposal with their tool-window sessions.

The component has no Core, App or tool-assembly dependency. Its public scene records contain only immutable arrays, System.Numerics values, strings, integers and scalar values.

Attach and dispose

Call StructuralPreview3DFactory.Attach on the viewport host dispatcher. The ContentControl must be empty. The optional overlay canvas must use the same dispatcher. The returned IStructuralPreview3D owns one viewport and one effects manager. All presenter methods and disposal are synchronous UI-thread operations.

Attach returns a disabled presenter with the load error as its reason when Helix libraries cannot be loaded. The disabled presenter still validates and copies supplied scene and emphasis data, reports its status reason, returns false from projection, and can be disposed repeatedly.

For an available presenter, Dispose removes viewport, camera, owner-window, timer and input handlers; closes the tooltip; removes only the overlay children created by this presenter; disposes owned scene elements, viewport and effects manager; clears scene data and subscriber events; and clears the host content only when that content is still the viewport owned by this presenter. Cleanup is synchronous and does not post a dispatcher frame. Disposal clears subscriptions before cleanup, so it publishes zero presenter events during or after disposal. Repeated disposal is safe.

Scene data and picks

SetScene validates and deep-copies the supplied records and arrays. The caller may then release or reuse its own objects. Equal mesh geometry keeps existing Helix models; geometry or appearance changes update the rendered decorations and materials, while bounds or exterior-normal changes update camera state.

Mesh Opacity supplies the material alpha and overrides the alpha byte in Argb. Line sets multiply their ARGB alpha by Opacity. Selection and hover colors preserve the mesh opacity.

Mesh picking is independent of emphasis. A mesh is eligible for a hit only when its supplied IsPickable value is true; context meshes can therefore be pickable or non-pickable independently of their material role. A floor is supplied as scene geometry, normally a context mesh with IsPickable: false. Line sets and non-pickable meshes do not produce mesh hits. A missed hit has null mesh ID, null context ID and null world point. A hit's mesh and context hits are resolved independently: each is the nearest eligible hit for its role. MeshId is the nearest member ID, or null when there is no member hit; ContextId is the nearest context ID independently. WorldPoint is the nearest member hit point when one exists, otherwise the context hit point, so a context-only hit has a null mesh ID and a context world point. The event also carries WPF screen coordinates relative to the viewport and keyboard modifiers.

SetEmphasis accepts one emphasis state per mesh ID. The presenter applies selection, segment-selection, sibling, dimmed and hover material policies from the selected StructuralPreviewPalette. StructuralPreviewPalette.Sgt and .Erft are the adapter presets. They differ in member color boost, surfaces, selection and hover colors, and edge and outline settings, and use the same renderer.

The presenter adds a pivot marker to the supplied overlay canvas while orbiting. The marker and all generated WPF objects have their data context cleared or blocked so tool data contexts do not flow into the stable visual tree.

Home views and camera movement

The ExteriorThreeQuarter strategy is the SGT home view. When bounds or the exterior normal changes, the session recomputes and stores a raw Home camera. Its exact formula is:

distance = max(2.2 * boundsDiagonal, 8)
yaw      = 28 degrees
pitch    = 0.22 downward along the configured up axis

The exterior normal is projected onto the up plane. A missing horizontal normal uses negative Y as the stable fallback. The stored Home keeps this exact distance. Clamping applies to the displayed camera only. If the user has moved the camera, a changed scene clamps the current camera and retains the new raw Home for a later reset. Reset clears the moved flag, applies Home, and clamps the displayed camera.

ERFT uses the PreserveAngle strategy. When bounds change, the session fits the current view angle and captures that result as Home. The fit formula is:

halfV    = radians(fieldOfView) / 2
halfH    = atan(tan(halfV) * aspect)
distance = max(boundsDiagonal / 2 / sin(min(halfV, halfH)), 2) * 1.2

Helix FieldOfView is the vertical angle. The fit keeps the bounds' bounding sphere inside both the vertical and the horizontal field of view, so the whole scene is visible at the viewport aspect when the fit runs; the distance clamp still applies. Scene constraints use these bounds-only constants (StructuralPreviewCameraMath):

diagonal   = actualDiagonal, or 10 when actualDiagonal <= 1e-6
min        = clamp(diagonal * 0.0005, 0.005, 0.75)
max        = clamp(diagonal * 40, min * 2, 50000)
targetPad  = max(2, diagonal * 6)
near       = max(0.0005, min * 0.05)
far        = max(100, max * 2)

When a scene changes mesh geometry without changing these bounds, the presenter keeps the stored Home object and only updates its owned render models. Adapters must compute bounds from every mesh vertex so a real extent change is reported as a bounds change; a bounds change is an intentional Home refit under PreserveAngle.

ZoomToFit performs the exact fit. When FitRedefinesHome is enabled, the fitted camera becomes Home and the viewport default camera is updated to the same pose; otherwise the fit marks the camera as user-moved while preserving Home. ResetView restores stored Home. Pan uses screen-space camera axes, orbit uses the configured arbitrary up axis around the selected or picked pivot, and wheel zoom moves toward the picked world anchor. Gesture cancellation occurs on lost capture, window deactivation, unload and disabled interaction.

The viewport's native view cube handles its own preview input before scene picking. The presenter keeps the default camera synchronized with stored scene Home when a scene is attached; an explicit fit also updates it when FitRedefinesHome is enabled.

Input and hover

StructuralPreview3DOptions.ShowTooltips defaults to true. It enables the stable presenter's mesh tooltips. When disabled, pointer updates keep the tooltip closed.

Materials and lighting

Adapters choose StructuralPreviewPalette.Sgt or .Erft and can copy the record to adjust individual values. A palette supplies member and context surfaces, key/fill/rim/ambient light colors, sibling and dimmed policies, selection and hover colors, emissive scaling, edge colors and thickness, outline mode and pivot colors. IsPickable controls hit testing. A non-pickable context mesh remains rendered with its base context material but bypasses selection, segment-selection, sibling, dimmed and hover emphasis; pickable context meshes can receive context hover, sibling and dimmed states but never member selection states.

The SGT preset uses these alpha rules. Sibling emphasis scales diffuse alpha by 0.70 and retains the source ambient, specular and emissive alpha. Dimmed emphasis sets every channel's alpha to max(0.05, sourceAlpha * 0.45). Hovering a sibling restores the base material and adds emissive brightness while preserving its source alpha. Hovering a dimmed mesh adds emissive brightness and retains the dimmed alpha.

The default options select the SGT palette and exterior home strategy. ERFT selects both its palette and its camera strategy:

var options = new StructuralPreview3DOptions
{
    Palette = StructuralPreviewPalette.Erft,
    HomeView = StructuralPreviewHomeView.PreserveAngle
};

Diagnostics and projection

Diagnostic reports debug, warning and error messages as plain strings with an optional exception. Repeated identical diagnostic messages are suppressed for two seconds. An initialization or disabled-path diagnostic is delivered once to the first diagnostic subscriber; the reason is also available in Status. Event publication takes an invocation-list snapshot and stops when a callback disposes the presenter. No presenter event is raised after Dispose clears subscriptions.

On the first render failure, the presenter changes to Unavailable, disables interaction, cancels navigation, clears hover state, stops its clamp timer and collapses the viewport. It reports that failure as an error diagnostic, subject to the two-second diagnostic de-duplication; later render failures are ignored while the presenter is unavailable.

TryProjectToViewport returns false when the presenter is unavailable, disposed, unloaded, has no render context, receives a non-finite point, has an invalid camera or the point is behind the camera. It returns WPF device- independent coordinates relative to the viewport on success. Projection failures are reported as debug diagnostics and never escape as exceptions.
