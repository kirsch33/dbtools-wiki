Build commands

NAME

build/Build.proj - build the product and its test assemblies

SYNOPSIS

dotnet build build/Build.proj [-t:TARGET] [-p:NAME=VALUE]...

DESCRIPTION

Install the .NET SDK 10.0.401 or a newer 10.0 patch in the 10.0.4xx feature band. Run the build from the repository root on Linux, native Windows or WSL 2. The default BuildAll target builds, validates and publishes the complete Release distribution from a clean Git checkout.

Set -p:RevitYear=2026 or -p:RevitYear=2027 to stage the product for one year. In this mode BuildAll runs BuildApp after Preflight. Leave RevitYear unset for distribution validation and publication.

Content versions include the .NET SDK version. Builds of the same commit with different SDK patches have different content versions.

PREFLIGHT

dotnet build build/Build.proj -t:Preflight

Preflight reports Git LFS, model file hydration, Python 3.10 or later as python3, Inno Setup on Windows, the dbtools-daemon CLI and relay settings, and the DocFX local tool. The report includes install instructions for missing tools. It prints could not check when a probe cannot finish. A Git LFS pointer in testing/RevitTestModels/ gets the commands git lfs install and git lfs pull.

BuildAll runs the report before product restore. The CANON gate, build-docs.sh and compile-installer.ps1 enforce their tool requirements. BuildInstaller requires Inno Setup 6.7.1 or later in the 6.x series.

OPTIONS

Target Action
BuildAll Build, validate and publish the complete Release distribution.
BuildApp Compile and stage the product.
RestoreProduct Restore the production graph from NuGet.
BuildTests Compile the Pure, Local and Design Automation test graphs.
BuildSelectedPureTests, BuildSelectedLocalTests, BuildSelectedDesignAutomationTests Compile projects selected by TestProjects.
BuildDevModeScenario Compile the Revit-hosted Dev Mode scenario.
BuildSandbox Compile and stage the standalone Sandbox.
AssembleDistributionCandidate Assemble a Release candidate and its metadata.
PackageSandboxValidationInput Package the candidate and Sandbox for Windows acceptance.
BuildBundle Package an Autodesk bundle from a promoted distribution.
BuildInstaller Build the bundle and compile the installer on native Windows. Requires -p:Version.
ValidateComponentResourceUris Check component resource URI interpolation in product source.
ValidateManifestTypes Build and stage the product, then resolve manifest type references.
Clean, Info Remove build output or print the effective configuration.
Property Value
Configuration Release (default) or Debug.
Version Product version in MAJOR.MINOR.PATCH form. The default comes from Version.props.
RevitYear 2026 or 2027. An unset value selects both years.
SkipClean true (default). Set false to clean during product build.
DryRun false (default). Set true to inspect Clean or BuildBundle without writing their outputs.
TestProjects Exact project filename stems. Use %2C between stems in a command-line value.
CandidateDistributionPath Path to the promoted distribution that BuildBundle packages.
Revit2026Dir, Revit2027Dir Reference metadata directories. Revit API packages supply the defaults.

The test graph targets require SkipClean=true and DryRun=false. Use dotnet build build/Build.proj -t:Clean to clear build output. The target keeps build/, build-tasks/, dist/, acceptance/, test-results/ and build.json under .artifacts/. It also deletes build bin/ and obj/ directories and *_wpftmp.csproj files left in the source tree. The scan skips build/, docs/, vendor/, .git/, nested Git checkouts and symbolic links.

EXIT STATUS

dotnet build returns zero when the requested targets succeed. A failed build or validation target returns a nonzero exit status and a diagnostic.

FILES

Path Use
global.json Minimum .NET SDK patch and feature band.
Version.props Default product version.
.artifacts/build/<build-id>/ Child build binlogs. A later build removes run folders idle for more than one day.
.artifacts/bundle/dbtools.bundle Autodesk bundle from BuildBundle.
.artifacts/bundle/installer-defines.json Bundle path, product files, version and years for the installer compiler.
.artifacts/release-assets/dbtools-Setup-<version>.exe Installer from BuildInstaller.

EXAMPLES

Stage a Debug build for Revit 2026.

dotnet build build/Build.proj -t:BuildApp -p:RevitYear=2026 -p:Configuration=Debug

Check a promoted distribution for packaging.

dotnet build build/Build.proj -t:BuildBundle -p:CandidateDistributionPath=.artifacts/dist/Release -p:DryRun=true

Build the bundle and installer on native Windows.

dotnet build build/Build.proj -t:BuildInstaller -p:Version=0.1.0
