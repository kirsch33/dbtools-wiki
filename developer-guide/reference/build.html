Build commands

NAME

build.sh, build.ps1 - build the product and its test assemblies

SYNOPSIS

./build.sh [TARGET] [OPTION]...
pwsh -NoProfile -File build.ps1 [TARGET] [OPTION]...

DESCRIPTION

Use build.sh on Linux or WSL and build.ps1 with PowerShell on Windows. Both pass the target and options to build/Build.proj as MSBuild arguments. Both map the public Restore target to _DBT_Restore because MSBuild reserves Restore for package restore.

OPTIONS

Both wrappers print the full list of targets, options and defaults from build/Usage.txt.

./build.sh --help
pwsh -NoProfile -File build.ps1 --help
Task Target and options
Publish the distribution BuildAll is the default target.
Stage a product year Use BuildApp -y YEAR. Add --debug for Debug output.
Compile test projects Use BuildTests for Pure, Local and Design Automation. Use BuildSelectedPureTests --TestProjects A,B to compile selected Pure projects.
Package the Autodesk bundle Use BuildBundle. Pass --candidate-dist DIR to use a promoted distribution.

BuildTests and the selected-test targets reject --clean and --DryRun true. Use the standalone Clean target to clear build output first.

Clean keeps build/, build-tasks/, dist/, acceptance/, test-results/ and build.json under .artifacts/. It deletes all other entries there, including .artifacts/bin/. It also deletes build bin/ and obj/ directories and *_wpftmp.csproj files left in the source tree. The source scan skips build/, docs/, vendor/, .git/, nested Git checkouts and symbolic links.

--Revit2026Dir and --Revit2027Dir select the installed metadata files for validation. The default reference source is the Revit API packages.

EXIT STATUS

The Exit status paragraph of ./build.sh --help (build/Usage.txt) lists the exit codes.

ENVIRONMENT

Variable Effect
DOTNET Selects a dotnet executable if it has the pinned SDK.
DBT_BUILD_SERVERS In build.sh, 1 enables compiler and MSBuild servers scoped to the invocation. Set 0 to disable them. The default is 1. PowerShell builds run with servers disabled.
DBT_MSBUILD_MAX_CPU_COUNT Sets the MSBuild CPU count for child graphs. The default is 2.
DBT_BUILD_CONSOLE_LOG Sets the destination for the copy of the latest detailed log.

FILES

Path Use
global.json Pins the .NET SDK.
~/.dotnet/pinned-sdk-<version>/ Holds the verified SDK when a system installation lacks the pinned version.
.artifacts/build/<build-id>/ Holds the detailed console.log and child build binlogs.
.artifacts/build/console.log Default path for the copy of the latest run log.
.artifacts/bundle/dbtools.bundle Autodesk bundle from BuildBundle.
.artifacts/bundle/installer-defines.json Supplies the bundle path, product files, version and years to the installer compiler.

EXAMPLES

Use --candidate-dist with --DryRun to check a promoted distribution and skip writing the bundle.

./build.sh BuildBundle --candidate-dist .artifacts/dist/Release --DryRun

On Windows, use Inno Setup 6.7.1 or later in the 6.x series. Build the bundle, then compile .artifacts/release-assets/dbtools-Setup-<version>.exe.

pwsh -NoProfile -File build.ps1 BuildBundle
pwsh -NoProfile -File .github/scripts/compile-installer.ps1
