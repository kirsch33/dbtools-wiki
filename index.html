DB Tools documentation

DB Tools is a set of tools for Autodesk Revit 2026 (2026.5 or later) and Revit 2027, mainly for structural engineering workflows. It runs on 64-bit Windows 10 or 11 and installs for the current user.

Tools

Tool Purpose
Global Mapper Bulk replacement of families, types, styles and materials; duplicate detection; shared parameters.
Super Girt Tool Girt, header, sill and jamb placement on walls.
Combined Foundation Tags Data and positions for combined pier and footing tags.
Transfer Drafting Views Copy of drafting views between a project and a library.
View Template Comparer Comparison and merge of view templates.

The user guide lists all tools.

Item Requirement

Architecture

DBTools.dll is the Revit entry point. It loads DBTools.Core (shared infrastructure and the tool registry), DBTools.Presentation (WPF resources and controls) and one assembly per tool from the Tools folder. The architecture overview describes the layers.
